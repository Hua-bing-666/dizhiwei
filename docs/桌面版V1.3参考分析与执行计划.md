# 桌面版 V1.3 参考分析与执行计划

本轮参考用户提供的“智水生态系统.exe”和配套技术报告。目标是将滴智卫现有诊断、事件核查、实验工具和台架模型组织成更成熟的桌面工作台。算法判断及数据真实性以滴智卫已有证据为准，申报书保持用户当前文件。

## 参考项目的组织方式

已读取报告正文并查看用户正在运行的参考 EXE 原生窗口及其本机服务界面。参考项目使用 WebView2 桌面窗口，主导航包括三维孪生、视觉分析和预测调控；公共指标栏始终展示同一状态，工作区再展示对应的模型、分析或预测。三维区域与硬件模块操作并排，图表与判断依据并排，状态来源和动作反馈集中管理。配套说明将状态更新、独立预测副本、控制请求和回执分别处理。

这些做法对滴智卫有参考价值：统一的会话状态可以减少页面间的数值冲突；并排展示读数与解释有利于人工核查；部件聚焦比仅展示一个三维模型更有用途。参考项目界面上的“真实”“在线”和算法效果属于它自身的表述，本轮不将其作为滴智卫的实验依据，也不复用水族模型参数或其他项目的图片、代码和标识。

## 当前软件的边界

保留八个职责明确的页面。运行总览安排工作，支管监测查看读数与特征，事件页面保存人工核查，设备页面说明接入，历史页面查询和导出，实验页面比较策略并拟合参照，台架页面核对测点与结构，设置页面核对版本与参照。共用会话、采样和事件快照；页面不另建诊断结果。

固定 1 Hz 的 C 诊断仍为运行主线，事件触发采集仍是独立策略实验。所有回放和台架读数均标注合成来源。模型读数映射到 P0、P1、Q 测点，不表示已测出管道精确故障位置。控制仍采用软件请求、收到、模拟执行和人工复位，不接入实物阀门。

## 分项执行与验收

| 步骤 | 实施内容 | 通过标准 |
| :--- | :--- | :--- |
| 1 界面结构 | 紧凑导航、会话状态、公共回放控制、明确页面标题与读数层级 | 八页职责可区分；关键按钮可发现；1024 与 1440 宽度无根页面水平溢出；不出现重叠和截字 |
| 2 图表与核查 | 使用本地 ECharts，保留压力和流量独立单位，提供悬停、范围切换及候选标记 | 图表数据来自同一采样快照；缺测保持断线；候选标记来自事件；交互不改变诊断和历史数据 |
| 3 回放控制 | 手动推进和可暂停的合成回放播放 | 每个中间样本仍经 C 核心；不并发写会话；关闭页面、异常或结束后停止播放；回放速度不冒充采样频率 |
| 4 台架工作区 | 嵌入模型去掉重复页面头；P0、P1、Q 与当前会话同步；支持测点部件聚焦 | 保留 207 构件及几何；点位顺序正确；无有效读数时显示空值；聚焦只改变浏览视角或选中部件 |
| 5 桌面体验 | 原生导出、外观偏好保存、目录与版本说明 | 保存与取消正确；偏好重启保留；旧会话恢复为历史；菜单和退出清理可用 |
| 6 打包交付 | V1.3 便携文件夹和单文件 EXE | 中文和空格路径可运行；无需外部 Python／GCC；解压测试与交付文件一致；包内没有测试数据库 |
| 7 实际验收 | 打包 EXE 操作、截图、后台及浏览器回归 | 逐页查看实际截图；事件和导出核对；两次启动退出；异常输入不改写数据；通过结果和未验证范围分别记录 |

## GitHub 参考与采用

[Microsoft Fluent UI](https://github.com/microsoft/fluentui) 用于参考表面层级、控件状态和焦点设计，采用自有 HTML／CSS 实现，不引入另一套业务框架。[Apache ECharts](https://github.com/apache/echarts) 用于本地交互图表，保留版本和许可证。[pywebview](https://github.com/r0x0r/pywebview) 继续承载原生窗口、保存对话框和 Python 服务。图表库随包保存，运行不从 CDN 获取资源。

UI/UX Pro Max 的搜索结果仅作为设计建议：本轮采用紧凑工作区、清晰来源和可暂停更新；营销式页面段落、过量装饰和玻璃背景不适合当前操作界面，不采用。先完成实际界面及独立运行验收，再根据结果形成交付记录。

## 用户体验补充约束

按用户最新要求，默认工作区突出读数、状态和操作。删除重复页脚、重复工作区说明、每张指标卡的解释性长句和无动作价值的状态文字。设备参数、协议、诊断阈值、实验条件和模型尺寸用途放入可展开的说明；单位、质量状态、候选判断和合成数据来源继续保留。自动回放推进不弹出保存提示；新建会话、主动控制操作、导出和错误才给予反馈。桌面已自动连接时不展示切换到离线网页的按钮。

此约束增加对应验收：默认视图没有协议报告段落，详细配置仍可查阅，模型控制可操作，播放时不连续弹出保存通知。窗口重复启动只返回已有窗口，保留原窗口尺寸；图表与模型聚焦均检查标注边界。
