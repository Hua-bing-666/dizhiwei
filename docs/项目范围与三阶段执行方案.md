# 南疆滴灌支管道早期故障诊断原型系统的范围与执行方案

版本1.4，2026年10月4日。本文件与正式申报九节正文共同作为执行依据；候选硬件细目见《国内硬件选型与可行性核对》，旧仿真保留为研究基础。

## 目标与适用范围

申报名称采用老师提出的“基于 LoRa 的南疆滴灌支管道早期故障诊断物联网原型系统”。在2027年3月至2028年2月完成一个滴灌支管巡检闭环：采集压力和流量，判断需要检查的故障模式，通过LoRa保留并发送告警，在接收软件中提供数据、建议、核查、处置、同工况复测记录与回放。

研究重点为支管下游等效泄漏、支管等效受限两类渐进水力故障，在正常供压调整和支路切换中评价可辨识程度；另一问题是在相同本地诊断下评价可靠上报的开销与及时性。南疆是目标部署场景，现阶段尚无田间适用性证据。原型级系统按台架和有限现场条件验证，不承诺全南疆适用。

早期指在独立确定的失效判据前首次可靠发现，必须同时报告故障程度、误报、漏检及本地/远端时间。不把时间较短直接等同早期。现有仿真用相对同工况健康流量偏离15%作演示判据，它不是农业损失阈值；正式台架判据由导师依据参考测量及实际维护需求冻结。

诊断分三种输出：已满足判据的“等效泄漏模式”或“等效受限模式”；信息不充分时“异常待检查”；数据无效、节点掉线时“无法判断”。不得将“数据正常”覆盖掉线状态。位置只到已布置的监测支管及两压力点所包围的区段，不定位单滴头或厘米级漏点。节流只模拟等效阻力变化，不证明化学、生物堵塞诊断。

## 四个工作包

| 工作包 | 要做的工作 | 可检查产出 |
| --- | --- | --- |
| WP1 测量与建模 | 双支路等效模型，P0/P1/Q布点，量程与参考标定，误差传播和故障程度定义 | 模型说明、布点图、标定记录、适用范围与参数表 |
| WP2 诊断与边界 | 固定阈值、压力归一化、差压/流量特征及持续判据对照；切换、漂移和未知状态挑战 | 独立批次数据、误报/漏检、正确分类和早期提前量、失败案例 |
| WP3 LoRa可靠告警 | 固定本地采样、周期与事件公平对照、缓存、ACK、去重、掉电会话和溢出记录 | 固件、协议、发收日志、两段延迟、通信量和整机测量 |
| WP4 系统与分层验证 | 节点/接收集成，设备档案、支管示意、核查处置、复测归档、趋势、回放、导出、质量状态 | 一套系统与台架、软件、演示、调研/结题报告、过程记录与论文稿 |

## 必做与扩展

必做配置为1个双压力流量节点、1个LoRa接收端、1套可重复双支路清水台架、1个本地Web管理系统；已有电脑作为接收主机。压力点P0位于监测区段入口，P1位于受限元件下游，Q记录该支管进入下游负载及泄漏旁路的总流量。必须先判断测点间健康压降是否高于合成不确定度，不能默认两只廉价压力传感器足以测差压。

节点2、太阳能、云端部署、多支管调度、自动阀控及正式现场试验列入条件扩展，不是基础结项依赖。扩大资助首先增加校准质量、实验重复和独立验证，再扩节点。无法取得现场故障标签时，只报告正常运行适应性。

## 台架与田间安装的用途

三维模型是用于核对装配布置的实验平台方案，服务于标定、共同供压与正常切换、可控故障注入、独立参考测量和重复操作。先用现有板材与管夹搭最小夹具，再依据实际器件调整尺寸；全套定制机架不作为2000元基础采购。小型收集杯是位置示意，实际根据泄漏流量和计时长度选择有余量的量具或称重容器，维持自由出流，避免溢流、背压和电气溅水。

田间设备为固定在实际管路上的传感器与受保护节点；安装间距、管件压损、流量计条件、维护空间和防护须现场核对。台架几何有效性不证明耐压、防水、制造可行或田间适用。

## 系统运行与维护记录

系统贯通监测、告警、人工核查、处置、复测和归档。ACK表示远端保存事件，已查看表示人工浏览，归档要求有可比工况下的复测记录；三者各记时间。无效、离线及证据不足时保留待检查。事件关联设备/会话/序号、试次、配置和健康参照版本，独立标签另存，避免以界面状态代替故障真值。

当前网页实现的是合成回放与浏览器本地维护流程演示，可以保存演示备注、复测结论并导出；不连接硬件，也没有真实维修记录。大创实施期将串口、SQLite、节点日志及独立参考接入该流程。

## 大创实施计划和阶段门槛

2027年3—4月：落实人员与参考仪器，完成水路、单传感器及差压标定、有线日志、时钟和独立操作标签。若测量误差掩盖目标故障，调整布点、量程或目标程度，必要时依学校流程调整任务。

2027年5—6月：完成正常稳定、正常切换、渐进泄漏、渐进受限、切换期间异常五组工况。以3个供压水平、3个程度和每组合≥3次独立操作构建主要故障实验，两个故障类型合计拟54次；正常和切换对照另做。供压暂以80/120/160kPa作为设计网格，真实范围由水泵和传感器确定。各独立试次另记录时间、操作者、阀态、设置和参考测量。

2027年7—8月：实现LoRa节点与管理软件，进行独立日/批次验证，至少8小时连续台架记录，检查节点重启、离线、重复事件、队列溢出和接收恢复；测量真实射频设置与整机能量。不将相邻采样点作为独立样本。

2027年9—10月：冻结方法，完成强基线、单点/双点和状态信息消融，条件允许开展现场正常轮灌适应性测试。整理主论文初稿并视贡献与导师意见投稿。

2027年11月至2028年2月：补关键实验、修订软件和论文，逐项准备任务书对应的系统、数据、调研、研究报告、过程记录和结项演示。按本批要求参加规定竞赛；不要以必须录用论文作为结项唯一条件。

建议研究目标为覆盖台架定义的5%、10%、15%相对流量偏离程度，取得检出概率—误报—提前量曲线，并将故障前误报按小时统计。研究指标是“验证并报告适用边界”；95%准确率、100%早期检出或固定节电比例目前没有依据，不填作已证实性能。若需要数值验收阈值，必须经资源与初试结果审核后写入提交版。

## 论文和科研积分路线

论文方向A优先：轮灌条件下双压力流量测点对渐进支管故障辨识和早期检测边界的作用。必须超过有竞争力的固定阈值和归一化基线，或提供可信的误差/观测边界贡献。增加测点本身不是创新。方向B备选：相同告警机制和及时性约束下的LoRa事件通信取舍，需要真实链路、完整能量和可靠性消融。只选证据充分的主贡献，不拼两条薄弱结果。

目标为形成稿件并尽早投稿，录用、发表、检索和学校认定均不保证。参考用户提供的今年科研评分，省级第一完成人4分加符合条件的6分论文可达10分；国家级第一完成人5分加6分论文按上限10分计。校级3分加6分仅9分，国家级5分加4分也仅9分。未来推免规则和截图中“CSD”等收录口径要向学院核实；普通期刊、软著和专利不自动按该页获得科研分。

## 可延伸的研究路线

第一优先级为跨工况与跨负载迁移。在标定和单区段验证完成后，增加健康负载档位，以整档压力、负载或日期作为留出单位，比较冻结参照、压力归一化与少量健康重标定，报告检出边界和重标定成本。它能利用现有台架深化论文，但新增样本及跨负载验证不属于现有480次噪声回放。

第二优先级为多支管共同供压扰动与局部异常区分。需要至少两实际节点、公共供压参照、时间对齐和补充经费，再检验共性变化判别及无线竞争下的告警公平性。第三方向为长期维护前后配对研究，必须有真实复测与维护记录。后续是否推进取决于测量、标签和资源质量；云平台、太阳能与自动阀控不代替上述研究问题。

## 预算和人力约束

2000元为启动额度估计，未收到整体报价或资助证明。暂分电子/LoRa260、两压力及流量/调理900、水路材料400、供电/外壳200、耗材记录100、调研返工140，合计2000；前提是已有电脑、可借参考仪器及可调连续水源。两压力采购额度约680元是控制额度，非厂家报价。报价超额或水源不能借用时须增加经费或落实合格借用，不能承诺2000元独立覆盖全部实物。论文费用、高精度参考仪器和多节点不含在内。

节点候选为STM32F103C8T6、两路MPM489 K200表压、SEN0549流量、ADS1115及microSD，LoRa为E220-400T22D×2，接收端USB-TTL连接已有电脑。压力型号须核对0—200kPa、4—20mA及对应目录精度，不能按系列名称默认选对规格。传感器项差压界限1kPa不等于整机精度。另做24组设计计算后，A支路候选负载流量1.85—4.34L/min，模型最大双支路流量7.95L/min；工作点、真实压损、时间窗和连续供水能力仍需标定。原480次试验保持原参数。

目前只确认负责人会焊接，编程、团队及可借条件未确认。建议3人实际分工为系统/实验、嵌入式/LoRa、数据/网页，导师负责研究和实验把关，最终以真实成员填报。软件和仿真由辅助工具生成，不等于团队已独立掌握；提交前需能解释、复现和修改核心代码。
