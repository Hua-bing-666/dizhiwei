## 1.2 技术口径类（本轮新查出的硬伤）

### ★ H1（新查）改差压测量后，原有「±0.5kPa/路、最不利 1kPa」的整套表述失效

3.5(1) 的论证建立在"两只表压变送器相减"上。**一旦改成差压变送器（解决 A1 的必然结果），这段的误差链、共模误差、通道间偏差对照全部要重写**：

- 「单路压力标称误差界限 ±0.5kPa」→ 不再适用（改后是单一差压通道，误差为 ±(0.5%FS × 量程)）
- 「两路最不利差压界限 1kPa」→ 不再适用
- 「增加两个压力通道的共同压力对照以量化通道间偏差」→ 若改差压方案，这一步骤**失去对象**
- 但**静压影响**成为新的误差项（差压变送器在高压侧静压下的零点偏移），必须补进标定

> **这是上一版计划遗漏的连带影响**：换传感器不是换个型号，是把 3.3.2(2)、3.3.2(3)、3.4.2(1)、3.5(1) 四处一起改。

### ★ H2（新查）流量计自身压损与 5% 信号同级，且位置在 P1 下游

流量计 Q 装在 P1 下游。其自身压损会叠加到 A 支路总阻力上：

| 项 | 数值 |
|---|---|
| 5% 流量变化对应的差压信号 | 0.51 — 1.03 kPa |
| 小口径涡轮表典型压损 @3L/min | 0.5 — 2 kPa |
| 高阻力型表压损 | 3 — 10 kPa |

**流量计压损比要检测的信号大 0.5—10 倍。** 后果有两个：占用供压余量、压缩受限元件 R 的可调范围；若压损随流量非线性，会混入 `R̂` 的估计。

> 3.3.3 只提了"流量计压损是否改变 P1 与总流量关系需核对"，**未把它提升为必须实测的标定项**。要求：**把「压损—流量曲线」写入标定记录，作为 `R̂` 估计的已知分量扣除。**

### ★ H3（新查）受限工况 R=8 时压降达 18—72kPa，超出 3.3.3 的水力假设范围

按 `ΔP=R·Q²`，R=8 且 Q=2.5—3.0 L/min 时，区段压降为 **50—72 kPa**，而健康态只有 5—7.5 kPa。

- 此时「P1 仍能维持 80—160kPa」的假设不成立（供压大量消耗在受限段）
- 3.3.3 只给了 R 的取值范围，**未给出该范围内的供压自洽性检查**，即"R 能加到多大而不使 P1 跌出工作区"

> 要求：在 3.3.3 补一段**工作区边界计算**：给定供压 P_s 与共同阻力 Rc，求 R 的上限使 P1 ≥ 下限（如 30kPa）。**把"R 由 0.8 增至 8"改为"R 由 0.8 增至经验证的工作区上限"。**

## 2.3 全文语言统一规则（改稿时逐条套用）

1. 「仅」→「单」（仅凭流量 → 单看流量）
2. 「难以」→「不易」或直接说条件
3. 「尚未」「尚缺」→「将在」「下一步落实」
4. 「需要指出的是」「需要注意的是」→ 直接陈述
5. 「无法保证」→ 改为具体范围（「在本期台架条件下…」）
6. 「局限」→「适用边界」「适用范围」
7. 「失败分支」→「条件判定与处理方式」
8. 所有"预期/目标"统一用「目标为」「预期达到」，禁止完成时表述

# 第四部分　项目实现路线（怎么把这个大创做出来、做完）

> 这一部分回答"**咋实现、咋完成**"。核心判断：**这个项目的成败不在算法，在三件事——测量链能否分辨目标信号、台架能否复现故障、实验能否被独立核验。**

## 4.1 实现主线（一张图）

```
        ┌── 测量可行吗？ ──┐
        │  差压能否分辨 5% │ → 不能则降低目标程度（5%→10%）
        └────────┬─────────┘
                 ↓ 通过
     ┌── 台架能否复现故障？ ──┐
     │ 泄漏量独立计量、受限可调 │ → 不能则换元件/换测点
     └────────┬───────────────┘
              ↓ 通过
   ┌── 判据能否区分正常与故障？ ──┐
   │ 阈值扫描出性能边界            │ → 边界太窄则改判据（多元/频域）
   └────────┬──────────────────────┘
            ↓ 通过
  ┌── 告警能否可靠送达？ ──┐
  │ 真实LoRa + 整机电流     │ → 不能则如实报告适用条件
  └────────┬────────────────┘
           ↓ 通过
     ┌── 能否形成可复核闭环？ ──┐
     │ 事件贯穿采集→核查→复测   │ → 验收与结题
     └──────────────────────────┘
```

**关键设计**：每一关都设"不通过怎么办"，**任一关不通过都不停止项目，而是收窄结论**——这是保证能按时结项的核心机制。

## 4.2 五道关卡的实现方法（正推＋反推）

### 关卡 A：测量可行性（2026.11 — 2027.2，提前做，成本约 150 元）

| 项 | 内容 |
|---|---|
| **目标** | 确定差压通道能否分辨目标信号 |
| **做法** | 买 1 只差压传感器 + 量筒，接自来水，用球阀当受限元件，手动改变阻力，记录 P0/P1/流量 |
| **正推** | 若能分辨 → 5% 纳入正式目标 |
| **反推** | 若不能（不确定度 ≥ 信号）→ **把正式目标从 5% 退到 10%**，并把 5% 写成边界情形 |
| **验收** | 得到实测不确定度数值与"变化/不确定度"比值 |
| **为什么提前** | 这是唯一一件"不做就会白干一年"的事；且**不需要任何其他条件就能开始** |

### 关卡 B：台架与标定（2027.3—4）

| 项 | 内容 |
|---|---|
| **目标** | 台架能复现两类故障，且独立计量可信 |
| **做法** | 搭 A/B 双支路；压力 ≥5 点双向标定（每点 ≥3 次）；流量容积/称重校核 ≥5 点；**流量计压损曲线实测**；受限元件 R 的工作区上限实测 |
| **正推** | 标定残差 < 目标信号的 1/2 → 进入实验 |
| **反推** | 残差过大 → 改量程/改布点/提高故障程度，重标定后再做 |
| **验收** | 标定曲线、残差、压损曲线、工作区边界四项齐备并归档 |
| **这是项目的第一个真门槛** | 3.4.2(1) 已写好，只需把压损项补进去 |

### 关卡 C：判据与实验（2027.5—6）

| 项 | 内容 |
|---|---|
| **目标** | 给出判据的性能边界，而不是一个点 |
| **做法** | 54—72 次独立操作；关键档位加密；**同时报告误报率（次/小时）、检出概率、提前量、最短可检时长** |
| **正推** | 15% 与 10% 达标 → 按计划写论文 |
| **反推** | 只有 15% 达标 → 论文主贡献改为"**测量边界研究**"（这本身就是贡献） |
| **验收** | 性能曲线图 + 独立操作级数据表 + 失败案例清单 |
| **老实话** | 若三种程度都不达标，项目退化为"**测点与量程的适用性研究**"，仍可结项（有实物、有数据、有报告） |

### 关卡 D：通信与联调（2027.7—8）

| 项 | 内容 |
|---|---|
| **目标** | 事件真的能从节点走到平台，延迟与丢失有实测数字 |
| **做法** | 36 次链路对照（4 策略 × 3 条件 × 3 批次）；≥8 小时连续记录；≥3 次重启恢复；**整机电流实测** |
| **正推** | 事件策略省通信且及时 → 支撑备线 B |
| **反推** | 省包不省电 → 只报告"通信开销"结论，不报节电比例 |
| **验收** | 发收日志、时钟校核、电流记录、8 小时无缺口记录 |

### 关卡 E：成果与结项（2027.9—2028.2）

| 项 | 内容 |
|---|---|
| **目标** | 形成可交付、可复核、可结项的成果包 |
| **做法** | 留出批次验证 + 消融；论文初稿；软著材料；结项报告 |
| **验收** | 按任务书逐项对照；原始记录与版本可追溯 |
| **兜底** | 论文录用不影响结项；实物 + 数据 + 报告构成结项依据 |
