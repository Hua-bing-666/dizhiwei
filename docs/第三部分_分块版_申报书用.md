# 一、场景与目标（项目内容·项目目标）

## 1.1 对应申报书要素

项目内容的应用场景、项目目标的量化表述、系统边界。

## 1.2 方案内容

1. **应用场景**：南疆棉田膜下滴灌，支管层（分干管 → 支管 → 毛管三层中的分配环节）。锚定数据：一师阿拉尔市已建成田间自动化控制灌溉 25 万亩；轮灌周期 72 h 完成一轮全覆盖；单支管一次灌水 0.4—1.8 小时。轮灌切换 1—5 分钟一次、末端压力衰减 1—8 分钟，是天然的强干扰背景——这正是本项目把「轮灌扰动写进实验设计」的立论点。
2. **项目目标（可量化）**：在双支路清水台架上实现支管早期故障的原型闭环——
   - 目标一（测量）：差压测量链不确定度 U ≤ 0.20 kPa，压住 +2% 边界幅度（需求 ≤ 2.0 kPa，余量 11 倍）；
   - 目标二（诊断）：演示参照档 10%/15% 故障在 80 s 注入窗内检出率 ≥95%、正常确认误报 ≤1 次/小时（台架口径）；
   - 目标三（系统）：LoRa 事件链路先落库后 ACK，重复帧/乱序帧/丢 ACK 三反例全部通过；
   - 目标四（成果）：独立操作级数据集 + 论文初稿 + 软著 + 可运行原型，保底档不依赖田间。
3. **系统结构**：感知诊断节点（P0/P1/Q）→ E220 LoRa → USB-TTL 接收端 → PC 接收服务（SQLite 先落库后 ACK）→ 本地 Web 六模块 → 巡检闭环（告警 → 人工查看 → 现场处置 → 同工况复测 → 归档）。
4. **边界（如实列入申报书）**：只做「支管下游等效泄漏」与「测点区段等效受限」两类故障；单滴头定位、自动阀控、云平台、太阳能、多节点组网、水质监测、水锤列入后续扩展；「节流不证明真实滴头堵塞」。

# 二、测量与采集（硬件方案）

## 2.1 对应申报书要素

项目内容中的硬件方案、测点布置与器件选型。

## 2.2 方案内容

1. **测压**：单只差压变送器（**35—40 kPa 档 / ±0.5%FS**，U ≤ 0.20 kPa）直接测区段压降 + 一只 0—200 kPa 干管参照表压（两线制 4—20 mA）。相比两表相减，量程/信号比从 20—40 倍降到 4—8 倍。
2. **主控**：**GD32F103CBT6**（128 KB Flash / 20 KB SRAM）。约束来自脉冲计数连续性（只能 SLEEP @8 MHz ≈ 4 mA，不能 STOP）与 Flash 容量（固件含 FatFs）。
3. **ADC**：**SGM58031**（16 位 I²C），PA0 采 ΔP、PA1 采 P1。
4. **流量**：SEN0549 电磁式流量计（0.3—5 L/min，540 脉冲/L，±1%，NPN 脉冲），PB6/TIM4_CH1 计数（避开 SPI1_MISO PA6）。
5. **供电**：电池直降 5 V/3.3 V 供连续负载；24 V 由 XL6009 单独升压、高边开关（控 EN）仅供两线制变送器；上电建立时间 T_set 台架实测（100/200/300 ms ⇒ 续航 10.2/7.2/5.5 天）。
6. **采样契约**：1 s 提交 + 10 s 判据窗（固件 `end_ms=(t+1)*1000` 锁死；1 s 窗脉冲量化 ±3.8% 不足以检 5%，10 s 窗 ±0.38%、信噪比 13.2）。
7. **水路安装顺序（不可调换）**：`流量计 → 取压嘴A → 区段R（φ5.0 孔板 + 针阀）→ 取压嘴B → 泄漏球阀`；两取压嘴都在流量计下游 ⇒ ΔP 只含区段阻力。
8. **BOM**：18 项 **2409—5018 元**（含天线/RTC/防反接/高边开关/PCB/孔板/电平整形等八项漏项），专项额度 6300 元，余量 ≥20%。

### 2.2a 台架构成与关键参数

双支路清水台架的物料与参数全部来自 BOM v2.2（13—18 项）与水力核算：

- **管路**：De25 PVC-U（外径 20 / 内径 16 mm），配球阀、活接、三通与回水管路；
- **测量支路（A 支路）**：按冻结顺序装配 `流量计 SEN0549 → 取压嘴A → 区段R（可换孔板 φ5.0 mm + 针阀）→ 取压嘴B → 泄漏球阀`。区段 R 为 30—50 cm 短管——光管在 2.9 L/min 下压降不足 0.1 kPa，健康态 ΔP 需约 7—8 kPa，因此段内必须内置 φ5.0 mm 可换孔板充当等效支管阻力（2.76 L/min 下理论 ΔP ≈ 8.0 kPa）；**受限故障用针阀连续调节**（孔板定量受限需孔径精确到 4.82 mm，不可控）；
- **扰动支路（B 支路）**：B 切换阀 + B 正常负载，只复现"隔壁轮灌组开关"的正常扰动，不注入故障；
- **计量**：开口容器（内腔 r = 60 mm、h = 60 mm，几何容量 678.6 mL）+ 量筒/电子秤（优先借用），泄漏真值用称重/容积法独立计量；
- **供电**：24 V 适配器 + XL4015/MP2359 两级降压 + XL6009 高边开关（仅供两线制变送器）。

# 三、建模与标定（健康参照）

## 3.1 对应申报书要素

技术路线中的模型结构与标定方法。

## 3.2 方案内容

1. **模型结构**：`Q = C·P1^n`（负载特性）与 `ΔP = R·Q²`（区段阻力）；特征 `K = Q/√P1`、`Rh = ΔP/Q²`；比值结构把共同供压/流态波动抵消（原始通道 ACF(1)=0.984，块级残差 lag1 ≈ −0.014）。
2. **标定流程**：前 16 个 10 s 块为标定窗；指数 log-log 回归、水平中位比值定标；健康参照与故障段严格分离。
3. **可辨识性**：单工况内 P1 跨度仅 0.34%，指数回归 −1.46—−0.19 跳变 ⇒ 固定 n=0.5；跨度 ≥20% 才开拟合（写成方法步骤，不是缺陷）。
4. **参数核实**：反推 R=0.7928、C=0.2799、n=0.4914，与设计值 0.8 / 0.28 / 0.5 一致。

### 3.2a 模型与判据的数学表达

支管水力模型与判据的完整数学表达如下（符号与正文一致）：

- 负载特性：`Q = C·P₁ⁿ`；区段阻力：`ΔP = R·Q²`；
- 比值型特征：`K = Q/√P₁`（负载系数），`Rh = ΔP/Q²`（区段阻力）——共同供压波动在比值中相消；
- 块平均：第 m 块的块均值 `x̄ₘ = (1/10)·Σ x(t)`，t 取该块内 10 个 1 s 采样点；
- CUSUM 递推：`Sₘ = max(0, Sₘ₋₁ + zₘ − k)`，其中 zₘ 为第 m 块特征相对健康参照的标准化偏移，k = 0.5；判决规则：`Sₘ > h` 即产生持续候选，h 按目标误报率反推（仿真基准 h\* = 26.0：6720 块健康观测零越限）；
- 可辨识性判据：标定段 P₁ 压力跨度 < 20% 时指数 n 不可辨识，固定 n = 0.5；跨度 ≥ 20% 时由 log-log 回归给出 n 及其置信区间。

# 四、判据与验证（诊断边界）

## 4.1 对应申报书要素

技术路线中的判据算法、性能指标与验证方法。

## 4.2 方案内容

1. **判据**：10 s 不重叠块（块内算术平均）+ CUSUM（k=0.5，每块累积一次）。不重叠的理由：逐点判据相邻样本共享 90% 原始数据，有效样本数被高估，门限被高估约 57 倍。
2. **门限**：按目标误报率反推（健康段 160 条 × 42 块 = 6720 块观测）。冻结值 h\*=26 为**仿真基准**（FAR≤1% 目标实测 0.00%，ARL0 > 6.2 h @95%）；实物门限由台架实测噪声重标后冻结。
3. **注入口径**：泄漏 → K 增大、Rh 不变；受限 → Rh 增大、K 不变；噪声结构原样保留。
4. **可检边界（80 s 注入窗，仿真基准）**：泄漏 +2% 为下限（+1% 33/40、+2% 40/40）；受限 +50% 40/40；幅度 +30% 的受限 80 s 窗仅 32/40，需 ≥5 min 累积。
5. **精度需求**：+2% 边界幅度下 U ≤ 2.0 kPa 达标；设计工况 U ≈ 0.175 kPa，余量 11 倍。
6. **台架必测四项**（全绿才把仿真边界写入结项报告）：σ_gp/σ_dp/σ_q（门限重标）、τ（≤10 s 直接用块判据，否则加长块长或预白化）、K 漂移（≤1%/h，超限启用自适应基线可翻倍至 2%/h）、流量计长期稳定性（称重法，Q 通道增益漂移全程 ≤0.10%）。
7. **申报口径**：演示参照档 10%/15%；5% 作为测量与辨识边界的挑战档。

# 六、实验与成果（实验方案·要解决的主要问题）

## 6.1 对应申报书要素

实验方案、预期成果、要解决的主要问题。

## 6.2 实验方案

1. **主矩阵**：2 类型 × 3 供压 × 3 程度 × 3 操作 = **54 次**，扩展至 **72 次**；每类配置独立标签，标签不输入检测规则。
2. **对照三件套**：健康段、供压扰动、邻支路切换（误报的真实来源）。
3. **切换期故障 12 次**：量化「切换期间暂停分类」丢弃故障的代价。
4. **真值计量**：泄漏量称重/容积法（10 L 桶 + 秤/量筒 + 秒表）。
5. **四工作包**：WP1 测量建模与台架 → WP2 诊断边界与独立对照 → WP3 可靠告警与接收服务 → WP4 软件集成与维护复测。
6. **三档结项**：保底（有线 + 台架 + 桌面端含 SD 导入）/ 标准（+电池 + LoRa + 手持终端）/ 加分（+田间一轮实测）。保底档即可结项。
7. **时间门槛（对齐执行期 2027.3—2028.2）**：G1 2027.3—4 测量可行（U 实测压不住边界信号 → 换传感器/换布点/上调演示参照档）；G2 2027.5—6 独立诊断（54+18+12 次操作标签独立记录）；G3 2027.7—8 无线联调（8 h 连续记录、3 次重启恢复、整机电流实测）；G4 2027.9—2028.2 论文与结项。

### 6.2a 单次注入操作规程（SOP）

每一次故障注入都按同一规程执行，保证台账可复算：

1. **健康段确认**：注入前先运行 ≥3 个 10 s 块，确认判据无候选、质量字正常，作为该次实验的健康基线；
2. **注入执行**：泄漏类开泄漏球阀至预定开度（旁路放水），受限类调节针阀至预定圈数（区段 R 内）；同时开始计时；
3. **窗口观测**：80 s 注入窗内记录节点判决输出（首越时刻、幅度估计）与原始 1 s 三通道行；
4. **真值计量**：泄漏用称重/容积法计量泄水量（对应时间窗内），受限记录针阀圈数与当时的 ΔP、Q 稳态读数；
5. **独立复测**：同一故障配置至少一次独立复现（重新调节、重新计时）；
6. **记录字段**：注入类型与幅度标签（标签不进入检测规则）、原始三通道、真值计量值、供压档、B 支路阀态、起止时间、复测编号。

对照实验（健康段 / 供压扰动 / 邻支路切换 / 切换期故障）按同一规程执行，仅把第 2 步替换为对应扰动操作。

## 6.3 要解决的主要问题

- **主线（研究问题 A——诊断边界）**：在多大测量误差、多大供压波动范围内，双测点方法（K/Rh）才开始优于单流量阈值？赢多少、在什么条件下输——把适用边界画出来就是贡献。已知反例：σ=10 kPa 下 K/R 泄漏仅 17/40；未知负载与泄漏三通道响应一致（ΔQ=+6.39%、ΔK=+7.07%、ΔRh=+0.08%），在 (P0,P1,Q) 下严格不可区分——这一原理性边界写进申报书，区分需阀态信号/邻支路流量/时序先验，属后续扩展。
- **备选（研究问题 B——通信取舍）**：同一本地判断下，事件上报对比周期上报省多少、慢多少；指标为告警延迟 P50/P95、期内送达率、重传率、缓存溢出缺口、实测整机电流。需真射频与电流计，作为第二作者内容或扩展方向。
- **主动写能力边界**（不可区分、τ 敏感、漂移容限 1%/h）是方法贡献，不是弱点。
