### 一、数值自洽性验证（能否"推出来"）

**基础参数**：`C = 0.28`、`R = 0.80`、三档供压 `80 / 120 / 160 kPa`。

| 环 | 检验内容 | 结果 | 判定 |
|---|---|---|---|
| 1 | 健康工况自洽（Q/√P1 是否恒为 C） | 三档均得 **0.2800** | ✓ |
| 2 | 差压量程与精度 | 最大健康压降 **9.33 kPa**，需量程 ≥14.0 ⇒ 选 20 kPa；信号/U = **9.7 / 14.5 / 19.4** | ✓ |
| 2b | 原方案对照 | 信号/U = 0.70 / 1.04 / 1.39，三档全 <2 | ✓（说明改差压的必要性） |
| 3 | 流量是否超量程 | 最大 **4.97 L/min**（160kPa+50%泄漏）≤ 5.0 | ✓（须注明 >50% 超程） |
| 4 | 受限工作区 | R=8 时 P1 = **98.3 kPa** ≥ 30；ΔP = 61.7 ≤ 160 | ✓ |
| 5 | 标定压力跨度 | 跨工况 **100%** ⇒ n 不确定度 0.014 ✓；单工况 0.256% ⇒ 不可辨识 | ✓ |
| 6 | 通道 / 静压 / 供电 | 2 路模拟（器件供 4 路）；耐静压 20 MPa；24V ≤40mA、5V ≈150mA、3.3V ≈81mA | ✓ |

**结论：可从基础参数一路推到器件选型与实验设计，各环自洽，无断链。**

### 二、与实际仿真数据反推比对

|---|---|---|---|
| 区段阻力 `R = ΔP/Q²` | **0.8004** | 0.80 | ✓ 吻合 |
