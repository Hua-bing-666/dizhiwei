# 滴智卫桌面版 V1.3 验收记录

2026 年 10 月 7 日。本轮交付 Windows x64 的便携文件夹与单文件 EXE。参考用户提供的“智水生态系统.exe”实际界面和配套报告，完善状态共享、交互图表、模型测点和桌面操作。申报书保持用户当前文件，C 诊断配置仍为 `20261007-platform-c-v1`。

## 参考如何落实

参考程序的三维、视觉与预测页面围绕公共状态展开，硬件操作与模型、图表与解释分别并排展示。滴智卫采用其中的状态组织和交互层级：八个页面读取同一会话，监测和台架显示相同的 P0、P1、Q；事件核查保留独立记录，历史查询不切换当前会话。三维聚焦只改变相机和选中部件，207 个构件及其几何保持原样。水族 ODE、视觉模型、参数、界面图片和源代码没有复制到本项目。

[Fluent UI](https://github.com/microsoft/fluentui) 用于参考控件层级、状态和焦点；[Apache ECharts](https://github.com/apache/echarts) 6.0.0 用于本地交互图表；[pywebview](https://github.com/r0x0r/pywebview) 继续承载 WebView2 与原生保存窗口。图表库来源、版本和摘要保存在 `scripts/vendor/echarts/provenance.json`，LICENSE、NOTICE 随两种程序分发。three.js 许可证保留在模型 HTML 中，Python 依赖许可证随包保存。

## 用户体验处理

默认界面删除重复的工作区介绍、页脚协议说明、指标解释长句、重复版本装饰和无操作价值的提示。诊断阈值、协议、设备配置、实验条件与模型尺寸边界按需展开。合成来源、单位、缺测、异常候选及软件控制标识保留，避免精简造成数据误解。

自动回放逐个处理 1 秒 C 样本，10× 仅表示播放速度；推进过程不弹出保存消息。新建会话、主动控制、文件保存和错误提供反馈。桌面自动连接后隐藏离线切换入口；历史状态下保留“新建会话”提示。重复双击返回已有窗口，保留窗口大小。外观和时间范围保存到独立的偏好文件，不修改诊断配置。
