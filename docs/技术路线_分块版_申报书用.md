# 一、现场与场景

## 1.1 目标

把监测对象、故障类型和系统形态一次钉死，使后续所有环节有同一张底图。

## 1.2 做法

1. **监测对象取支管**。南疆棉田膜下滴灌管网为分干管 → 支管 → 毛管三层；支管是干管向田间的分配环节，「一处故障影响一片地」，且其管径与流量档与室内台架可比。
2. **用本地公开数据锚定场景**：一师阿拉尔市已建成田间自动化控制灌溉 25 万亩；轮灌周期 72 h 完成一轮全覆盖；单支管一次灌水 0.4—1.8 小时。这三项是实验设计与工况分档的直接输入。
3. **系统形态**：一个 P0/P1/Q 感知诊断节点 + 一个 LoRa 接收端 + 现有 PC 上的接收服务与本地 Web + 双支路清水台架。节点保存原始采样、质量与工况信息，计算候选模式并持久化事件；接收端只桥接无线字节；PC 校验去重、SQLite 提交成功后回 ACK；Web 分别记录人工「已查看 / 处置 / 同工况复测」。
4. **故障只定义两类**：支管下游**等效泄漏**（旁路放水复现）与测点区段**等效过流受限**（孔板 + 针阀复现）。两类故障都有明确的物理注入手段，保证实验可复现、可计量。
5. **本期不做**：单滴头定位、自动阀控、云平台、太阳能、多节点组网、水质监测、水锤。这些列入结项报告「后续扩展」，不占本期资源。

## 1.3 交付物

- 场景表一份：管径、设计流量、工作压力、轮灌周期、单次灌水时长，五项全部带出处。
- 故障定义与注入手段对照表一份。
- 系统总体结构图（`deliverables/系统总体结构_单色学术版.svg`）。

## 1.4 验收标准

| 编号 | 标准 | 证据形式 |
|---|---|---|
| A1-1 | 场景表五项每项有可查出处，零「估计值」 | 场景表 + 出处链接/文献号 |
| A1-2 | 两类故障与注入手段一一对应（针阀/孔板 → 受限；旁路 → 泄漏） | 对照表经导师签字确认 |
| A1-3 | 申报书写明「节流不证明真实滴头堵塞」 | 申报书正文原文 |
| A1-4 | 「不做清单」在申报书中如实列出 | 申报书正文原文 |

**未达标处置**：场景表任一项无出处 → 该项降级为「待实测参数」并从申报书正文移除；故障定义被导师质疑 → 回到本块重新收敛，不进入环节二采购。

# 二、测量与采集

## 2.1 目标

用最少的传感器把「区段阻力变化」与「负载变化」分开测出来，并给出采样契约的量化依据。

## 2.2 做法

1. **测压架构**：单只差压变送器直接测区段压降 + 一只干管参照表压。差压取 **0—40 kPa 档 / ±0.5%FS**（厂家最小标准档，订货号 K040，U ≤ 0.20 kPa），干管参照 0—200 kPa（两线制 4—20 mA）。量程/信号比从两表相减方案的 20—40 倍降到 **4—8 倍**。
2. **主控与 ADC**：主控 **GD32F103CBT6**（128 KB Flash，按 128 KB Flash / 20 KB SRAM 规划）；ADC **SGM58031**（16 位 I²C），3.3 V 供电。
3. **流量**：SEN0549 脉冲流量计（540 脉冲/L），定时器连续计数。计数连续性要求 MCU 只能进 SLEEP、不能进 STOP。
4. **采样契约**：**1 s 提交 + 10 s 判据窗**。依据：1 s 窗脉冲量化误差 ±3.8%，不足以检 5% 级故障；10 s 窗降到 ±0.38%，信噪比 13.2。契约写入固件（`end_ms=(t+1)*1000` 锁死）。
5. **供电时序**：24 V 走高边开关（控 XL6009 EN）；采样窗内上电、读完即断电，断电期间 ADC 不采样。上电建立时间 T_set 由台架实测，实测值决定续航（100/200/300 ms ⇒ 10.2/7.2/5.5 天）。
6. **水路安装顺序（不可调换）**：`流量计 → 取压嘴A → 区段R（φ5.0 孔板 + 针阀）→ 取压嘴B → 泄漏球阀`。两个取压嘴都在流量计下游，ΔP 只含区段阻力，流量计压损被完全排除。

## 2.3 交付物

- 18 项 BOM（**2409—5018 元**，含天线/RTC/防反接/高边开关/PCB/孔板/电平整形等八项漏项），余量 ≥20%。
- 双支路水路图（`application/figures/quality_review/water_layout.png`，安装顺序已按冻结契约标注）与采集接口图（`measurement_interfaces.png`）。
- 差压小试报告：标定曲线、实测不确定度、T_set。

## 2.4 验收标准

| 编号 | 标准 | 证据形式 |
|---|---|---|
| A2-1 | 差压小试实测 U ≤ 0.20 kPa（参考表三点比对） | 小试报告 + 原始记录 |
| A2-2 | 厂家书面确认量程档与精度档；系列名不作为订货依据 | 书面报价/规格函 |
| A2-3 | T_set 实测值写入续航表，三档电流按实测修订 | 续航计算表 v2 |
| A2-4 | 台架装配后按水路顺序逐项核对并拍照存档 | 装配检查单 + 照片 |
| A2-5 | 固件 1 s 提交节拍与契约一致（连续 1 h 无漂移） | 固件日志 |

**未达标处置**：A2-1 实测 U 超标 2 倍以内 → 复核标定流程后重测；超 2 倍 → 触发改型评审（换量程档 / 换布点 / 上调演示参照档），评审记录归档后才继续采购。

# 三、建模与标定

## 3.1 目标

给「健康」一个可复现的基准，并说清这个基准的适用范围。

## 3.2 做法

1. **结构**：支管水力用两条稳式——`Q = C·P1^n`（负载特性）与 `ΔP = R·Q²`（区段阻力）。构造两个比值型特征 `K = Q/√P1`、`Rh = ΔP/Q²`；共同供压/流态波动被比值抵消（原始通道 ACF(1)=0.984，块级残差 lag1 ≈ −0.014）。
2. **标定**：前 16 个 10 s 块作标定窗；指数由 log-log 回归得到，水平由中位比值定标（增益恒为 1，避免用增益补偿错误的指数）。
3. **可辨识性结论**：单工况内标定段 P1 跨度仅 0.34%，指数回归在 −1.46—−0.19 间跳变 ⇒ **默认固定 n = 0.5**；跨多档供压且压力跨度 ≥20% 时才开拟合。
4. **参照独立性**：健康参照只用独立健康轨迹拟合；标定种子与监测种子分离；待监测的故障段一律不参与标定。
5. **参数核实**：从数据反推 R=0.7928、C=0.2799、n=0.4914，与设计值 0.8 / 0.28 / 0.5 一致。

### 3.2a 模型与判据的数学表达

- 负载特性：`Q = C·P₁ⁿ`；区段阻力：`ΔP = R·Q²`；
- 比值型特征：`K = Q/√P₁`、`Rh = ΔP/Q²`——共同供压波动在比值中相消；
- 块平均：`x̄ₘ = (1/10)·Σ x(t)`（块内 10 个 1 s 采样点）；
- CUSUM 递推：`Sₘ = max(0, Sₘ₋₁ + zₘ − k)`，k = 0.5；`Sₘ > h` ⇒ 持续候选（仿真基准 h\* = 26.0）；
- 可辨识性：标定段 P₁ 跨度 < 20% ⇒ 固定 n = 0.5。

## 3.3 交付物

- 可辨识性分析脚本与结果（`simulation/project_review/ident.py`、`results/identifiability.txt`）。
- 健康参照标定流程一页纸（后续台架直接执行）。

## 3.4 验收标准

| 编号 | 标准 | 证据形式 |
|---|---|---|
| A3-1 | 标定段跨度 <20% 时，全部文档写「固定 n=0.5」及理由，无「拟合得到 n」表述 | 全文检索零命中 |
| A3-2 | 台架跨 ≥20% 压力跨度复拟合一次，给出 n 的置信区间 | 标定报告 |
| A3-3 | ≥8 h 静置实测 K 通道漂移速率，作为参照是否自适应的依据 | 静置日志 + 报告 |

**未达标处置**：A3-2 跨度仍不足 → 增加供压档位重测；两次仍不足 → 固定 n=0.5 为最终写法，置信区间一栏填「不可辨识（跨度不足）」，不虚构。

# 四、判据与验证

## 4.1 目标

给出误报率与可检边界的定量结论，并把「仿真结论变实物结论」要补的四个测量一次性列清。

## 4.2 做法

1. **判据结构**：**10 s 不重叠块**（块内算术平均），CUSUM 每块累积一次，k=0.5。改不重叠的依据：逐点判据使相邻样本共享 90% 原始数据，有效样本数被高估，门限被高估约 57 倍。
2. **门限来源**：由目标误报率反推，健康段 160 条 × 42 块 = 6720 块观测。冻结值 **h\*=26**（仿真基准：目标 FAR≤1%，实测 0.00%，Rule-of-Three 95% 下界 ARL0 > 6.2 h）。实物门限由台架实测噪声重标后冻结。
3. **注入口径**：泄漏 → K 增大、Rh 不变；受限 → Rh 增大、K 不变；噪声结构原样保留，amp=0 严格还原。
4. **可检边界（80 s 注入窗，仿真基准）**：泄漏 **+2%** 为下限（+1% 33/40、+2% 40/40）；受限 **+50%** 40/40；幅度 +30% 的受限在 80 s 窗仅 32/40，需 ≥5 min 累积。
5. **精度需求**：+2% 边界幅度下 U ≤ 2.0 kPa 仍达标；设计工况 U ≈ 0.20 kPa，余量 10 倍。
6. **申报口径**：泄漏/受限演示参照档 **10% / 15%**；5% 作为测量与辨识边界的挑战档，不预先承诺全部检出。

## 4.3 交付物

- E9/E10 结果文件（`results/E9_block_threshold.txt`、`results/E10_robustness.txt`）。
- 两张关键图：`threshold_separation.png`（图B）、`detection_boundary.png`（图C），2026-10-17 已重绘为窄幅（宽 7.6 in，A4 纵向放置最小字号 9.98 pt）。

## 4.4 验收标准（台架必测四项，全绿才允许把仿真边界写入结项报告）

| 编号 | 必测项 | 通过标准 | 未达标处置 |
|---|---|---|---|
| A4-1 | 各通道独立传感器噪声 σ_gp / σ_dp / σ_q | 实测值代入后复扫 6720 块，FAR ≤1% | 门限按实测重标并冻结新版 |
| A4-2 | 噪声时间常数 τ | τ ≤ 10 s 直接用块判据 | τ > 10 s → 加长块长 W 或对块残差预白化，重标门限 |

# 五、通信与平台

## 5.1 目标

事件可靠送达、原始数据可复查，射频合规且功耗最低。

## 5.2 做法

1. **无线合规**：E220-400T22D，发射功率设 **≤10 dBm**（433.05—434.79 MHz 免执照限值 10 mW e.r.p.；模块标称能力为限值的 16 倍，设置值与依据条款留档）。
2. **帧格式**：事件帧 **55 / 57 B**、ACK **24 B**（第七轮后 v2）。事件帧 ≤ 64 B，可整包发送。
3. **可靠性**：接收端先落库后 ACK；重发复用原身份；重复帧按身份去重；事件身份与快照绑定，同源不同内容直接拒绝。
4. **离线通道**：节点同时把 1 s 原始行写入 SD 卡；回实验室用 CLI（`scripts/import_sdcard_csv.py`）或 HTTP（`/api/sdcard/import`）导回桌面端。**该链路 2026-10-17 已打通并测试通过。**
5. **本地 Web**：总览、支管监测、异常事件、设备链路、历史记录、设置六模块；人工「已查看 / 处置 / 同工况复测」三态分别落库。

## 5.3 交付物

- SD 卡导入链路文档（`docs/SD卡CSV导入链路.md`）与持久化时序图（`durable_event_sequence.png`）。

# 六、实验与成果

## 6.1 目标

用可复现的实验矩阵回答「误报从哪来、边界在哪里」，并交出不依赖田间的结项成果。

## 6.2 做法

1. **实验矩阵**：基础网格 2 类型 × 3 供压 × 3 程度 × 3 操作 = **54 次**，扩展至 **72 次**；每类配置独立标签，标签不输入检测规则。
2. **对照三件套**：健康段、供压扰动、邻支路切换——它们才是误报的真实来源，缺一不可。
3. **切换期故障**：12 次在轮灌切换期间注入，专门量化「切换门控丢弃故障」的代价。
4. **真值**：泄漏量称重/容积法独立计量（10 L 桶 + 秤或量筒 + 秒表），不靠模型反推。
5. **四工作包**：WP1 测量建模与台架 → WP2 诊断边界与独立对照 → WP3 可靠告警与接收服务 → WP4 软件集成与维护复测。系统集成是结项必做；测量边界与诊断比较形成主论文候选。
6. **三档结项**：保底（有线采集 + 双支路清水台架 + 桌面端含 SD 卡导入）；标准（+电池供电 + LoRa + 手持巡检终端）；加分（+田间一个灌溉季一轮实测）。保底档即可结项，加分项不挤占基础验证。
7. **原理性边界（写进申报书与论文）**：`load_unknown` 与 `leak` 三通道响应完全一致（ΔQ=+6.39%、ΔK=+7.07%、ΔRh=+0.08%）⇒ 在 (P0,P1,Q) 三测点下「下游负载自身变化」与「等效泄漏」严格不可区分；区分需阀态信号、邻支路流量或时序先验，属后续扩展。

## 6.3 交付物

- 独立操作级数据集（每次注入：标签、原始三通道、真值计量、复测记录）。
- 论文初稿（目标 Sensors / CEA）、软著申请、结项报告。
- 全部结论口径统一为「台架验证，田间外推受限」。

## 6.4 验收标准

| 编号 | 标准 | 证据形式 |
|---|---|---|
| A6-1 | 每次注入有独立标签与复测记录；同一故障至少一次独立复现 | 实验台账 |
| A6-2 | 对照三件套各成组入库，误报统计分来源报告 | 数据集 + 统计表 |
| A6-3 | 论文/软著/竞赛三类成果分别登记，不互相顶替 | 成果登记表 |
| A6-4 | 原理性边界（不可区分）写入申报书与论文 | 正文原文 |
| A6-5 | 风险触发线三条在案：测量不足先调量程/可检程度；报价超帽或水源不可借先重编经费与任务；未知负载与泄漏同形时保留「异常待检查」，不用复杂模型宣称消除信息不足 | 风险登记表 |

**未达标处置**：实验矩阵任一单元连续两次失败 → 停止扩格，先把失败原因写进台账并请导师复盘；复现缺失的单元不计入统计。
