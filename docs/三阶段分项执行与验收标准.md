# 三阶段分项执行与验收标准

2026年10月4日。适用项目为基于 LoRa 的南疆滴灌支管道早期故障诊断物联网原型系统。本文件把总规划展开到具体产物与检查项，当前先执行申报阶段。以下数字是本项目的内部交付要求或拟定实验规模，除明确引用学校文件外，不代表学校统一评分标准，也不表示已经达到性能。

## 一 总目标和固定约束

成果目标为完成一个大创项目并形成一篇有实际研究贡献、符合未来学院认定条件的第一作者论文，争取科研类成绩10分。按用户提供的今年表格，省级第一完成人4分加符合条件的6分论文可达10分，国家级5分加6分论文按上限10分计；级别、结项、发表、收录和学院认定分别记录。未来年度规则须核实，不能保证满分。

题目和基础配置固定为一个P0/P1/Q感知诊断节点、一个LoRa接收端、双支路清水台架、现有电脑上的本地Web。研究对象是等效泄漏与等效受限，位置只到监测支管及两压力点包围区段；不定位单滴头，不从节流推出化学或生物堵塞机理。B支路为正常共同负载扰动，不作为第二监测节点。

实施期采用用户确定的2027年3月至2028年2月，学校批次周期以获批任务书核定。2000元是启动估算，参考仪器、可调水源和电脑借用为前提；正式申请经费按本批规则和实际报价核定，不把自筹额度写成学校已资助金额。仅确认负责人会焊接，人员、固件能力、场地、参考仪器及田间许可未落实。

新增任务应满足三项条件：直接支持一个研究问题，有独立可检查的产物，资源和时间可承担。多节点、云端、太阳能、自动阀控和正式田间故障试验按条件扩展；优先增加标定质量、独立操作和对照，不增加展示性功能。

## 四 当前申报阶段的逐项标准

每项交付都要有源文件、版本、证据类型、实际检查记录和未解决项。状态使用未开展、已有待审、部分通过、通过内部检查、待真实资源确认，不使用“95分”或没有依据的完成百分比。后项引用前项的版本；前项变更时，只重查受影响项。

### A01 研究问题与范围

产物：一页范围说明及申报简介。清楚说明使用者是支管巡检/维护人员，主要问题是正常操作与渐进故障混淆，以及告警可靠送达的开销。写清两种故障、正常干扰、诊断输出、定位范围、早期参照、已有与拟开展。

验收：全文题目、测点和时间一致；“早期”同时包含独立失效参照、首次持续正确提示和前期误报，不只比较速度；不能把15%模型流量偏离说成农业损失阈值。没有资源支持的多节点和自动控制只放条件扩展。

当前：已有待审。先与导师冻结主科学问题、失效参照和正式任务目标；未知信息不编写成既有条件。

### A02 文献和技术增量

产物：正文研究现状、17条完整引文及主张—引用—适用边界记录，中文11条为主、英文6条保留。每条有作者、题名、来源、年份和可核对入口。

验收：正文引用与文后编号逐一对应；用于论证的资料确实支持相邻主张，综述不代替原始性能实验，厂家资料不计入学术论文数量。不声称“首次用LoRa”或“双测点本身首创”。创新写成待验证的辨识边界或同规则告警取舍。

当前：来源与编号已有程序检查，科学增量仍待真实实验检验。新增文献必须重新核验，不为扩大数量堆无关引文。

### A03 系统架构和职责

产物：一幅总体架构图及数据/事件职责说明。图中覆盖台架与独立参考、感知诊断、节点日志和缓存、接收持久化、管理核查及独立评价。

验收：每条箭头有数据或动作含义；独立真值不从检测器输出生成；接收ACK、已查看、复测恢复三者分开；一个节点和两个水路支路不混淆。云端和控制器不出现在基础链路中。架构里的每个必做模块能在任务、预算和实验表找到对应内容。

当前：已有设计图。检查通过只说明设计关系正确，不表示模块已经联调。

### A04 水路和硬件接口

产物：水路布点图、压力采集原理图、候选BOM及接口/供电核对表。P0侧取压→受限元件→P1→Q→A负载与泄漏分流；Q包括正常与泄漏流量。B正常支路有独立开关且同源供水。

验收：水路无逻辑矛盾，独立收集不产生背压；两线制4—20mA、150Ω采样、24V回路、ADS1115供电和量程、电平保护及流量脉冲转换写清；LoRa发射供电/天线及接收USB接口待台架验证。型号、数量、单位一致，压力精度按具体规格核对。功能图不得冒充可直接投板的PCB制造图。

当前：A04/A08候选接口包已完成17个引脚无重复、量程/采样时序、设计供电预留和条件预算核对，三张同源图完成文字及人工逻辑检查；部分通过。22mA故障电流已达到ADC轨，保护定值未冻结；指定精度报价、真实板卡和调理尚未验证。详见《硬件接口与LoRa通信论证分项验收》，不是可直接投板或已装配证明，尚未整合原申报稿。

### A05 三维模型和建模图片

产物：同一参数化实体模型的STEP、GLB、交互查看器；申报使用轴测总览，配套保留俯视安装关系和取压/泄漏局部图。配套尺寸/接口待核清单。不要用无连接含义的圆柱堆叠替代装配方案。

验收分四层：

1. 研究逻辑：P0、受限、P1、Q、A/B与独立计量位置能识别，和A04一致；电气区与水路/收集区关系合理。取压是侧口，不把压力传感器当作串联堵塞件。
2. 几何源：STEP可重新打开，实体有效；GLB单位和坐标转换正确；参数记录底板、管中心高、管内外径、器件包络及来源。探针不被实体阻断只能说明稀疏中心点概念检查，不能称全通道或全装配无干涉。
3. 图像：轴测、俯视和局部图来自同一场景版本，保存源和截图哈希；主要件不被标注遮挡，编号与图例对应，无引线错位；插入Word后主要说明字不小于9pt，按实际插入宽度核查；图像不裁掉接口或底板。不为了“真实感”增加不存在的采购件。
   引线端点需在所指部件边界上，不能停在空腔、相邻件或悬空位置；透视图可能有遮挡，俯视可另取同件的可见边界点。尺寸有明确起止面和单位；透视容易误读时用标明非比例的关系示意，禁止用不对应几何的漂亮引线代替尺寸依据。程序检查文字边界、重叠与锚点，人工再核对指向、遮挡、含义与最终插入大小；任一关键图失败，本项返工。
4. 实际性：标明未制造的概念布局；尺寸暂定，螺纹/安装长度/流量计要求待选型冻结；收集容器按最大泄漏流量×时长×余量选择并保持自由出流。制造模型还需采购尺寸、整体碰撞、间隙、耐压与装配验证，当前不得宣称通过。

当前：本轮提供独立收集优化候选包，包含容量核算、受影响部件的实体交集检查、离散取出路径和同源多视角；详见《三维台架建模论证与本轮验收》。仅通过所列概念检查，未整合进原申报稿，制造和全装配验收未做。三维不以零件数多作为质量指标。

### A06 水力建模和量程计算

产物：公式、参数表、假设、健康基线与24组量程核对，明确P0−P1=RQ²和Q=(Cn+Cl)√P1适用的简化条件。

验收：所有变量有单位；等式、支路汇合和故障注入与A04一致；噪声模拟与具体传感器精度不能等同；双压力差值考虑偏差、随机项和相关性，不把单个ADC分辨率当整机差压精度；量程、供水能力和计量容积按最大设计工况核对。未知负载与泄漏同形时明确不可辨识。

当前：A06—A07独立候选证据包通过所列内部检查，参数与当前台架统一，24组量程和288个有界误差工况可复核；区间分离与固定阈值的触发/误触发余量分别呈现。真实水力指数、工作点和完整误差预算等待B01—B02，不做没有物理依据的CFD彩色云图。详见《仿真建模与诊断证据分项验收》，尚未整合原申报稿。

### A07 诊断仿真和统计图

产物：6场景×4噪声×20种子的480次合成试次、参数和脚本，展示早期定义、噪声影响和失败反例。至少同时解释误报、漏检、检出程度与提前量。

验收：每张图有轴、单位、样本口径、场景、种子/分组和数据来源；单次轨迹与20种子统计明确分开；正常/漂移/未知负载不能从结果中删除。提前量仅对符合先验定义的有效早期试次报告，失败/未检出另计，不只算成功均值。不把480次模拟写成480次实物，不把601时间点写成601独立操作。

当前：当前参数480个合成试次、960条配对规则结果、五张同源图及失败反例已通过数值/图片内部检查；20个基础随机序列跨场景和噪声档复用，不将480作为独立物理操作。高压力噪声下K/R规则劣于固定Q，未知负载与泄漏不可辨识；这些局限须随结果进入正文。历史参数和结果保留并明确区分，尚未整合原申报稿。

### A08 LoRa协议与通信证据

## 五 大创实施阶段的逐项标准

### B01 资源落实与台架装配

先落实成员开发职责、参考仪器、供水和场地，按真实型号冻结BOM和几何接口，再搭最小水路。检查密封、排气、回水、可控泄漏计量、固定、检修与电气隔离。产物包括报价/借用记录、真实装配照片、BOM版本和安装检查。几何图不能代替耐压或实际漏水检查；水源不足时调整实验范围和申请经费。

### B02 标定和测量进入条件

分别完成P0/P1零点、跨工作范围多点标定、共同压力差值检验、重复性和流量参考标定，保留原始记录和参考仪器信息，估计偏差、随机和相关误差。健康工况重复操作后确认压力—流量关系。

内部进入条件为目标故障带来的关键测量变化能相对不确定度清楚分辨，可用预计变化至少约为扩展不确定度的两倍作保守预实验审查线；这不是已取得精度或学校规定。若不满足，改量程/布点/目标程度，重标定后再做B03，不能用滤波“消除”未知系统偏差。

### B03 故障实验和独立标签

拟按两故障×三供压×三程度×至少三独立操作完成54次主要故障，另做正常稳定、正常切换、允许供压变化和切换期间故障。80/120/160kPa及5%/10%/15%为设计网格，预实验后由导师冻结，必须受实际设备和参考测量支持。

每次包含健康建立、独立操作、参考程度、恢复及重复；记录trial、日期、操作者、阀态、原始数据、参照版本和缺失。独立故障标签另存，不由检测曲线反向生成。预实验/调参与验证分开，整日/压力档/负载档留出。54次是计划基础规模，不自动保证论文统计充分，关键边界须追加独立批次。

### B04 固件与真实可靠告警

质量检查、采样/时钟、原始microSD日志、事件缓存、串口帧、LoRa设置、接收持久化及去重真实贯通。阻断、短时异常、重复、掉电、会话变化和溢出分别测试；不可恢复损失据实记录。保存配置和完整发收/ACK日志，验证持久化先于ACK，延迟由对齐时钟或误差界限支持。能量必须测整机电流及相同时间窗，不能用发送次数代替。

### B05 接收服务与实际维护闭环

接收拟采用串口与SQLite，网站接真实记录后保持六模块和质量语义。事件身份和参照版本可追踪，断开显示无法判断；查看、处置和同工况复测分别留痕。实测归档要求同工况、有效参考读数及证据，不能只靠一个恢复选项。产物为源码、数据库/数据导出、事件样本及维护前后配对，软件操作标签与独立真值分开。

### B06 连续运行和公平比较

拟完成单次至少8h台架连续记录及至少3次恢复检查，统计缺失、停机、缓存和重启，不把无日志时间当正常。保持相同本地检测和信息条件比较诊断及通信，报告失败率与不确定性。8h只能证明该条件下的短期连续运行，不能宣传长期田间可靠性。现场许可和标签不足时，仅报告正常响应/安装与链路适应性。

### B07 结项与成果归档

按获批任务书逐项填写实际成果、原始证据和未完成/变更情况，提交原型、数据、调研/研究报告、过程、经费及本批竞赛/其他要求。国家级选择成果及署名规则按当批核定；论文稿不写已发表。形成可复现版本和证据包，队员能讲清楚测量—诊断—通信—维护的时间和身份关系。

## 六 论文阶段的逐项标准

### C01 冻结主问题

优先研究跨供压/跨负载下测点、状态信息和参照迁移对早期辨识的作用；真实通信取舍为备线。选一条证据充分的贡献，明确与已知方法的差别及可证伪结论。系统集成与LoRa本身不写成独立创新。

### C02 冻结数据与方法

完成独立标定和标签、留出单位、参数/参照版本，锁定调参和验证范围。实测不满足平方律时用预实验拟合或经验健康关系，不能在留出结果上重新挑模型。所有剔除有理由与记录，相邻点不当独立样本。

### C03 对照 消融与不确定性

采用同信息固定阈值、压力归一化等强基线，做单点/双点、阀态、持续性或参照迁移消融。按独立操作报告误报/小时、漏检、检出程度、提前量、重标定成本与置信区间，展示未知负载与漂移失败。性能不优时据实收缩到观测边界贡献，不选择性报告成功档位。

### C04 稿件和可复现材料

稿件包含问题、文献、测点/模型、标定/标签、冻结实验、结果、失败/限制与数据代码；图表从冻结数据生成，单位和样本一致。经导师审查贡献和署名，按真实经费与项目编号致谢；来源、作者贡献和辅助工具使用按期刊要求说明。

### C05 投稿与科研分认定

依证据质量、领域和导师意见选期刊；提交、返修、录用、发表、检索分别存证明。科研分需达到学院要求的作者、专业相关性、时间和收录口径，录用通知不自动等同收录。不能保证高水平录用、审稿周期或10分。
