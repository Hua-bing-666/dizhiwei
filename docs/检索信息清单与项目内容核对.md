# 第三部分　深刻分析：三个结构性问题

## 3.1 问题一：项目**最有价值的本地数据一条都没用上**

阿拉尔一师的数据（25 万亩自动化灌溉、72 小时一轮、节水 30—50 m³/亩、节电 5 元/亩、增产 30—50 公斤/亩、田间已装毛管水力监测仪）**全部来自项目所在地**，是能直接用在申报书里的硬材料。

**但申报书一条都没用**，反而保留三个来源不明的数字（切换 1—5 分钟、堵塞率 17%—18%、灌溉费 130 元/亩）。

**这意味着**：项目讲"南疆棉田"是在**讲一个想象中的南疆**，而不是**脚下的阿拉尔**。

> **这是最深刻的差距**：项目有地缘优势却没用。补上之后，"为什么是我们做"这个问题自动有了答案——**我们就在这个场景里**。

## 3.2 问题二：研究定位**落后于同方向文献半步**

| 本项目 | 同方向已有工作 | 差距 |
|---|---|---|
| 固定阈值 + 连续确认 | **B7**：BOCD/PELT/CUSUM 变点检测对比（2026） | 方法落后一代 |
| 主机端诊断 | **B6**：ESP32 + TFLite Micro 边缘推理（2026） | 部署落后一代 |
| 未点出灌溉管网定位工作 | **B3**：真实 125 公顷灌溉管网模型化定位（2025） | 缺对比 |
| 把"事件 vs 周期"当增量 | **B5**：3 个月田间实证，传输 -77%（2025） | 该点已被占 |

**但也要看到真实空间**：
- B3 用的是**市政管网模型**（敏感度矩阵、残差投影），**计算重**，不适合田间低功耗节点
- B5 测的是**土壤水分与灌溉控制**，不是**支管水力故障**
- B6 的准确率 >96% 是在**实验室台架**上，未解决"轮灌切换与故障区分"
- **B7/B8 的变点检测**用在输水干管，**未用于支管级小流量高频切换场景**

> **空间是"场景 + 约束"，不是"算法"**：把成熟的变点检测，用到**轮灌切换频繁、一天只灌 1—4 小时、低成本测量**的支管场景，并回答**它的边界在哪**。这个定位诚实、可做、有增量。

## 3.3 问题三：**"大创"该有的东西没写出来**

一份大创要评审看到的是：**学生能提出问题、能做实验、能得出结论**。

| 大创该有的 | 申报书现状 | 差距 |
|---|---|---|
| 清楚的问题 | 有，但混在方案里 | 需提炼成 2—3 个具体问题 |
| 能做完的边界 | 有"验证范围"，但语气含糊 | **需明确"必做/争取/不做"三档** |
| 学生做的工作量 | 未体现 | **需写工时与分工，说明 3 人 30 周能做完** |
| 能拿到手的成果 | 写了论文软著 | 需补**竞赛参与**（D7 硬条件） |
| 为什么值得做 | 讲节水增产 | **需补本地实测 + 政策原文** |

> **一份大创不需要解决工程难题，需要把一个小问题问清楚、答明白。** 现在的稿子把力气花在"证明方法最优"上，而不是"把问题问清楚"。
