## 1.2 场景的三个关键推论

### 推论一：一条支管一天只有 1—4 小时"有流量"

```
单条支管：一次连续灌水 0.4—1.8 小时 → 关闭 → 等下一轮（72h 内若干次）
⇒ 一天 24 小时中，只有 1—4 小时处于"有流量"状态
```

| 项 | 数值 |
|---|---|
| 判据确认门限 | 15 秒 |
| 一次灌水窗口 | 约 0.4—1.8 小时 = 1440—6480 秒 |
| **门限占窗口比例** | **0.2%—1.0%** |

**⇒ 门限不是瓶颈。** "早期"的正确口径是**第几次灌水发现**，不是第几秒。

### 推论二：轮灌切换是"阶跃 + 新稳态"，不是持续扰动

实测（`normal|0.3` 首条轨迹，B 阀 180—299 开）：

| 时段 | P0 均值 | P1 均值 | Q 均值 | **C = Q/√P1** | **R̂ = (P0−P1)/Q²** |
|---|---|---|---|---|---|
| B 阀关（早） | 116.6 | 109.7 | 2.931 | **0.280** | **0.79** |
| B 阀开 | 104.1 | 98.5 | 2.780 | **0.280** | **0.79** |
| B 阀关（晚） | 116.7 | 109.7 | 2.933 | **0.280** | **0.79** |

**关键**：切换使 P0 骤降 **10.7%**、P1 降 10.6%、Q 降 5.2%，
**但 C 与 R̂ 恒定不变。**

**⇒ 轮灌切换只是换了一个工况点，不是故障。**
**⇒ 判据应建立在"参数在同一工况内的漂移"上，而不是"参数绝对值"上。**

### 推论三：田间已有水力监测，但层级不同

| | 已有设备 | 本项目 |
|---|---|---|
| 层级 | 毛管、田间、作物 | **支管**（干管到田间的分配环节） |
| 关心 | 长势、墒情、均匀度 | **支管区段的等效泄漏与受限** |
| 核心问题 | 长得好不好 | **正常轮灌切换与故障如何区分** |

**⇒ 差异化清晰，且不重复劳动。**

# 第二部分　技术瓶颈（三个，均可定量刻画）

## 瓶颈一：可辨识性 —— 单一工况内压力—流量关系不可辨识

### 现象（实测）

| 工况 | P1 标准差 / 均值 | 相对波动 |
|---|---|---|
| B 阀关（早） | 0.281 / 109.71 | **0.26%** |
| B 阀开 | 0.306 / 98.52 | **0.31%** |
| B 阀关（晚） | 0.291 / 109.69 | **0.27%** |

在 **±0.3%** 的跨度上做 log-log 拟合，斜率完全由噪声支配：
- 单窗口拟合得 **n = −0.23 ~ −1.46**（荒谬）
- 跨工况拟合得 **n = +0.49**（正确）

### 定量：需要多大的压力跨度？

斜率不确定度 ≈ `σ_Q/(Q·√N) / ln(P1_hi/P1_lo)`

| P1 跨度 | n 的不确定度（σ_Q/Q=0.1%） | （σ_Q/Q=1%） |
|---|---|---|
| 1% | **1.00** | 10.0 |
| 5% | 0.021 | 0.205 |
| **20%** | **0.0055** | **0.055** |
| 100% | 0.0014 | 0.014 |

**⇒ 要辨识到 n 的不确定度 ≤0.05，需压力跨度 ≥20%（σ_Q/Q=0.1%）或 ≥20%（σ_Q/Q=1%）。**

**⇒ 这证明申报书设计的"80/120/160 kPa 三档供压"是必要的**——跨档合起来跨度约 100%，实测才能得到正确的 n=0.49。

### 处置

| 措施 | 说明 |
|---|---|
| 台架必须跨多供压档标定 | 三档供压 × 阀态 = 至少 6 个工况点 |
| 单档内不做指数拟合 | 单档只用于残差尺度估计 |
| 标定窗口跨工况联合 | 实测采用 `20—175 + 300—599` 联合标定，得 n=0.4755 |
| 申报书写明该限制 | "单一工况内不可辨识，需多供压档构造跨度" |

## 瓶颈二：共模/差模不可分 —— 上游供压与本支管故障在数学上等价

### 推导

```
观测方程：  P1 = Ps − Rc·Q² − R·Q²     （串联阻力）
            Q  = C·√P1                   （负载关系）

代入消元：  P1·(1 + (Rc+R)·C²) = Ps
       ⇒   P1 = Ps / (1 + (Rc+R)·C²)
       ⇒   Q  = C·√Ps / √(1 + (Rc+R)·C²)
```

**关键结论**：联合量 **β = (Rc + R)·C²** 一个标量决定一切。

**⇒ 在单一工况下只能辨识 β，无法把上游共同阻力 Rc 与本支管阻力 R 分离。**

实测印证：`Q/√P1` 全程恒为 **0.280**（C 已知），而 `(P0−P1)/Q²` 中混着 Rc 的成分。

### 这意味着什么

| 现象 | 观测变化 | 能否与本支管故障区分 |
|---|---|---|
| 上游供压下降 | P0↓ P1↓ Q↓ | **仅凭本支管测点：不能** |
| 本支管受限 | P0↑ P1↓ Q↓ | — |
| 邻支管开关 | P0↓ P1↓ Q↓ | **仅凭本支管测点：不能** |

**⇒ 这是结构性限制，不是算法能解决的。**

### 处置（两条并行）

| 措施 | 原理 | 成本 |
|---|---|---|
| **加一路干管参照 P2** | 用上游压力归一化，扣除共同扰动 | +1 只压力变送器（80—350 元） |
| **多工况门限分档** | 按 P1 档 + 阀态分档标定 | 0（软件） |

**⇒ 干管参照是刚需，不是锦上添花。这一条把"要不要加第 4 路测点"从工程偏好变成了理论必然。**

## 瓶颈三：切换与故障的时域可分性 —— 判据的新意所在

### 实测依据

| | 轮灌切换 | 等效泄漏/受限 |
|---|---|---|
| 时域特征 | **阶跃 + 新稳态**（1—2 采样内跳变，之后参数不变） | **同一工况内参数持续漂移** |
| C | 不变（恒 0.280） | 泄漏时增大 |
| R̂ | 不变（恒 0.79） | 受限时增大 |
| 绝对压力 | **变化很大（−10.7%）** | 变化小 |

### 由此得到的判据设计原则

> **判据不建立在参数绝对值上，而建立在"参数在同一工况内相对健康参照的漂移"上。**

这条原则把两类现象在原理上分开：
- 切换 → 参数不变，只是工作点移动 → **不报警**
- 故障 → 参数漂移 → **报警**

### 与现有做法的对比

| 做法 | 问题 |
|---|---|
| 绝对阈值（固定门限） | 切换造成的大幅压力变化会误触发 |
| 切换期暂停判断 | **会漏掉切换期故障**（项目内部反例：20/20 → 0/20） |
| **工况内漂移判据（本项目）** | 既不漏也不误——用同工况健康参照做基准 |

### 处置

| 措施 | 说明 |
|---|---|
| 建立**分工况健康参照表** | 按 P1 档 + 阀态分档，每档独立标定增益、r0、稳健尺度 |
| 用**参数漂移**而非绝对值 | 残差 = 同档内实测参数 − 该档健康参照 |
| 加**流量阶跃检测** | 从数据自身识别切换时刻，不依赖外部阀态信号 |

# 第三部分　算法技术路线（含仿真验证计划）

## 3.1 判据框架

```
输入：P0, P1, Q（1 Hz）
  ↓
① 质量门控：越量程、缺测、计数复位、时间错位 → 不合格则输出“无法判断”
  ↓
② 特征计算：K = Q/√P1（负载）、R̂ = (P0−P1)/Q²（区段阻力）
  ↓
③ 工况识别：
     · 流量阶跃检测（|ΔQ| 跳变）→ 标记“工况已变”
     · 结合 P2 干管参照 → 判定是“共同扰动”还是“局部变化”
  ↓
④ 分工况健康参照：按 (P1 档, 阀态) 取对应档的健康参照 (gain, r0, s)
  ↓
⑤ 残差与归一化：e_Q = Q/(gain·Q_ref) − 1；e_R = R̂ − r0
                z_Q = e_Q/s_Q；z_R = e_R/s_R
  ↓
⑥ 双路 CUSUM：S = max(0, S_prev + z − k)，k=0.5；S > h 报警
  ↓
⑦ 分类：K 升而 R̂ 平 → 泄漏；R̂ 升而 K 平 → 受限；两者同升 → 待检查/共同扰动
  ↓
⑧ 输出：模式 + 支管编号 + 测点区段 + 建议检查部位
```

## 3.2 为什么用 CUSUM 而不是固定阈值

| 理由 | 依据 |
|---|---|
| **最优性** | 对"变化幅度未知"的检测问题，CUSUM 在给定虚警率下使最坏情况检测延迟最小（Lorden 1971） |
| **可设计** | 门限 h 由目标 ARL₀ 反推，把"1 次/小时"从事后统计变成设计输入 |
| **适合渐进故障** | 累积小偏差，不等单点越限 |
| **对齐主流** | 同类研究已用 BOCD/PELT/CUSUM 做变点检测（Benavides-Muñoz 2026） |

| 结论 | 数值 |

| P1 (kPa) | 5% 变化的 ΔP | 原方案 U | 信号/U |

| 120 | 0.77 | 0.74 | **1.04 ✗** |

**原方案（两只 0—200kPa 表压相减）三档全部不可分辨。**

改差压后：

| 量程 | 精度 | U | P1=80 | P1=120 | P1=160 |

| LoRa 分包 | 64B 分包、9600bps 下 57B 需 59.4ms | 帧长已控制；接收端按 COBS 重组；实测分包行为 |

# 第六部分　场景适配与验收

## 6.1 场景适配结论

| 项 | 结论 |
|---|---|
| 判据时间尺度 | 15 秒门限占 0.4—1.8h 窗口的 **0.2%—1.0%**，余量充足 |
| "早期"口径 | 按**第几次灌水发现**计 |
| 无流量时段 | 判据只在 `Q > 0.5 L/min` 时有效；停灌段输出"无当前数据" |
| 切换干扰 | 用**工况内漂移判据 + 流量阶跃检测 + 干管参照**三重处理 |
| 与已有设备关系 | 已有测毛管/田间；本项目测**支管区段**，核心答"切换与故障如何区分" |
