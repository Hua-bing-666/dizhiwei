# 总体设计配图记录

本轮配图依据用户提供的“3.3.1 总体设计”正文截图制作，采用两路表压 P0、P1、一路脉冲流量 Q、STM32F103C8T6、ADS1115、SEN0549、microSD 和两只 E220-400T22D 的口径。旧版差压变送器/GD32 文档不作为本图的配置依据。未修改申报书正文，也未据此变更采购清单。

图名建议为“图3-1 系统总体结构”。图示硬件功能连接和信息流，不是接线施工图或已完成实物成果。供电、引脚及阻容数值不在本图展开，避免与专门接口图重复。

图中四个部分为双支路清水台架、感知诊断节点、LoRa 接收端和本地巡检平台。节点侧显示压力取样保护、外置 ADC、流量脉冲整形计数、主控处理、无线与日志接口；右侧显示无线接收、USB 串口、校验去重、持久化和巡检记录。虚线仅表示接收确认返回，确认由接收服务在成功持久化后产生，不解释为无线模块自行提供的应用确认。
