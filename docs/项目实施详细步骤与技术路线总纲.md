## 2. 系统架构：五个角色、一条链路

```
                ┌─────────────── 双支路清水台架（A 被测 / B 健康扰动）────────────────┐
水源 ─→ P0（上游侧向取压）─→ 受限元件 R ─→ P1（下游侧向取压）─→ 流量计 Q ─→ 正常负载
                                                                    └─→ 泄漏旁路（可控注入）
                └───────────────────────────────────────────────────────────────────┘
                                          │
                        ┌─────────────────┴─────────────────┐
                        │ 感知诊断节点  STM32F103C8T6       │
                        │  · P0/P1：4–20mA → 150Ω → ADS1115 │
                        │  · Q：SEN0549 脉冲 → 电平转换 → 计数器 │
                        │  · 本地诊断（整数 C 内核）+ microSD 原始日志 │
                        │  · 待确认事件队列（16+1+64 槽）    │
                        └─────────────────┬─────────────────┘
                                          │ E220-400T22D（LoRa）
                                          ▼
                        ┌───────────────────────────────────┐
                        │ LoRa 接收端：E220 + USB-TTL 字节桥 │
                        └─────────────────┬─────────────────┘
                                          │ 串口
                                          ▼
                        ┌───────────────────────────────────┐
                        │ 已有电脑：Python 串口服务          │
                        │ 校验/去重/冲突回滚 → SQLite → ACK  │
                        └─────────────────┬─────────────────┘
                                          ▼
                        ┌───────────────────────────────────┐
                        │ 本地 Web 六模块：总览 / 支管监测 / │
                        │ 异常事件 / 设备链路 / 历史记录 / 设置│
                        │ 闭环：告警→人工查看→现场处置→同工况复测→归档 │
                        └───────────────────────────────────┘
                                          ▲
                        ┌─────────────────┴─────────────────┐
                        │ 独立参考测量与故障操作标签（旁路评价）│
                        └───────────────────────────────────┘
```

**四条必须守住的语义边界**（申报书与台账反复强调）：

1. **接收 ACK ≠ 人工已查看 ≠ 复测归档**：三者各记时间，分别存库。ACK 只表示接收端已持久化。
2. **数据正常 ≠ 在线**：无效/离线时必须显示"无法判断 + 最近有效时刻"，不能拿旧数据填成正常。
3. **独立真值不由检测器输出生成**：故障程度由参考流量/参考压力与操作记录独立定义。
4. **定位只到"支管编号—两测点包围区段—建议检查部位"**，不定位单滴头、不定位厘米级漏点。

**诊断的四种输出**：`等效泄漏候选` / `等效受限候选` / `异常待检查`（信息不足）/ `数据无效或节点离线`（无法判断）。

### 阶段 B：大创实施（2027.3—2028.2，7 项门槛）

#### B01 资源落实与台架装配（2027.3—4 前段）

#### B02 标定与测量进入条件（2027.3—4 后段）
- 分别完成 P0/P1 零点、跨工作范围多点标定（**压力、流量各 ≥5 点，每点 ≥3 次独立读取**）、共同压力差值检验、重复性、流量参考标定（容积或称重计时）。
- 估计偏差、随机误差与相关误差；健康工况重复操作后确认压力—流量关系。
- **进入线（保守预实验审查线）**：目标故障带来的关键测量变化 ≥ 扩展不确定度的约 2 倍。
- 不满足时：改量程 / 改布点 / 把目标从 5% 退到 10%，重标定后再做 B03。**不能用滤波"消除"未知系统偏差。**

#### B03 故障实验与独立标签（2027.5—6）
- 主要故障：**2 类型 × 3 供压 × 3 程度 × ≥3 独立操作 = 54 次**。
  - 供压设计网格 80 / 120 / 160 kPa；程度 5% / 10% / 15%（15% 为本期实验失效参照，**不代表棉花减产阈值**）。
  - 泄漏：逐步打开旁路形成附加出流，独立收集+计时测量泄漏量。
  - 受限：调节 R 改变局部阻力，以操作记录+参考压力/流量共同核验程度。
- 对照：正常干扰 **3 供压 × 2 个 B 状态 × 3 次 = 18 次，每次 ≥20 分钟**；切换期间故障 **2 类型 × 3 供压 × 2 切换方向 = 12 次**。
- 每次包含：健康建立 → 独立操作 → 参考程度 → 恢复 → 重复；记录 trial、日期、操作者、阀态、原始数据、参照版本、缺失。
- **独立故障标签另存，不由检测曲线反向生成**；预实验/调参与验证分开；按整日 / 压力档 / 负载档留出。

#### B04 固件与真实可靠告警（2027.7—8 前段）
- 让下列环节**真实贯通**：质量检查、采样与时钟、原始 microSD 日志、事件缓存、串口帧、LoRa 设置、接收持久化、去重。
- 分别测试：阻断、短时异常、重复、掉电、会话变化、队列溢出；不可恢复损失据实记录。
- 保存配置与完整发收/ACK 日志；**验证"持久化先于 ACK"**；延迟由对齐时钟或误差界限支持。
- 能量必须测**整机电流及相同时间窗**；**不能用发送次数代替节能比例**。

#### B05 接收服务与实际维护闭环（2027.7—8 中段）

## 5. 关键技术路线详解

### 5.1 水力模型与测点

集中参数模型（申报书 §3）：

```
P0 − P1 = R · Q²          管路：ΔP = R·Q²
Q = (Cₙ + Cₗ) · √P1       负载：Q = C·√P_end
```

- 单位：压力 kPa，流量 L/min，R [kPa/(L/min)²]，C [(L/min)/√kPa]。
- 当前设计取值：健康 Cₙ = 0.28，R = 0.8；泄漏时总负载系数渐增至 0.37；受限时 R 渐增至 8。
- 24 组供压×B 状态网格：A 支路流量 **1.85—4.34 L/min**，模型最大双支路总流量 **7.95 L/min**。
- B 支路 = 健康共同负载扰动（模拟隔壁轮灌开关），**不作为第二个监测节点**。

**第一关（全项目成败点）**：按 200 kPa、±0.25%FS 选型，单路压力标称误差界限 ±0.5 kPa，**两路最不利差压界限 1 kPa**；还需叠加采样电阻、ADC、温漂、参考仪器、管路安装、时间错位。**必须用参考仪表实测回答"这个不确定度能否压住 5% 故障信号"，不能靠选型表。**

### 5.2 采集与时间窗

| 项目 | 参数 |
|---|---|
| 记录周期 | 固定 **1 Hz**（当前软件基线与 C 输入合同） |
| 流量计数窗 | **10 秒**滚动脉冲计数；SEN0549 为 540 脉冲/L，单脉冲分辨率 0.01111 L/min（≈4 L/min 的 0.278%） |
| 1 秒窗对比 | 单脉冲对应 0.111 L/min（≈2.78%）——窗越短分辨率越差、窗越长滞后越大 |
| 十秒主窗 | **11 个计数端点 + 10 次压力观测**，连续 **5 次**满足判据才输出候选 |
| 三秒短窗 | **3 个压力点 + 4 个计数端点**，连续 **2 次**越限只输出"待复核提示"，**不替代主诊断** |

### 5.3 诊断判据（当前合成基线）

定义两个诊断特征：

```
K  = Q / √P1                   下游等效负载
R̂  = (P0 − P1) / Q²            测点区段等效阻力
```

诊断量：

```
e_Q = Q / Q_ref − 1                     相对流量偏离（无量纲）
e_R = (P0 − P1)/Q² − R0                 区段阻力变化 [kPa/(L/min)²]
```

健康参照（log-log 经验拟合）：

```
Q_ref = a · (P1/100)^n
```

实测拟合指数 n ≈ 0.0008 / 0.3007 / 0.5007 / 0.8006（不同工况档），说明**真实水力指数必须在台架标定后确定**，不能预设平方根律。

快速通道判据（越限即触发）：

```
x_j > max( τ_j , 6 · s_j )
τ_Q = 0.06      τ_R = 0.6
s_j  = 初始健康段残差的 MAD 稳健尺度
```

主窗判据：e_Q 相对参照增加 **6%** 或 e_R 绝对增加 **0.6**，且**连续 5 次确认**（均为合成基线参数，台架标定后由导师冻结）。

输出逻辑：`K 持续升高且 R̂ 相对稳定 → 等效泄漏线索`；`R̂ 持续升高 → 局部受限线索`。

**已暴露的失败边界（必须写进论文的"适用边界"）**：

- σ = 10 kPa 高压噪声下，K/R̂ 方法泄漏只识别 **1/20**、受限 **2/20**，而固定流量阈值仍为 **20/20**；且各出现 18 次故障前确认误报。
- **未知正常负载增加与等效泄漏产生相同观测**（不可辨识）。
- P0 零点漂移可能被误判为"受限"；负载指数失配可使正常供压调整触发报警。
- 结论：**480 次合成试次不足以证明 K/R̂ 优于固定流量阈值**，只支持"把压力误差纳入研究"。

**被对照后否决/降级的方法**：统一 20 秒切换暂停（低噪声快速切换泄漏有效早期 20/20 → **0/20**，不采用为默认）；CUSUM（k=0.5，h_K=362.7049，h_R=419.7514）与 EWMA（λ=0.2，门限 0.135781/3.211460）减少部分高噪声误报，但低噪声下无更早检出收益，**保留为候选对照，不替换主方案**。

### 5.4 整数化移植（C 内核）

- 为 MCU 定点化：用 **10—200 kPa、0.5 kPa 间隔的 381 点预测表**（`DIAG_POINTS = 381`）替代浮点插值，`diag_predict()` 做查表+线性插值+round-half-even。
- 两条严格比较式（不含除法，全部整数）：

```
l = d·10¹²  −  9·n·pred·(10⁶ + leak)                 > 0  → 泄漏
r = (p0_sum − p1_sum)·81·n·10⁶  −  100·d²·(r0 + restriction)  > 0  → 受限
```

- 设备级约束：`DIAG_MAX_DELTA = 450`（单秒计数增量上限）；压力合法域 0—20000（0.01 kPa 量化）。原始值先检查范围再量化，**防止 −0.001 kPa 舍入为 0 后变成有效值**。
- 状态机：11 元素（`ring[11]`）滑窗、`pressure_run ≥ 10`、`counter_run ≥ 11`、`confirmed ≥ 5`、`rapid_pending ≥ 2`。
- 输入合同（`issue`）：`0` 有效 / `1` 缺失或非有限 / `2` 原始越量程 / `3` 时序失败。迟到端点既不能作为当前测量，也不能作为将来窗口起点（桥接程序显式清零 `size`、`counter_run`、`pressure_run`）。
- 内存布局（主机 `sizeof`）：诊断状态 **200 B** + 含预测表配置 **1548 B** + 候选槽 **84 B** + 完整布局 **6968 B** = **8716 B**（**不含驱动、FatFS 与栈**，不证明 F103 整机资源满足）。
- 溢出安全：`-std=c11 -Wall -Wextra -Werror -Wconversion -O2 -ftrapv` 严格编译；配置校验把最宽乘法限制在**已核对上界 2,025,000,000,000,000,000**（< 有符号 64 位上限 9,223,372,036,854,775,807）。
- 等价性验证：216 条轨迹（144+72）、**130,896 次更新**、**102,816 条监测记录**与独立整数参考零差异。**九个比较字段** = 测量状态、诊断模式、短窗有效性、短窗活动状态、短窗越限、主窗当前标签、事件掩码、质量原因、输出流量。同时保留 **3 个构造临界反例**（压力舍入、表插值临界、工作域舍入），说明"九字段一致 ≠ 任意输入下浮点与整数数学等价"。
- 计数器边界：`DIAG_MAX_DELTA = 450 脉冲/秒` 是 **50 L/min 的算术保护范围**，**不能据此拓展传感器的已知精度适用区间**（SEN0549 的 ±1% 只适用于 0.3—5 L/min，5 L/min 时约 45 脉冲/秒）。**16 位计数差仍无法区分所有复位与合法回绕**，因此需要「计数复位」与「计数端点缺失」分别重建窗口。
- ADC 侧：ADS1115 顺序转换、暂按 128 SPS 与 I²C 100 kHz 设计；**复用采样不是理想同时采样**，须记录两次转换时刻并核查错位。
- 标定与健康参照拟合**仍在 PC 端**，不在 MCU 内。

### 5.5 LoRa 协议 v2（帧格式与可靠机制）

**帧结构**（小端）：公共头 **16 B** + 快照/事件体 + CRC16(CCITT-FALSE, 初值 0xFFFF)，经 **COBS** 定界并以 `0x00` 收尾。

**公共头 16 B**：`version u8`、`type u8`、`payload_len u16`、`device u32`、`session u32`、`seq u32`；类型常量 `EVENT = 1`、`ACK = 2`、`TELEMETRY = 3`。

| 帧类型 | 总长 | 说明 |
|---|---|---|
| 遥测（3） | **55 B** | 周期状态上报（快照 35 B + 头 16 B + 校验/定界 4 B） |
| 事件（1） | **57 B** | 快照 + 事件码 1 B + 细节码 1 B |
| ACK（2） | **24 B** | 载荷 = 原消息的 **4 B CRC32 指纹**，同时核对原 device/session/seq |

**测量快照 35 B（偏移相对解码后快照起点）**

| 偏移 / 长度 | 字段 | 单位与含义 |
|---|---|---|
| 0 / 4 | `uptime_ms` | 本会话采集端点毫秒，**不是 UTC** |
| 4 / 4 | `sample_seq` | 本会话采样序号 |
| 8 / 4 | `config_id` | 接收端已登记的配置标识 |
| 12 / 2 | `reference_id` | 已登记参照标识；无数值参照为 0 |
| 14 / 4 | `cumulative_pulses` | 累积流量脉冲 |
| 18 / 4、22 / 4 | `P0`、`P1` | 有符号整数，**0.01 kPa** |
| 26 / 4 | `Q10` | 十秒流量，**mL/min** |
| 30 / 1 | `status` | 测量与参照条件状态 |
| 31 / 1 | `flags` | 数值参照 / 健康许可 / 短窗有效 / 短窗关注 / 合成来源 |
| 32 / 1 | `pattern` | 无证据 / 泄漏 / 受限 / 不确定 / 不可用 |
| 33 / 1、34 / 1 | P0 / P1 年龄 | 读取完成至计数端点的毫秒数，**缺失 = 255** |

编码量化误差实测上限：压力 **0.004995 kPa**、流量 **0.0004445 L/min**（界限 0.005 kPa / 0.0005 L/min）。候选 E220-400T22D 支持 **64 B 分包**，上述帧可放入。

字段约束（解码器强制校验）：`version == 2`；`type ∈ 1..3`；`payload_len == n − 16`；`device/session/seq ≠ 0`；`status ≤ 5`；`pattern ≤ 4`；`flags & 0x70 == 0`；压力缺失标志必须与 `INT32_MIN` 一致；`status == 0` 时要求 `numeric && approved`、`p0 ∈ [0,20000]`、`p1 ∈ [1000,20000]`、`q ≥ 500`、`pattern ≠ 4`；`status ∈ {1,2}` 时禁止带短窗标志。

> **版本冲突提示**：`docs/archive/docs_历史/硬件接口与LoRa通信论证分项验收.md`（2026-10-04）记录的是**上一版线格式**（事件/遥测 44 B、ACK 24 B、快照 24 B），与第七轮之后的 v2（55 / 57 / 24 B、快照 35 B）**不是同一版本**，引用时必须区分。

**身份与可靠性机制**：

- 事件身份 = `device / session / seq` 三元组。
- **接收端提交 SQLite 之后才回 ACK**；重复内容只回 ACK 不改首次存储时间；同一身份内容不同 → 冲突回滚进异常处理；旧采集时刻不因重传而更新。
- 队列容量：**16 业务槽 + 1 探测槽 + 64 历史环**（另有最新遥测各 1），逻辑行 ≤ **83**。
- 重传策略：初始派发 ≤ **8** 次；恢复追加 ≤ **4** 次（间隔 2 s）；合计 ≤ **12** 次；业务保留 **300 s**。
- 探测条件：派发后 ≥ 8 s 未确认且最近 8 s 无有效 ACK，两次探测间隔 ≥ 30 s。
- 接纳规则：**普通未确认遥测最多 1 条，可被新遥测替代；事件优先接纳，已接纳事件不因新遥测被删**；满事件队列时**明确拒绝**并留拒绝记录。
- 有限容量与期限意味着**长中断不能保证全部送达**（见 §6 量化结果）。

### 5.6 四种上报策略的公平对照

在**同一段本地检测轨迹、同一载荷、同一确认规则**下比较：

1. 快周期（10 s 定期）
2. 慢周期（60 s 定期）
3. 原始事件（变化即刻）
4. 滤波限频事件（事件 + 60 s 心跳）

指标：远端告警延迟 **P50 / P95**、期限内送达比例、未送达数量、重传与重复、缓存溢出与恢复缺口。通信开销用帧数/字节/无线占用；**整机能量必须独立测电流，不以帧数换算节能比例**。

**取样容器核算**：当前模型最大泄漏量 1.055 L/min，按 18 秒取样并留 25% 余量 → 需有效容积约 **440 mL**；容器几何空腔计算值 678.6 mL，**实际使用前须测定有效容量**；出口与杯口预留 20 mm 自由出流间隙，长时实验另设排水（避免背压与溅水）。
