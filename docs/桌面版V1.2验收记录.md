# 滴智卫桌面版 V1.2 验收记录

2026 年 10 月 7 日。交付为 Windows 64 位桌面程序与便携文件夹压缩包。应用版本 1.2.0，底层诊断配置仍为 `20261007-platform-c-v1`；未修改申报书或扩大实物验证范围。

## 桌面实现

EXE 在独立线程启动本机 HTTP 服务，主线程显示 WebView2 桌面窗口。SQLite 的创建、请求处理及关闭均在服务线程完成。端口由系统分配，界面启动后自动连接；端口变化不影响数据库记录。程序文件与 `data` 分开，后台不向页面提供申报书、研究报告、源代码或数据库文件。

C 诊断程序预先编译并随程序分发，启动时核对源文件与二进制摘要。客户端不编译 C，不依赖制作电脑的 Python、GCC、工作目录或数据库服务。主窗、短窗、质量门控与软件控制演示保持原有逻辑。运行配置函数从研究入口中独立出来，与原实现逐一比较了 0.3／3／10 kPa 三档结果和 C 配置命令，完全一致。

导出直接调用 Windows 保存窗口，写入临时文件后替换目标文件。用户取消不会写文件；接口只接受规定的 CSV／JSON 文件名及文本内容。保存失败在界面显示原因。浏览器版本仍使用原有下载方式，两个入口各自处理保存。

同一数据目录使用 Windows 互斥量保护。重复双击会返回已有窗口；正常关闭会停止本地服务、关闭 C 子进程和 SQLite。更新构建使用临时输出目录，交付时只合并程序文件，保留已有 `data`。

检查了实际 EXE 的原生窗口、运行总览、监测、配置、三维台架和重启后的历史页面。窗口采用系统标题栏与菜单，首次以最大化方式打开，文字、卡片和侧栏沿用现有 UI。页面较长时使用滚动查看，三维台架保留自身视角与部件检查功能。此项确认桌面封装没有造成页面水平溢出、资源缺失或主要内容遮挡。

## 运行边界

依赖 Windows 10／11 x64、系统 .NET Framework 和 Microsoft Edge WebView2 Runtime；Python 和后台依赖已打包。未验证其他 Windows 版本、其他电脑、缺少 WebView2 的安装流程或只读目录的数据回退。桌面版不承诺射频、真实串口、STM32 采集、功耗或实物阀门效果。备份数据库时应先关闭程序。
