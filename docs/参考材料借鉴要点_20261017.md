## 一、总判断：三份各取一样东西

| 参考 | 取什么 | 不取什么 |
|---|---|---|
| ①分步(1).docx | **图的画法**：3D 立体框、大编号、分层面板、(a)(b) 子图、图例惯例 | 彩色配色（黑白打印会糊）；图内写大标题 |
| ②双车联动（国家级） | **章节骨架与语言句式**：项目内容 1.1/1.1.1 分层、图随文"如图X"、研究现状按国内/国外分节并落到新疆棉田 | 大量"预计/计划/目标"式软承诺（实测数据支撑的硬指标才是我们的优势） |
| ③电池检测（检测类） | **硬件模块写法**：型号 → 量程 → 误差 → 接口引脚 → 选型依据，五要素逐项写透 | 只列器件不做误差合成、不设验收门槛、结论自承"误差较大" |

## 二、图的规范（已落到本项目 5 张图）

1. **3D 立体框**：正面白/浅灰 + 右下深灰侧面 + 深描边；替代原来的扁平方框。
2. **每框两层文字**：粗体主词 + 小字关键词注解（"／"或"："分隔），不写长句。
3. **黑白打印适配**：全部灰度体系（正面 #f7f7f7、侧面 #c4c4c4、强调纯黑）；已完成阶段用 45° 斜纹；R/G 用黑底白字小标签。
4. **分层面板**：物理层／输入层／处理层／输出层，左侧竖排层标签 + 横向节点链。
5. **图例惯例**：实线箭头＝数据流，虚线箭头＝参数/控制流，斜纹＝已完成。
6. **底部注释行**：一行灰字说明整图逻辑（参考材料每张图都有， ours 已照做）。
7. **图内不放大标题**，图题由正文段落承担。

字号口径（已写入 `scripts/verify_html_figs.mjs`）：主词 ≥9.5 pt、次要 ≥6 pt、坐标刻度 ≥4.5 pt（按 A4 版心 15.4 cm 宽放置换算，`pt = px × 0.75 × 436 / 绘制宽`）。

## 三、语言句式（取自国家级立项，可套用）

- 架构类："以……为控制中枢／核心，构建……三层（或四层）架构"。
- 目标类："预计……≤……；实测……为……"（**我们只写实测与门控值，"预计"仅用于尚未开测的台架项，且必须标注待实测定型**）。
- 闭环类："形成'感知—判决—上报—处置'闭环"、"实现……无缝衔接"。
- 数字密度：**每一段至少有一个量化数字**（我们已有 U ≤ 0.20 kPa、h* = 26、57 B、≤10 dBm、+2%/+50% 等，密度只嫌少不嫌多）。
- 段落编号：正文用 1.1／1.1.1 分层，每层末尾挂"如图 X"。

**不可借鉴**：把未做的工作写成既定成果。我们的稿件里"仿真已得"与"台架待测"必须分开陈述，门控 G1—G5 就是这条分界线。

## 四、硬件模块写法（取自电池检测，检测类通用）

每个模块按五要素写，一段写完：

1. **型号**：芯片/模块完整型号（如 INA226、ACS712）。
2. **量程/范围**："共模电压 0—36 V"、"测温 -55—+125 ℃"。
3. **误差/精度**："总输出误差 1.5%"、"-10—+85 ℃ 内 ±2 ℃"。
4. **接口**：引脚级连接（"DO 接 PB13(SCK)，CS 接 PB12"）。
5. **选型依据**：为什么选它、为什么不选替代方案（这一步是电池检测稿缺的，我们必须补，且已有 D1—D8 决策表可直接引用）。

对照我们已冻结的选型写法示例：
> 差压测量采用 MDM490 型两线制差压变送器，量程 35—40 kPa、准确度 ±0.5% FS，24 V 供电由 XL6009 高边开关控制；ADC 选用 SGM58031（P2P 替代 ADS1115），经 PA0/PA1 接入。选单只差压表而不用两只表压相减，是为了把量程/信号比从 20—40 倍压到 4—8 倍（决策 D1）。

## 五、研究现状写法（取自国家级立项）

- 分"国内／国外"两节，每节按技术方向再分小节（如"农机协同与数据互通"、"秸秆处理与耕地数据融合"）。
- 每条引用写全：**单位/企业 + 具体做法 + 量化结果 + 局限**。例："中国农业大学基于 LoRa 的田间农机协同系统，STM32F4 为核心，河北小麦产区试点衔接时间缩短 40%、效率 2.5 亩/小时；局限在……"。
- 必须落到**新疆/南疆**：该稿已给出"阿克苏棉区无人机+双车试点，作业效率 3 亩/小时、成本降 60%，但部分地区 4G 覆盖不足"。我们写现状时要顺着这条引到滴灌支管诊断的空白。
- 现状末尾要有一句"综上，已有工作解决了……但未解决……"，直接引出我们的研究问题。
