# 算法与软件最终方案

2026年10月6日。本次完成申报前的软件验证收尾，研究对象、单节点双压力流量、LoRa接收端和本地巡检平台保持原范围。以下“采用”指软件基线及拟移植方案，不代表台架、无线或棉田性能已经验证。

## 1. 当前基线与取舍

固定1Hz采集，持续累计脉冲；十秒主窗使用十一处计数端点和十次压力观测，连续五次满足判据后输出候选。PC以参考标定及监测开始前的独立健康区段形成经验压力—流量关系、局部健康增益和残差门限。主窗结合相对流量偏离与区段阻力变化；门限使用健康残差稳健尺度的六倍及0.06、0.6下限。阈值及配置在回放前固定，故障标签和未来输入不进入节点判定。

健康许可与数值参照分开登记。参照缺失、许可不足、压力缺测/越量程、计数窗口不完整及工作域不足有不同不可用状态；“无当前模式证据”不能显示为已经确认健康。量程内漂移、未知负载和初始故障污染健康段仍需独立参考、工况记录与人工核查，不能仅凭两个特征认定真实原因。

三秒短窗连续两次越限只触发待复核提示，主窗确认要求保持不变。先前对照中的CUSUM、区间组合及统一20秒切换暂停未取得足以替换当前基线的证据，保留为对照或边界分析；不为了叠加算法名称改变主路线。短时异常在主窗确认前恢复时，仍应记录提示与确认的不同结果。

事件触发分级采集为独立研究任务。1Hz是当前实际回放及C输入合同；2秒、5秒和更长周期属于候选设置，需要相应真实时间窗实现及独立覆盖验收，不能直接把现有逐秒内核喂入稀疏保持值。减少读取、减少无线发送与降低整机能耗分别评价，当前没有真实电流或节电比例。

## 2. 采集适配与通信语义

两路压力转换顺序进行，候选输入要求在一秒计数端点之前30ms内完成；计数锁存与端点偏差不超过1ms。这里是待实测校核的输入合同，不是已测得的总线或中断性能。原始值先检查范围，再量化为0.01kPa，防止−0.001kPa舍入为零后变成有效值。计数复位与计数端点缺失分别重建窗口；迟到端点既不能作为当前测量，也不能作为将来窗口的起点。

快照保留采集结束时刻、采样序号、配置与参照身份、计数、压力年龄、流量、测量状态及候选模式。版本2没有专用的缺失累计计数值：锁存失败时保留上一可信计数，流量写缺失，状态不可用，时序事件注明原因；本地日志保存原计数及保持标志。接收端不能将不可用快照当作新的有效计数端点。序号中断或算术保护拒绝会停止当前测量会话，不生成补齐的正常快照；后续需显式建立新的测量和通信会话身份，不能在原身份下重写时间。

普通遥测55B、事件57B、确认24B，CRC校验、COBS定界及身份/内容一致性核对保持已验证版本。主机发送端使用16业务槽、1探测槽和64审计记录；普通未确认遥测最多1条，新遥测可替代旧遥测，事件优先接纳，已接纳事件不因新遥测被删。初始发送最多8次、恢复最多4次、业务保留300秒；满事件缓存时明确拒绝。有限容量和期限意味着长中断不能保证全部送达。

接收端检查注册证据和原身份，提交SQLite后回复ACK。重复内容不改首次存储时间；冲突回滚；旧采集时刻不因重传而更新。本轮发送/接收时钟由主机回放共享，实际时钟映射仍须单独实现。CRC及ACK指纹是完整性核对，不构成身份认证。测量日志、可替代遥测和事件审计承担不同职责。

## 3. 已完成与后续验收

便携整数C内核、采集适配及主机通信参考已通过本次分项检查。216条合成轨迹、130,896次更新与独立整数参考的九字段一致，另有131,671帧编码和分段解析核对；17组输入和6组接收端定向检查通过。80组端到端回放覆盖正常、随机丢失、60秒中断及ACK全丢，具体结果与有限边界见[软件收尾报告](../deliverables/软件链路收尾验证.md)。这些输入仍来自同一合成模型，本轮是既有轨迹回归，不是新的独立实验或新种子性能评价。

此前整数版本保留三个构造临界反例；本批九字段一致不等于任意输入下浮点与整数数学等价。主机固定布局8716B不包含驱动、FatFS和栈，也不证明F103整机资源满足。完整STM32固件、目标链接、ADC/计数真实时序、SD掉电与事件预算持久化、实物RF、电流和现场健康标定分别进入实施验收，软件源文件和冻结数据可用于交接。

控制以主机状态模拟、拟用LED/蜂鸣器和硬件接口预留为本期范围。当前没有实际IO、驱动或阀门反馈；申报书不会声称自动关阀止损已完成。网站、三维模型和PPT保持各自职责，本轮不增加材料导航、业务页面或自动报告功能。
