# 一、先说结论

**方向不用换，架构不用换，但要"换三样东西"：**

1. **换定位**——从"证明我们的方法更好"改成"把一个具体问题问清楚并给出边界"。后者才是大创项目该有的样子，也才是这份材料目前唯一缺的东西。
2. **换口径**——申报书正文（权威稿 `大创申报书_正式稿6.docx`）与 `docs/` 现行文档已经**脱节**：正文写的是已否定的固定门限 0.06/0.6，承诺的却是 CUSUM h=61 的成绩；正文写的 0—20kPa / ±0.25%FS 在厂家选型表里**根本不存在**；正文还出现了 ADS1115 与 SGM58031 自相矛盾。
3. **换投入方向**——把钱和工时从"加器件、加算法"挪到"把边界测出来"。本项目真正值钱的不是检测器选型，而是**可检边界**和**结构性不可分辨**这两条结论。

**一句话**：现在这份材料读起来像一份优秀的工程技术可行性报告；它缺的是"研究问题"—"对照"—"结论"这条链，以及一批与厂家原件对不上的硬数字。

# 二、正向重建：这个项目该长什么样

## 2.1 真实用户问题

南疆棉田膜下滴灌是**轮灌**：一根支管一天只灌 1—4 小时，其余时间静压。泵工/管护员**不缺数据，缺的是"哪根支管该去看一眼"**——因为开阀关阀、供压波动本身就会让压力和流量变，跟真故障长得一样。

这句话在 `docs/项目场景与边界_大创版.md` 里写得很好，但**申报书正文一次都没出现**（已核对 docx 全文，"研究问题"0 次、"必做/争取/不做"0 次、"第几次灌水"0 次）。

## 2.2 可观测性（这次重新推的核心）

模型三条稳态关系（与 `simulation/diagnosis_feasibility.py:20-26` 一致）：

```
P0 − P1 = R·Q²        区段阻力（测点之间）
Q      = C·√P1        下游负载
Ps − P0 = Rc·(Q_A+Q_B)²   上游共同阻力
```

测 3 个量 (P0, P1, Q)，未知 3 个量。**恰好定解、零冗余**，由此得到四条硬结论：

| # | 结论 | 性质 |
|---|---|---|
| 1 | 供压变化、邻支路开关对 `K=Q/√P1`、`R̂=(P0−P1)/Q²` **严格不可见** | 模型内代数恒等，不是"鲁棒性好" |
| 2 | 泄漏与受限**正交**，可隔离 | 因为灵敏度矩阵是对角阵 |
| 3 | 受限 与 P0 传感器偏置**共线，任何算法不可隔离** | 只能靠定期标定 + 输出"待核查" |
| 4 | 二维联合检测器（T² / PCA-SPE / 马氏距离）**数学上零增益** | 对角阵 ⇒ 退化为两个独立一维问题 |

**由此直接否掉了几项既有建议**：加 BOCD（假设分段常数，而本项目故障是斜坡，模型误配）、加 PCA/SPE/马氏距离（对角阵下零增益）、加第三测点"提升检出"（只增加定位，不增加检出，未知数同步增加仍零冗余）。

## 2.3 一个被写错的因果链（本次发现的最要紧的一处）

`docs/` 与申报书都把"**差压变送器量程从 200kPa 降到 20kPa**"当成"5% 泄漏能否检出"的决定因素。**这一步推错了。**

泄漏判据是 `K = Q/√P1`，只吃 **Q 和 P1**，**根本不读差压 ΔP**。ΔP 只进 `R̂`。按同一供压档比较，Ps=160 kPa 时 R+30% 令 ΔP 从 9.17 kPa 增至 11.72 kPa；即使采用 70 kPa / ±0.5%FS，信号/U 仍约 7.3，受限侧仍有足够分辨余量。

用项目自己的参数复算（本次独立计算）：

| 项 | 数值 |
|---|---|
| `K` 的不确定度构成 | 流量计 ±1%（占 **89%**）⊕ P1 表压 0.34—0.68%（占 11%） |
| `u_K` 合成 | **1.02%—1.06%** |
| 5% 泄漏引起的 `dK` | **+5.00%**（三档一致） |
| 信噪比 | 约 **4.7—4.9 σ** |

**⇒ 决定 5% 能不能检出的，是流量计（±1% 读数），不是差压表。**
差压表的真实价值是：**避免用 200kPa 量程去测 5—10kPa 压差（量程是信号的 20—40 倍）**，让区段压降测得住——这是**量程选择问题**，不是"提高灵敏度"。

这个改写对项目是**好事**：它让"差压方案"的论证从"提高 4—8 倍灵敏度"（这句话会被厂家选型表当场证伪）变成"量程比从 20—40 倍降到 4—8 倍"（这句话查手册就成立）。

## 2.4 最能立住的创新点（建议重构为一条）

> **把轮灌切换从"要压制的干扰"改成"辨识所需的激励"。**

理由：`docs/技术路线_申报书版.md:698` 自己算出——单工况内 P1 只波动 0.256%，指数 n 的不确定度 >10，**不可辨识**；跨 80/120/160 三档后跨度约 100%，才得到 n=0.49。

也就是说：**没有轮灌带来的压力变化，连"健康"都标定不出来；有了它，才能把"负载改变了"和"泄漏了"分开**（压力补偿式滴灌带下，健康时 `n≈0`，泄漏项仍按 `√P` 走，拟合指数会向 0.5 漂移——`n` 本身就是可判别特征）。

这一条正面回答了"轮灌切换与故障怎么区分"，而且是**结构性、可证明**的，比"我们用了 CUSUM"硬得多。

⚠️ **前提必须先验**：实测手上的滴灌带是不是压力补偿式（E1 实验）。若 `n≈0.5`，这条主线失效，退回"可检边界"一条即可——**保底档照样能结项**。

# 三、最要改的七处（按杀伤力排序）

## 【1】差压量程与精度：冻结值在厂家选型表里不存在 ★★★★★

**证据**（麦克传感器 MDM490 选型资料 V6.0，2025-02 原件）：
- 量程：**0kPa～40kPa…3.5MPa**（kPa 档最小为 **40**，往上 50/60/70/…）
- 精度：**±0.5%FS（全系列唯一档）**；选型表精度代号仅 **A2 = ±0.5%FS**
- 过压：正压端 ≤2 倍满量程，**负压端不允许过压**
- 长期稳定性：±0.5%FS/年（≤200kPa）
- 厂家明确建议：**在被测点与变送器之间安装三阀组**

**结论**：`docs/硬件选型与BOM冻结.md` 与申报书 p136/p137/p204 写的 **0—20kPa、±0.25%FS（优先 ±0.1%FS）三个规格全部无出处**，且"±0.1% 升级 +300—800 元"也无依据（单晶硅 ±0.075—0.1% 实价 2800—6500 元）。

**怎么改**（见修改计划 P0-1）：量程以 **40 kPa 为早期故障分辨优先方案**；70 kPa 只能作为“覆盖严重受限全量程”的方案，不能笼统称为“保守退路”。两档精度均按 **±0.5%FS** 写实；删除“±0.1%FS 升级”；新增 **三阀组 + 排气阀**（厂家明确建议，且水介质下引压管积气是最大零点误差源）。

两种选择对应两个不同目标：

| 量程 | U=0.5%FS | 按现有线性化核算，5% 变化的信号/U（Ps=80/120/160 kPa） | 判断 |
|---|---:|---:|---|
| 40 kPa | 0.20 kPa | **2.4 / 3.6 / 4.8** | 三档均过项目判定线 2，但 80 kPa 档仅有 **1.2 倍**余量 |
| 70 kPa | 0.35 kPa | **1.4 / 2.1 / 2.8** | 80 kPa 档不过线，120 kPa 档也只略高于线 |

> 上表沿用项目当前的线性化信号值。完整耦合水力模型会把 5% 引起的 ΔP 增量算得更小，因此不会推翻“40 kPa 更适合早期变化、70 kPa 会牺牲低供压档分辨能力”的方向性结论；最终必须由 P1 小试定标。

受限故障的量程覆盖（统一按 Ps=160 kPa 计算）：

| 受限程度 | ΔP (kPa) | 40 kPa 档 | 70 kPa 档 |
|---|---:|---|---|
| 健康 | 9.17 | ✓ | ✓ |
| R +30%（当前声称可检下限） | 11.72 | ✓ | ✓ |
| R +300% | 31.31 | ✓ | ✓ |
| R +900%（设计上限） | **60.51** | ✗ 输出超量程（但未过正压端 2×FS） | ✓ |

**⇒ 对“大创早期故障诊断”这一主目标，40 kPa 更合适：保住低供压档的分辨能力，严重受限即使输出饱和也仍能报警，只是不能继续定量。只有当项目明确要求把 R+900% 仍作定量测量时，才选 70 kPa，并接受低供压档 5% 差压变化不可分辨的代价。**

## 【2】申报书正文与 docs 已脱节，且有一处"写了自己已否定的判据" ★★★★★

已直接解包权威稿核对（338 段 / 233 非空段）：

| 项 | 权威稿现况 | docs 口径 | 判定 |
|---|---|---|---|
| 判据门限 | p178 明写 **0.06 / 0.6**（固定门限） | CUSUM **h=61** | **正文写的是旧判据** |
| CUSUM / h=61 | **0 次** | 主文档核心结论 | **正文完全没写** |
| 差压量程精度 | **0—20kPa / ±0.25%FS** | 同上（但厂家无此档） | **两处都错** |
| 模数转换 | p139/140/141/192 写 **ADS1115**；p126/239/288 写 **SGM58031** | SGM58031 | **正文自相矛盾** |

## 【3】"5% 不可分辨"的双路径互证不成立 ★★★★★

`docs/技术路线_申报书版.md:570` 与 `立项阶段总验收记录.md:188` 都宣称："5% 不可分辨"由**解析核算**与**注入实验**两条独立路径互相印证，"这是最强的自洽证据"。

实际：

| 路径 | 结论 |
|---|---|
| 解析核算（附二第 2 环） | 5% 变化的信号/U = 9.7 / 14.5 / 19.4，**三档全部"✓ 达标"** |
| 注入实验（`E6_E7_v2.txt`） | 5% → **0/10** |

**两者结论相反，不是互证。** 真正原因是：`E6_E7_v2` 全程只在 **h=61 一个门限**下跑；`E7`/`F2` 显示 U 从 0 到 5 kPa 全部 10/10、无失效拐点——**传感器不是瓶颈，h=61 这个"为零误报而设"的保守工作点才是**。

**⇒ "泄漏 8% 可检 / 受限 30% 可检"不是物理边界，是 ROC 曲线上的一个点。**
而项目**至今没有做过任何门限扫描**（`诊断算法客观评价.md:122-126` 已自陈）。这是本次认为**回报最高、成本最低**的一处修改：纯离线扫一遍，1—2 天。

## 【4】"干管参照"的作用说反了，且掩盖了一个真实盲区 ★★★★☆

按模型，`P0−P1 = R·Q²` 只含**本区段阻力 R**，**不含**上游共同阻力 Rc。所以：

- 供压变化、邻支路开关对 `K`/`R̂` **严格不可见**（结构性结论，值得大写）；
- 反过来，**"用干管参照做差分"不但没收益，还会引入噪声**。

`results/F1_F2.txt` 的实测正是如此：加参照后扰动段误报从 10/40 **升到 40/40**（改善 −300%），σ=10kPa 时 7/40 → 10/40。

但 `docs/技术路线_申报书版.md:373-381` 把它写成"改善不显著（−12%~+20%，属噪声范围）"，README 写"负结果"。**两处口径不一致，且都没有给出机制解释。**

**正确的写法**：理论预测零收益，实测为负，**理论与实测一致**——这是把负结果变成正面证据的机会，不是需要遮掩的东西。

**同时暴露一个必须写进正文的盲区**：本测点布置只能看到 **P0—P1 之间**的区段。**上游（支管阀、竖管、干管到 P0 之间）的故障结构上不可见**。若要做上游区段，需把测点前移到干管（测 `P干 − P0 = Rc·Q²`），那是**定位能力**，不是检出能力。

## 【5】LoRa 频段与功率在中国不合规 ★★★★☆

- 模块 E220-400T22D：22 dBm ≈ **160 mW**，默认频点 **433.125 MHz**（亿佰特官方页）
- 工信部《微功率短距离无线电发射设备目录和技术要求》（2019 年第 52 号公告附件）：
  - **433.05—434.79 MHz：10 mW (e.r.p)**（通用无线遥控类）
  - **470—510 MHz：50 mW (e.r.p)**，但限**民用计量仪表类**、须具备**发射前搜寻（LBT）**、**单次发射 ≤1 秒**

**160 mW 是 433MHz 免执照限值的 16 倍。** 申报书 p149 白纸黑字写着 22dBm，属于可被直接指出的合规问题。

**建议处置**（见修改计划 P0-6）：台架阶段 **≤10 dBm + 单包远小于 1 秒**，正文写明"按微功率设备管理要求设置，实测功率与占空比留档"；若需远距离再评估 470—510 MHz 路径并说明适用类别。**对通信工程专业，这一段反而是加分项**——说明你知道频谱是有管制的。

## 【6】软件完成度被高估，且 MCU 侧几乎是空白 ★★★★☆

- `firmware/` 只有 4 个文件 380 行，**全是带 `#ifdef BUILD_HARNESS` 的主机可编译 C**，无一行 HAL/ADC/定时器/串口/Flash 代码（已核对：全仓库 `.c/.h` 仅 4 个，grep HAL/ADC/TIM/USART 唯一命中是注释）

- **4 套并行传输队列**（`reliable_outbox` / `session_transport` / `recovery_transport` / `admission_transport`），其中后两套 428 行**从未接入运行时**

## B. 硬件：改 6 项，删 4 项

**改**

| 项 | 改法 | 理由 |
|---|---|---|
| 差压量程/精度 | **首选 40 kPa / ±0.5%FS**；70 kPa 仅作“严重受限全量程定量”选项 | 厂家无 20/35 kPa 与 ±0.1%、±0.25% 档；70 kPa 在 80 kPa 供压档会失去 5% 差压变化分辨能力 |
| 三阀组 + 排气阀 | **新增（必装）** | 厂家明确建议；负压端不允许过压；引压管积气是最大零点误差源 |
| 测点口径 | "干管参照"改为 **P1 表压测点（必需，装在差压低压侧同点）** | `integer_diagnosis.h:35` 的诊断内核签名要 `p0,p1`；装在干管上则 P1 不可推导，`K` 算不出来 |
| 流量计 | SEN0549 保留，**脉冲流量标定 + 压损曲线 + 健康 `C_eff(P1,Q)` 稳定性**立为独立阶段 | `u_K` 的 89% 来自流量测量；流量计在 P1 下游，压损不进入 `R̂` 回路，但若压损不是稳定平方律，会使健康 `C_eff=Q/√P1` 随工况漂移 |
| 电源 | MP2359 → **MP2331H**（MPS 官方推荐替代）或 3.3V 改用 LDO | MP2359 已被 MPS 标注 **NRFND（新设计不推荐）**；且两级 DC-DC 给 16bit ADC 供电，纹波直接进测量 |
| MCU | **STM32F103C8T6 先定型**，GD32 作为国产化复验（BOM 已列） | README 现在两可，构建系统必须先锁定一个；GD32 有 BOOT0 必须下拉、供电窗口 2.6—3.6V、Flash 时序差异 |

**关于 SEN0549 压损的正确机制**：它位于 P1 下游，因此自身压损不会进入 `ΔP=P0−P1`，不能说“污染 `R̂`”。在健康状态下应写成 `P1=H_meter(Q)+H_load(Q)`。若两项都近似稳定平方律，则流量计压损只会被合并进健康负载系数，标定即可吸收；只有当 `H_meter(Q)` 明显非平方律、随工况/介质漂移，才会使 `C_eff=Q/√P1` 随 Q 漂移并伪装成泄漏。SEN0549 是电磁原理、无涡轮叶轮，预期压损风险低于收缩明显的涡轮式流量计，但厂家没有给压损曲线，不能把“预期较低”写成已证事实，必须小试。

**删**

| 删 | 理由 |
|---|---|
| ±0.1%FS 精度升级（300—800 元） | 厂家无此档；且 `K` 不读 ΔP，对正式泄漏判据**零收益**；70 kPa 档下 R+30% 的受限信号在同一供压档比较仍约为 U 的 3.6—7.3 倍 |
| 孔板差压通道（200—500 元） | 第二只耐静压 ≥160kPa 的差压实价 600—1500 元（预算低估 3 倍）；且与"0—2kPa 微差压耐不住 160kPa 静压"自相矛盾 |
| 下游第三测点（80—350 元，按"提升检出"立项） | 只增加定位不增加检出；若要保留须**按"定位"立项**，别按"检出" |
| BOCD / PCA-SPE / 马氏距离 | BOCD 假设分段常数，与斜坡故障模型误配；PCA-SPE/马氏在对角灵敏度矩阵下**数学上零增益** |

**阀态感知（3—16 元）——保留但改性质**：只作**实验真值标注**（给"流量阶跃自识别"提供对照标签），**不进运行判据**。因为 `未确认项处置与执行计划_技术路线详解.md:119` 已把"不依赖外部阀态信号"写成项目技术增量，装它进判据等于自己拆自己的卖点。

## C. 算法与实验：改 4 项，补 4 项

**改**

| 项 | 改法 |
|---|---|
| 门限标定 | `h = 1.10 × max(健康峰值)` → **按目标 ARL₀（如"≤1 次/小时误报"）反解**；极值统计量随训练集规模漂移，不是稳定估计量 |
| 判据结构 | "10 点均值 → 门限 → 连续 5 次确认"三级串联 → **单级 CUSUM**（EWMA λ=0.2 等效窗 9，叠在 10 点均值上变 19，这正是 EWMA 提前量只有 5 秒的真因） |
| 严重度口径 | 泄漏按**流量偏离**、受限按**阻力增量**，**分列**，不要并成一列"5/10/15%" |
| 评估指标 | 只报"中位提前量"（只对成功试次算，有存活者偏差）→ 改报 **MDFS（固定误报预算下的最小可检幅度）+ 带删失的 TTD** |

**补（按"不做就无法立论"排序）**

| 实验 | 判定什么 |
|---|---|
| **E1 实测滴灌带压力—流量指数 n**（≥3 压力档） | 是否压力补偿式；**决定 §2.4 主线成不成立** |
| **E2 健康残差功率谱/自相关**（≥2 h 含真实切换） | 残差是白噪声还是有色的；直接决定 CUSUM 门限该定多少 |
| **E3 流量计增益稳定性**（含沙水/长时/直管段） | ±6% 漂移就足以独立触发泄漏门限——**泄漏通道最大的单点脆弱性** |
| **E4 门限扫描（纯离线，1—2 天）** | 把"一个工作点"变成"性能边界曲线" |
