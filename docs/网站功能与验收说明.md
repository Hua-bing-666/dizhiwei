# 运行网站功能与验收说明

2026-10-04。主站为 `deliverables/index.html`；学术仿真、参考文献、三阶段材料、PPT和讲稿保留在独立的 `研究与答辩资料.html`。总体执行依据见《项目总规划与任务验收台账》。两页面离线运行，打开仓库或完整压缩包时保留目录关系。

## 六模块的实际职责

| 页面 | 用户可以做什么 | 数据与限制 |
|---|---|---|
| 运行总览 | 查看P0/P1趋势、Q、诊断解释、测点关系及最近维护记录；记录候选异常 | 一个配置支管，事件数来自本地已记录事件，真实LoRa未接入 |
| 支管监测 | 查看同一回放时刻的P0/P1/Q和操作条件；进入独立三维安装布局 | 数值为A06/A07 v1、seed10300带噪合成观测；K/R̂为原模型10点均值特征，状态来自已保存诊断；非实物读数 |
| 异常事件 | 记录异常、去重、搜索/筛选、查看、处置、复测与人工演示归档 | 标明本地演示、未发送、无无线ACK；归档不修改模型状态 |
| 设备与链路 | 查看计划节点、未连接接收端、未来设计链路和当前已实现软件流程 | 没有模拟RSSI、实际丢包率、在线时间或设备功耗 |
| 历史记录 | 分页查看当前时刻之前的合成观测；CSV导出；追溯人工操作并导出工作区JSON | 模型时刻和人工操作时间分开保存；处理备注历史不被最新输入覆盖 |
| 系统设置 | 保存本地显示名称与安装备注，查看参照和模型阈值，进入资料/三维/说明 | 不更改既有模型阈值以生成虚假表现；档案不改写已保存快照 |

回放控制共用一个场景、噪声级、质量状态和时刻。六场景×四噪声对应冻结的24条带噪观测轨迹；每条601个模型采样点不是601次独立实测。可播放/暂停、拖动或重置，切换场景、进入事件详情或标签隐藏时暂停。离线与无效状态下不能播放，也不显示当前有效读数，历史曲线仍明确为合成观测。

## 维护与保存规则

只有候选异常、待检查或质量问题可以记录事件，健康参照建立中和未见持续偏离不生成异常。同一模型版本、场景、噪声和连续候选片段去重；旧版本事件保持原快照，不与新版合并。记录瞬间的P0/P1/Q、参照、质量和模型时刻冻结；后续回放移动不改写快照。

必须先记录已查看，再填写处置备注。有复测结论时必须填写依据或暂缓原因；当前离线/无效时不允许录入恢复归档。恢复结论是**人工演示输入**，不是算法自动判定，不改变回放诊断，也不证明真实恢复。原始事件、查看和多次处置操作分别带人工时间及模型时刻，ACK不由“已查看”按钮生成。

本地档案与事件保存在当前浏览器localStorage。JSON和CSV包含来源、非物理数据标记和版本/参照信息。记录不可读或浏览器拒绝保存时，显式提示仅本次内存，不自动覆盖不可读原记录。更换浏览器/文件路径、清理站点数据或无痕模式可能失去记录，重要演示需导出。当前没有服务端、同步、登录或真实设备数据存储；实施期按规划接入串口和SQLite。

## 高标准验收口径

检查六页面在375/768/1024/1440宽度下的导航、选中态和根页面溢出；实际覆盖24条回放选择、质量门控、播放暂停、事件去重、处置门槛、快照不变、跨页记录、刷新保存、搜索/筛选、设置与实际导出文件。浏览器会收集脚本异常及外部HTTP请求。原研究资料页及三维查看器另行执行既有检查，避免新版主站替代旧材料证据。

视觉复核重点为信息归属、曲线单位与图例、控件和文字大小、卡片对齐、窄屏换行、弹窗可访问与无重叠；使用真实浏览器截图检查，不能只凭HTML语法过关。采用现有ui-ux-pro-max技能的操作型界面指导，统一深色导航、浅色工作区、绿色主操作、蓝色参考曲线和少量橙色候选提示，图标采用统一自绘SVG。
