# 采集周期选择与前期验证

2026年10月5日。读取周期不能只按“几分钟一次”决定：故障演变时长、流量计数窗口、测量误差与正常负载切换共同决定响应。压力间歇读取期间没有新压力观测，STM32不能仅凭尚未读取的压力变化自动唤醒。拟采用定时压力观测、连续硬件脉冲计数及异常加密读取，首先验证调度策略，不以整机深度休眠作为核心交付。

已有研究提供的是比较思路。[Lozoya等，Sensors 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8402102/)用土壤水分和模型预测下一次采集，在山核桃微喷灌场景比较周期与非周期通信；其标定周期或通信收益不能直接搬到支管故障诊断。[Water 2023的高频压力泄漏研究](https://www.mdpi.com/2073-4441/15/6/1187)使用高频压力和流量数据，说明不同信号机理需要不同时间尺度；本项目不将低成本集总模型写成负压波定位，也不据此要求采用同样的高频配置。

本期候选以1秒读取建立基线，正常读取比较5、10、30、60秒，同时以更长间隔检查漏检边界；异常加密以1秒作为初始配置。完整记录和无线发送独立配置，正常上报60秒仅为候选。流量保持10秒计数窗口，记录真实窗口及压力转换时刻，不把十秒滚动量说成瞬时流量。

## 回放设计与结果

冻结原480条合成轨迹，对固定高频、固定低频、仅调整上报和5→1秒分级读取四组作配对比较，共1920条策略结果。标定区间、健康参照和特征规则一致；持续确认采用经过时间与至少两次实际观测，未读取的数据不补成连续观测。连续流量计数在此为拟实现硬件条件，合成流量数值不是实测脉冲或ADC数据。

在压力随机噪声0.3kPa、故障相位固定的模型下，固定高频监测区间读取471次；分级方案正常、泄漏、受限场景平均读取218.2、393.2、399.8次。两故障各20条分级回放满足有效早期条件，但固定60秒读取的泄漏组为0/20。正常扰动同样可能触发加密，已有结果不支持“触发只发生于故障”。

改变监测起始相位后的两故障回放结果如下。每种周期的相位数不同，分母必须保留；相位回放与噪声轨迹复用均不算独立实物重复。

| 正常读取间隔 | 满足有效早期条件/相位回放数 |
| --- | --- |
| 5秒 | 200/200 |
| 10秒 | 240/240 |
| 30秒 | 240/240 |
| 60秒 | 240/240 |
| 120秒 | 179/240 |
| 300秒 | 98/240 |
| 600秒 | 18/240 |

固定60秒组的相位敏感结果与固定相位示例不同，说明不能用单一故障时刻宣称周期优劣。当前故障为模型中的180秒渐进变化，结论不外推到短时破裂或真实棉田。仅调整上报的方案也能减少发送，部分故障下发送次数少于分级方案，故不宣称分级策略在所有指标上占优。

## 实施阶段如何确定周期

先在借用仪器支持下完成压力与流量标定，再用独立故障操作和正常扰动选择触发参数；正式评价使用留出批次，不在评价数据上反复调参。每组保存读取时刻、压力转换、计数窗口、记录和发送次数，并报告误报、漏检、首次持续正确提示、有效提前量及远端延迟。若响应不足，调整读取间隔、触发或保持条件，再以新的独立批次复核。

整机能耗另行测量，相同供电、传感器配置和运行时长下记录各回路电压、电流与时间。无线突发、持续脉冲计数、压力回路、SD写入及触发监测的开销纳入测量；没有可信原始记录时，仅报告读取/发送数量，不折算节能率或续航。原始结果及配置位于simulation/event_sampling_review；因果检查的测试覆盖范围按程序与记录说明，不把少量软件检查称为形式化证明。
