# 滴智卫桌面版 V1.3

可直接双击 `滴智卫_V1.3.exe`，或将 `滴智卫_桌面版_V1.3.zip` 解压到一个普通文件夹，双击里面的 `滴智卫.exe`。两种形式的功能相同，无需打开命令行或安装 Python、GCC、数据库软件。单文件形式首次启动需要展开程序资源，速度通常慢一些；文件夹形式请保留同目录的 `_internal`。建议将单文件放入自己的普通文件夹，避免与其他版本共用数据目录。

运行环境为 Windows 10／11、64 位，以及 Microsoft Edge WebView2 Runtime。当前制作和验证电脑已安装运行时。其他电脑如果缺少，可从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Runtime。桌面版使用 [pywebview](https://pywebview.flowrl.com/guide/freezing) 和 PyInstaller 打包，运行时通过本机回环地址连接内置服务，不需要部署服务器。

## 使用

启动时会自动连接本地后台。首次打开可点击总览中的“新建回放”，或展开“回放控制”，选择场景与噪声档位，点击“新建会话”，再手动推进或开启自动回放。八个页面分别提供运行概览、压力与流量监测、事件核查、设备接口说明、历史记录、策略与标定实验、三维台架和配置说明。自动回放可以暂停；10× 表示软件演示速度，C 诊断仍逐个处理 1 秒样本。重新打开后，已有会话作为历史记录显示，需要演示时建立新会话。

监测页分别展示 kPa 压力和 L/min 流量，可切换最近 3 分钟、10 分钟或全部数据，悬停查看读数，按 Ctrl 并滚动鼠标缩放。缺测点保持断线，候选标记来自同一会话的事件记录。事件核查不会改写算法快照。

历史记录页面可导出 CSV 和 JSON，点击后使用 Windows 保存窗口选择位置。三维台架可加载概念装配，点击 P0、P1、Q 读数聚焦对应测点，选择部件检查包络，或查看受限、泄漏与健康扰动的试验路径；不需要连接 CAD 软件。显示的合成读数与当前会话同步，不代表台架实测。

顶部按钮和设置页可切换浅色、深色。外观及曲线范围独立保存，重启后恢复，不修改诊断参数。图表使用随包保存的 ECharts，模型也在本地，运行时不从 CDN 下载资源。

## 数据保存

正常情况下，数据保存在 EXE 旁边的 `data` 文件夹：`operations.sqlite` 保存采样、事件、核查和控制请求；`preferences.json` 保存外观与曲线范围；`desktop.log` 记录桌面程序异常；`webview` 保存界面浏览器配置。菜单“文件 → 打开数据文件夹”可找到实际保存位置。若目录不允许写入，则保存到 `%LOCALAPPDATA%\DizhiweiDesktop\data`，菜单和“帮助 → 关于滴智卫”显示该位置。

关闭窗口或选择“文件 → 退出”会关闭本地服务和 C 诊断进程。备份或搬迁记录前先关闭程序，然后复制整个 `data` 文件夹。更新版本时保留数据文件夹，不要以压缩包内容覆盖已有数据库。重复双击同一份程序会回到已打开的窗口。

## 当前范围

桌面版沿用现有 C 诊断核心、CRC16／COBS 协议和 SQLite 保存机制。界面里的回放数据、策略对照和清水台架模型属于软件验证材料。没有新增实物传感器、串口、LoRa 射频接入或真实阀门驱动，控制请求仍是软件演示。桌面打包不会改变这些验证边界。

源代码入口为 `desktop/app.py`，打包配置为 `desktop/dizhiwei.spec`；构建依赖见 `desktop/requirements.txt` 和 `desktop/build-lock.txt`。开发构建使用 Windows x64／Python 3.10 和 GCC；安装构建依赖后，运行 `python scripts/build_desktop.py`。构建会先生成程序文件，再合并到交付文件夹，不删除已有 `data` 记录。普通使用者不需要这些开发工具。
