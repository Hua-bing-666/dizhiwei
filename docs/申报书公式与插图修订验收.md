# 申报书公式与插图修订验收

2026年10月5日。对已审阅的语言与范围修订稿进行局部编辑，另存`deliverables/大创申报书_公式与插图修订稿.docx`。原申报书、学校模板、九节结构、四张表格及个人信息留空状态保持。

## 公式编辑

水力模型、负载特征和阻力估计的四条核心公式改为原生Office Math结构；压力及负载下标、估计帽符号、单位分式和噪声符号同时统一。共27个公式或数学对象，其中四个为核心等式。分式、根式、上下标及帽符号采用对应结构，不用图片、文本框或普通字符模仿。

依据[微软关于Office公式格式的说明](https://support.microsoft.com/en-us/word/editing-equations-created-using-microsoft-equation-editor)，采用OMML供内置公式编辑器处理。实际在本机WPS打开、重新保存并导出PDF，WPS公式对象API识别27个对象；对保存后的全部公式重新解析，核对每个对象的数学含义与源表达一致。页面复核确认根号范围、上下标、分子分母和估计帽显示完整，没有因公式增加行高而出现文字重叠。

正文整体字号不缩小。工作包编号WP1等保留普通文字，压力测点P0/P1与工作包编号分别处理；四表完整性及PDF文字复核均通过。

## 图片与文字

更新系统结构、水路、三维概念模型、采集接口、诊断流程、通信时序、噪声对照和反例分析八幅插图。只修改标注文字，原有几何、连线、统计曲线与数值不变。离线软件截图保留实际运行界面，不另画成未实现的产品效果图。

删除或改写“工作点待核”“设备包络暂定”“具体定值待验证”等零散标注。供水图用“稳压调节”表述方案功能；三维图保留“参数化概念模型”，明确其用途；接口图保留压力采样与电平转换功能，不列尚未落实的主控引脚。输入保护仍以功能块表示，未添加未经验证的保护元件定值。

诊断图以特征计算与状态判断描述流程，公式集中在正文便于编辑；阻力按“估计”表达，避免将估计量误写为真实水力参数。通信图去除尚未确定的“8次/300秒”重试上限，保留持久化、匹配确认、去重及有限重试的关系。

研究方法仍注明“拟研究流程”，噪声统计和诊断歧义图保留合成模型及必要试次说明，不将设计画成已完成的实物成果，也不删除已知失效反例。正文只作两处同步修改：删除未落实的压力器件系列推荐，以及不必要的暂定底板和管中心尺寸。原型范围、实验目标、预算、后续研究和八篇文献保持。
