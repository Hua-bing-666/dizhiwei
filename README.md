# 滴智卫

基于LoRa的南疆滴灌支管道早期故障诊断物联网原型系统。

当前项目目录只维护申报书最后一版和关键资料，历史稿按时间放在[历史分支](https://github.com/Hua-bing-666/dizhiwei/tree/codex/history-20261101)。

| 目录 | 内容 |
| --- | --- |
| [01 申报材料](01_申报材料/) | [大创项目申报书v4](01_申报材料/大创项目申报书_v4.docx)，用户确认的最后一版 |
| [02 技术图件](02_技术图件/) | 从当前申报书导出的现用图片和图件索引 |
| [03 台架模型](03_台架模型/) | 一份交互模型及可编辑模型源文件 |
| [04 算法与仿真](04_算法与仿真/) | 第八部分彩图、冻结参数、数据和独立复算资料 |
| [05 软件平台](05_软件平台/) | 桌面下载、本地运行说明及当前界面 |
| [06 硬件资料](06_硬件资料/) | 去重后的厂商原始资料与索引 |
| [07 实施计划](07_实施计划/) | 年度安排与当前维护事项 |
| [程序源码](程序源码/) | 节点、接收服务、网页、桌面与仿真研究代码 |

程序入口：在`程序源码`目录安装`requirements-platform.txt`，运行`python scripts/run_platform.py --port 8765`，打开`http://127.0.0.1:8765`。

目录说明与来源：[当前文件清单](当前文件清单.json)。历史迭代、重复路径映射及旧版本均从历史分支查阅。桌面程序与资料包见[发布页](https://github.com/Hua-bing-666/dizhiwei/releases/tag/results-20261101)。

当前基础包括水力模型、合成试验、主机测试、软件原型与台架设计。器件标定、真实水路、无线及整机电流按实施计划验证。新块级CUSUM和既有桌面诊断调用路径分别保留。
