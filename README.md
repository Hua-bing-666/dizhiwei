# 滴智卫 · DiZhiWei

面向南疆棉田滴灌支管的异常监测与无线通信研究项目；低功耗是待实测评价的目标。

当前阶段：已形成申报内容草案、文献方案及四场景简化模型仿真；尚未搭建硬件或完成台架、田间实测。仿真判据为展示用规则，正式检测方法仍待独立实验验证。

## 项目定位

以压力、流量监测节点和 LoRa 数据链路为基础，研究如何区分正常轮灌切换与支管运行异常，并比较周期上报、固定阈值事件上报和状态辅助事件上报的效果。首版采用本地固定周期测量；自适应采样在实测后另行评估。

项目尚未立项。用户确认计划执行期为 **2027 年 3 月至 2028 年 2 月**，启动预算约 2000 元，试验田需自行联系。项目优先形成可演示、可复现实验的系统原型，为大创结项和论文准备证据。具体考核要求应对照学校公开规则、后续批次通知与批准任务书。

## 首期范围

- 1 个压力、流量监测节点与 1 个 LoRa 接收端。
- LoRa 数据上报、接收端记录及基础状态展示。
- 拟搭可控水路实验平台，记录正常运行、轮灌切换、等效泄漏与节流；节流不等于真实滴头堵塞。
- 检测与上报策略对比：误报、漏报、告警延迟、通信量和整机实测能耗。
- 原始数据、标注、实验配置及分析过程可追溯。

电磁阀闭环控制、水质传感器、TinyML、大规模组网和完整云平台留待主线验证后评估。
