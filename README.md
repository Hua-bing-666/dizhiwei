# 滴智卫 · DiZhiWei

面向南疆棉田滴灌支管的低功耗无线监测与异常检测研究项目。

当前阶段：资料整理与研究范围收敛，尚无已实现的硬件、固件或算法。

## 项目定位

以压力、流量监测节点和 LoRa 数据链路为基础，研究如何区分正常轮灌扰动与支管运行异常，并比较固定周期采样、固定阈值事件采样和扰动感知自适应采样的效果。

项目优先形成可演示、可复现实验的系统原型，为大创结项和论文准备证据。结项目标日期依据原始记录暂定为 **2028 年 3 月**，具体要求需核对学校正式文件。

## 首期范围

- 1–2 个可重复使用的压力、流量监测节点。
- LoRa 数据上报、接收端记录及基础状态展示。
- 可控水路实验平台，记录正常运行、轮灌切换、模拟泄漏与模拟堵塞。
- 采样策略对比：误报率、漏报率、检测延迟、通信量和实测能耗。
- 原始数据、标注、实验配置及分析过程可追溯。

电磁阀闭环控制、水质传感器、TinyML、大规模组网和完整云平台留待主线验证后评估。
