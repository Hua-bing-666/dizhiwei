# 软件平台

[桌面V1.3下载](https://github.com/Hua-bing-666/dizhiwei/releases/tag/results-20261101)。本地保留单文件版“滴智卫_V1.3.exe”，双击运行；该EXE不进入源码仓库，GitHub提供含许可证与依赖的便携包。

源码启动：

```powershell
cd 程序源码
python -m pip install -r requirements-platform.txt
python scripts/run_platform.py --port 8765
```

浏览器打开`http://127.0.0.1:8765`。桌面源码入口为`程序源码/desktop/app.py`，打包入口为该目录内的spec和`程序源码/scripts/build_desktop.py`。
