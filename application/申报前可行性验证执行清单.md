# 申报前可行性验证执行清单

日期：2026-10-02；按用户确认“约一个月后截止”倒排，具体日期以学院通知为准。以下为待执行的工作，不是已经完成的实验。

当前优先目标：判断场景、测量与资源是否支持选题，并补最少但可信的申报证据。暂不在申报前完成整套论文实验。

## 1. 第一周：把前提变成可检查事实

| 工作 | 具体内容 | 交付/记录 | 未落实时如何处理 |
| --- | --- | --- | --- |
| 导师与任务 | 审阅研究问题、借用条件、项目周期和任务书范围 | 教师修改意见；具体指导与资源安排 | 不写“指导团队已保障”；继续寻找支持并缩小范围 |
| 编程与分析 | 明确谁能完成采集程序、时间标签、无线和分析 | 任务责任表；能够下载/运行一个采集程序的演示 | 先借成熟采集器或有线记录，减少从零研发任务 |
| 真实场景 | 至少取得一名实际使用/维护者的有效反馈，能补两类反馈更好 | 日期、对象、方式、问题原话、许可与水路草图 | 将痛点写为待调查，不引用假定损失或频率 |
| 模板与规则 | 获取正式申报书/答辩要求；核实未来评分关键口径 | 学院提供的文件及日期 | 当前只用可迁移内容稿，不冒充提交版 |
| 仪器与采购 | 列可借设备、型号、量程、误差和实际报价 | 借用联系人、费用、接口、数量、预留返工额度 | 先保测量，重新核算2000元，不先买齐所有模块 |

访谈重点：目标支管通常如何开关；供压是否恒定；怎样发现异常；是否已有报警以及如何设置；阀态、泵态是否能获得；收到何种告警会采取行动。

如果现场没有现成报警，不能写“现有系统频繁误报”；可以研究拟定监测系统如何避免正常操作误报，但应明确这是待验证的设计问题。没有进入田块时，远程反馈不能写成现场调查。

## 2. 第二周：先证明读数可信

先借水路或搭最小清水回路，有线记录即可。根据水路条件决定实际工作量程，不能照仿真120kPa、3.5L/min购买。

### 压力

- 查传感器单位、输出、量程和误差是百分比满量程还是读数。
- 在实际工作范围选择低、中、高等至少3个参考点，稳定后记录，重复上升/下降观察偏差和迟滞。
- 保留原始输出、换算值、参考表读数、仪器误差和采集时间。
- 分别记录系统偏差、重复波动和可能漂移；不能把模拟噪声标准差当作真实总误差。

### 流量

- 估算目标支路滴头总出流，检查流量计能否在该范围启动。
- 用称量或容积/时间参考，在可实现的低、中、高流量点重复测量；记录参考设备与时间误差。
- 流量小或脉冲稀疏时验证更新周期，不能默认每秒能得到高分辨率流量。

### 数据最小要求

记录试次编号、时间、原始P/Q、单位、传感器与测点、泵/阀操作、异常操作和独立出水参考。保留未滤波记录；另存处理结果及参数。先记录1秒级数据作为起点，若读数更新较慢则如实说明，不把插值数据当新增独立测量。

判断依据：目标工况的变化是否可重复、能否超出参考误差和正常波动。如果尚看不清，调整量程、布点或异常范围；不要先增加复杂AI。

## 3. 第三周：四类重复小试，另补短时切换异常

以下时长与次数是初始建议，需根据供水、传感器响应和导师安排调整。

| 工况 | 操作与标签 | 主要判断 |
| --- | --- | --- |
| 正常稳定 | 多段稳定记录，保留自然供压波动 | 正常波动、传感器误差与健康参考 |
| 正常轮灌 | A持续工作，记录B的开/关时间与响应 | 是否确有可见扰动、固定范围是否会误报 |
| 稳定期泄漏 | 可控旁路回水，独立测旁路出水 | 可观测异常程度；别把阀位当漏水量 |
| 稳定期节流 | 分别记录相对P测点的上游/下游位置 | 响应和故障原因歧义，不能直接称滴头堵塞 |
| 切换期间异常 | 在正常切换后叠加异常，含一次短时操作 | 等待规则会不会漏掉事件 |

每类先约5次作为前期起点。至少另安排一次不同批次/日期或重新设置工况的检验，不随机拆相邻采样点伪造独立重复。因现场条件无法实现的工况不填“已完成”。

原仿真未覆盖停灌、传感器断线、压力接近零、节点重启或开机时已故障。原型阶段要单独记录这些状态并设计无效数据/初始化处理，不能让异常值默默进入正常学习。

## 4. 第四周：冻结小试方法，形成可提交证据

用第一批正常/异常记录确定参数，再到另一批测试；每组允许同等阀态、供压与校准信息。至少比较固定阈值、切换等待、压力归一化流量和候选规则；压力归一化只在测点/负载假设合理、压力有效时使用。

按事件记录：发生次数、发现次数、漏检、标签外新告警、本地延迟及故障前是否已亮旧告警。小试数量少时展示原始计数和全部曲线，不只展示平均“准确率”或仅保留成功事件。

如果候选没有必要增量，申报书仍可写拟研究与比较，论文问题则需要调整；不将“算法更复杂”当成改进。

## 5. 项目书/PPT可使用的证据包

- 一页需求/操作调查与水路图，明确访谈或现场方式。
- 实物初样照片和具体接线/接口记录。
- 标定及重复性记录，含参考设备、单位和误差。
- 正常与异常的实测原始曲线、操作时间与可见范围。
- 至少一个独立批次的初步方法对照，包含失败情况。
- 已落实导师/编程/仪器支持，以及核价后的预算。
- 简化仿真用于解释假设与决定实验；与实测分开标注。

若截止前只有文献和仿真，材料可以如实形成研究计划，但不称“已验证可行性”。导师评估是否足以申报该级别，并据实写未落实条件。

## 6. 立项后再完成的内容

真实LoRa与告警确认/重发、整机能耗、更多供压/异常幅度、漂移/信息失配、独立测试、许可下田间正常轮灌、论文写作与投稿。正式任务书将具体数量、性能目标和验收方法与小试依据对应，不能仅写全部“待定”。
