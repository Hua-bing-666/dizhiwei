# 申报材料使用说明

2026年10月5日。最新申报文件为20页学校模板申报书语言与范围修订稿，面向南疆规模化棉田膜下滴灌支管巡检。13页实施项目书为此前执行参考稿。材料用于导师审阅和申报准备，尚未提交或立项。

1. 打开本目录[学校申报书](大创申报书_语言与范围修订稿.docx)。保留原封面、九节正文、说明和审批区，9图、4张居中的可编辑表及8篇完整文献（5篇中文、3篇英文），表题与表头居中。正文重写了研究范围、系统方案、实验评价、已有基础与后续发展。封面及登记信息全部留空，用户后续填写；正文没有团队或导师个人信息。原有本地DOCX未覆盖。
2. 打开[实施项目书](实施项目书.docx)或[PDF](实施项目书.pdf)：9章、5图、6张表，列明四工作包、实验协议、资源、进度、退出返工及归档。它是此前自主执行参考稿，后续细化需同步本次更明确的棉田支管研究对象。学校正式任务书下载目前返回验证码HTML，尚未套入官方表；批次与批准信息明确后填写正式任务书。
3. 打开[index.html](index.html)：六模块运行平台共用冻结合成回放、人工事件与维护记录。异常先记录、核查，再填处置和同工况复测；人工状态不改变模型诊断。离线及无效状态不能归档。数据保存在当前浏览器，保存失败或损坏会提示；换浏览器或移动文件前导出JSON/CSV。
4. [历史研究与答辩资料](研究与答辩资料.html)保留原文献库、历史统计和草案PPT，不作为最新申报材料入口。[收集优化三维模型](台架三维结构交互模型_收集优化候选版.html)用于概念布局和检修讨论，不用于加工下单。各文件在目录中独立打开，运行网站不再链接这些材料。
5. 本次检查见[语言与研究范围验收](../docs/申报书语言与研究范围修订验收.md)及[当前验收记录](申报书语言与范围修订验收记录.json)：20页实际图像已复核，所有图注与图同页，四表完整居中，正文未缩字号。第8、12、18页分别因完整图、完整实验表及经费正文结束而保留必要留白。此前[分页复核](../docs/申报书分页与图片复核.md)及[表格文献修订](../docs/表格文献与材料职责修订验收.md)只对应各自历史版本。[材料职责与修订标准](../docs/材料职责与本轮修订标准.md)划分各项内容。具体实施继续参考[总台账](../docs/项目总规划与任务验收台账.md)及[三阶段标准](../docs/三阶段分项执行与验收标准.md)。
6. 原[材料包](申报材料与证据包.zip)与证据清单保留上一轮25页、17篇文献版本，本次请使用上列修订文件。运行网站自身为独立HTML；共享三维模型、研究资料或证据时仍需保留对应目录和文件。最新文字与构建快照在application/language_scope_revision，此前分页快照在application/compact_layout_revision，application/table_reference_revision及application/quality_release保存历史记录。仓库不含用户参考案例原件及个人身份信息。

当前依据为未标定模型、概念几何、候选器件、主机协议检查和合成数据软件，不是实物、射频、功耗或田间证据。480个合成试次复用基础噪声；20/20不能当实测准确率。模型失败及未知负载不可辨识已保留。新增20秒取样需先标定有效容量≥440mL；长时实验另设排水。20,000组理想脉冲枚举不含漏计及实际计量误差。
