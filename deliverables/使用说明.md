# 申报材料使用说明

2026年10月5日。本轮最新文件为25页学校模板申报书格式优化稿及13页实施项目书。材料用于导师审阅和申报准备，尚未提交或立项。

1. 打开本目录[学校申报书](大创申报书_格式优化稿.docx)；[PDF](大创申报书_格式优化审阅版.pdf)用于查看固定版面。保留原封面、九节正文、说明和审批区，9图、4张可编辑表及17篇完整文献。身份、专业代码、意见、级别与签字必须据实补齐。
2. 打开[实施项目书](实施项目书.docx)或[PDF](实施项目书.pdf)：9章、5图、6张表，列明四工作包、实验协议、资源、进度、退出返工及归档。它是自主执行稿，学校正式任务书下载目前返回验证码HTML，尚未套入官方表。批次与批准信息明确后填写正式任务书。
3. 打开[index.html](index.html)：六模块运行平台共用冻结合成回放、人工事件与维护记录。异常先记录、核查，再填处置和同工况复测；人工状态不改变模型诊断。离线及无效状态不能归档。数据保存在当前浏览器，保存失败或损坏会提示；换浏览器或移动文件前导出JSON/CSV。
4. [研究与答辩资料](研究与答辩资料.html)集中放文献、历史统计和草案PPT；运行网站与答辩页面分开。[收集优化三维模型](台架三维结构交互模型_收集优化候选版.html)用于概念布局和检修讨论，不用于加工下单。
5. [本轮验收报告](../docs/全量复核与格式优化验收报告.md)和[验收记录](格式优化与实施项目书验收记录.json)列明修正项与限制。具体执行看[总台账](../docs/项目总规划与任务验收台账.md)，分项通过条件看[三阶段标准](../docs/三阶段分项执行与验收标准.md)。
6. 解压[完整材料包](申报材料与证据包.zip)，保留目录后打开deliverables/index.html。仅发送单个HTML会缺失三维、材料与证据链接。源稿及版式记录在application/quality_release，公开到本私有仓库的文件不含用户案例原件及个人信息。

当前依据为未标定模型、概念几何、候选器件、主机协议检查和合成数据软件，不是实物、射频、功耗或田间证据。480个合成试次复用基础噪声；20/20不能当实测准确率。模型失败及未知负载不可辨识已保留。新增20秒取样需先标定有效容量≥440mL；长时实验另设排水。20,000组理想脉冲枚举不含漏计及实际计量误差。

预算2000元是启动估算，依赖已有电脑、借用参考仪器与连续水源；压力器件待确认等级与报价。国内候选资料与淘宝入口见[硬件核对](../docs/国内硬件选型与可行性核对.md)，图片不是已购买实物，链接不保证库存和价格。

参考文献17篇，中文11篇、英文6篇，来源见[文献核验](../docs/参考文献核验与正文对应.md)。原24页学校稿、6页范围草案和15页PPT保留为历史版本；后续按稳定的最新正文同步PPT，不能把本轮文档检查说成PPT已更新。

提交前由真实团队与导师确认成员分工、参考仪器、水源、场地、报价、早期判据和批准目标，核对2027批次规则及正式模板。研究10分是成果目标，需要未来适用政策和成果时间认定；本材料不保证国家级立项、发表或收录。
