# 01_slide

本次采用老师提出的题目，研究对象保持在滴灌支管，但交付扩大为感知、有限诊断、可靠告警和管理确认的一套原型系统。周期为二〇二七年三月至二〇二八年二月。当前已有的是文献、模型与程序，没有实物和田间实验。场景图是目标部署概念，标出了两压力点、总流量、节点和接收端，并非现场或样机照片。

# 02_slide

系统面向支管巡检，应告诉管理者监测支管是否需要检查、依据是什么、何时发现。主研究下游等效泄漏和支管等效受限，正常供压与切换作为对照，信息不足时输出待检查。南疆是拟部署场景，现场需求和适用性仍待调查。

# 03_slide

已有研究包括滴灌间接检测、阀态模型、LoRa试验平台和农业事件通信。本项目不能以这些技术名称当作创新。拟通过实验研究增加参考测点和工况信息带来多大增益、早期可观察到什么程度，以及可靠上报的代价。这些是候选研究问题而非已证明的贡献。

# 04_slide

四个工作包依次完成测量依据、诊断方法、可靠告警与系统验证。工作量涵盖模型、标定、嵌入式、协议、管理软件和独立实验，不只交付一个模块。每个任务都有对应证据，扩展节点和自动阀控不放进基础验收。

# 05_slide

P0位于监测区段入口，P1位于目标受限元件下游，Q包含下游负载和泄漏总流量。平方律假设下可以用归一化流量与压降流量比形成简单强基线，新增压力点有望改善供压与局部受限的歧义。差压偏置和未知正常负载仍会混淆，需要校准、状态记录和不确定输出。

# 06_slide

图示两类从三百六十秒开始渐进的模拟故障，十五个百分点的流量偏离是为了说明评价定义而设定的演示失效判据，不是作物受损阈值。早期必须参照该判据，报告正确提前发现、前期误报和未成功试次。正式水路需要独立参考测量冻结程度与失效标准，还要测本地和远端两段时间。图中七十六秒和一百二十六秒是种子一〇三〇〇这一次模拟的提前量，分别对应四百零九到四百八十五秒、三百九十六到五百二十二秒；不是二十个种子的中位数。

# 07_slide

这里保留此前一千九百二十次单压力模型的公平通信回放，四策略使用相同检测、载荷与确认。慢周期有竞争力，噪声可使原始事件大量发送。帧数不能代替能耗，误差相对本地模拟量。新双压力诊断与这套通信证据尚未合并，因此端到端实物验证仍是研究任务。

# 08_slide

双压力假设检验包含六个场景、四种压力噪声和二十个种子，共四百八十次。在低噪声理想条件下能提前发现，但噪声为十千帕时两类均只有十二次满足无前期误报且正确提前发现。漂移和未知正常负载即使低噪声仍能误报。重复主要改变噪声，不能报告为实物识别率，也不证明优于强基线。

# 09_slide

软件是系统工作的一部分，提供设备档案、支管示意、趋势、事件证据、处理确认和回放导出。信息无法辨因、测量无效和节点离线分别处理，防止把没有数据当作正常。当前展示网页没有连接真实硬件，最终还要实现接收日志和管理状态持久化。界面按当前离线网站功能重绘，数据卡来自四百五十秒合成记录，完整曲线和游标用于回放，不是实时设备数据。

# 10_slide

实验首先校核两传感器差压误差与故障信号的关系，再做两类型、三供压、三程度和三个独立操作的主要网格，预计五十四次，正常及切换另做。参数在预实验确定，按独立日或批次测试，保留强基线和消融。随后测真实无线与整机能量，并进行八小时连续台架和掉电恢复。这里的数量都是计划，提交前需要导师核对。主要故障组合每组至少三次，因此总量至少五十四次；正常和切换对照另做。

# 11_slide

三四月解决测量门槛，五六月完成主要水路实验，七八月实现无线和管理系统，九十月独立验证与论文稿，之后补实验并结项。两千元是启动额度估算，已调整为双压力配置，前提是已有电脑并可借参考仪器。没有资源证据时不保证该预算足够，论文费用另行核查。

# 12_slide

交付包括一个双压力流量节点、接收端、台架和管理软件，还包含标定标签、对照、提前量及失败案例等研究证据，以及报告、过程记录和论文稿。按争取较高级别立项组织完整任务，但级别由评审决定。论文录用与收录不作为保证，更不能把计划成果写成已有成果。田块图用于表达目标部署概念，基础结项范围仍是一节点、一接收端和双支路台架。

# 13_slide

旧单点模型给出供压下降与受限相同观测的反例，新增入口压力只能有条件改善这类歧义，定位仍只到布置的支管区段。未知正常负载增大与等效泄漏在当前模型中同形，无法只靠复杂算法辨因，因此输出需要保留待检查和数据无效，不能声称单滴头通用早期诊断。

# 14_slide

申报需要完整模板、任务、证据和资源计划；大创需要实物系统、独立实测和过程；论文只从项目提炼一个贡献。现在优先研究渐进故障辨识边界，如果没有增量，可靠通信可作为另一个候选方向。两条方向均需要真实数据与强基线，不保证发表或推免认定。
