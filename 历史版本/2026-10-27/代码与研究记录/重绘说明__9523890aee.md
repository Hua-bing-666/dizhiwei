# 第八部分图形重绘说明

本版按用户关于图面杂乱、无关元素过多的反馈重绘两张正文图，并重新检查Word实际缩印效果。沿用上轮冻结参数及已核验的仿真数据，没有重新选择更好看的种子或改动统计结果。

## 具体调整

- 图8-1取消热图和条件提前量面板，保留泄漏有效早期、受限有效早期、正常误报三个直接可比的面板。统一纵轴范围、共享坐标说明，删去背景网格、密集刻度、逐点数值和解释性副标题。
- 图8-2改为并排的两个反例面板，取消长标题、360秒竖线和密集圆圈。重合观测只用四个空心点说明，保留必要的中位数、波动带和门限线。
- 统计口径、置信区间、色带含义、模型限制放在Word图注与正文。图8-1的连线仅辅助识别三档噪声下的同一方法，不是额外插值仿真。横轴为对数刻度；同档符号轻微错位以区分完全重合的结果。
- 两图使用统一细线和克制配色。PNG为600 dpi，PDF嵌入字体，SVG保留可编辑文字。Word插图宽14.45 cm，常规标签7.2—7.6 pt。
- 修正原Word的文档网格对行距的额外拉伸；保留10.5 pt正文及原页边距。第八部分排为两页，两张主图及图注都在第一页。

## 实际参照

查阅了以下原始资料，并实际查看作者网站公开的Nature Methods图形初稿与终稿图片，比较网格、双轴、标签和图例的删减。参考仅用于设计判断，没有复制论文数据或图片进入交付物。

- [Nature 绘图规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)：坐标和单位必须清楚，避免背景网格及多余装饰，保留可编辑矢量文字。
- [Nature 稿件格式指南](https://www.nature.com/nature/for-authors/formatting-guide)：仅保留有必要且逻辑相关的面板，把符号及统计解释放在图注。
- [Nature Methods 作者公开的图形演化案例](https://mk.bcgsc.ca/points-of-significance/figures.mhtml)：实际查看其中的clarity、errorbars初稿与终稿图片，采用删减次要元素、保留核心比较的思路。

## 数据与使用范围

图8-1仍使用900条新合成观测轨迹、2700条方法记录，以及原批次324条方法记录的复现结果；新种子每组100个、三档噪声和三个场景，参数未重新调优。图8-2仍使用初始K/R模型20个原始种子的反例数据，正文展示σ=3 kPa。它们均为合成仿真，不是实物或田间测量。

10 kPa下稳健门限对两类故障均为99/100有效早期，长时正常对照误报为2/100。保留原始失败，不将零误报小样本外推为实际无误报。已验证的数据保存在evidence，仿真及绘图代码保存在code。

本轮验收包括：新图的全部数据与源统计逐项比对、色带与原数组比对、画布边界和字体检查、Word两页原生渲染后的逐页查看。没有进行实体打印测试。

## 文件与复现

使用`第八部分_图形重绘稿.docx`替换申报书相应部分。`figures`内仅保留本轮两张主图的PNG、PDF、SVG，避免与上一版图件混用。

Python 3.12；numpy 2.5.3、matplotlib 3.10.9、Pillow 12.3.0、python-docx 1.2.0。中文字体使用Microsoft YaHei。

```powershell
python code/run_simulations.py
python code/plot_figures.py
```

`run_simulations.py`包含上轮实验协议、原始算法快照和冻结参数。直接解压到任意普通目录后，保持code、evidence、figures相对位置即可复现仿真与绘图。重新生成Word时，向`code/build_document.py`传入用户提供的原始第八部分Word文件路径；文档变更后应重新渲染，不能沿用旧验收记录。
