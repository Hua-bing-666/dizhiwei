# 滴智卫项目工作区

项目名称：基于 LoRa 的南疆滴灌支管道早期故障诊断物联网原型系统。

项目面向南疆规模化棉田膜下滴灌支管巡检，研究等效泄漏、局部过流受限与正常调节之间的辨识，为维护人员提供支管和区段核查线索。拟实施期为2027年3月至2028年2月。当前属于申报准备与软件、仿真预研阶段。

## 下一步顺序

1. 统一测点位置、故障幅度定义、量程、数据来源和申报稿版本。
2. 对齐仿真、节点、CSV、接收端与桌面端，随后再重新打包EXE。
3. 复核既有结果与图片，形成参数、图表和证据一致的申报书，再制作PPT。
4. 实施阶段完成真实器件、目标固件、独立标定、台架、射频及连续运行验证。

simulation/project_review/run_all.py当前列有9个步骤，其中包含历史对照，并会覆盖结果日志与部分图件；本轮未运行。执行新实验前应保存既有结果和未提交修改。
