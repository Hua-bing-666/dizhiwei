# 材料职责与本轮修订标准

2026年10月5日。本轮调整申报书的表格、文献和运行网站的职责，不重写研究目标，也不把旧验收状态用于新文件。

| 成果 | 应呈现的内容 | 边界 |
| --- | --- | --- |
| 申报书 | 问题、文献、四工作包、研究方法、前期证据、条件、预算和预期成果 | 依学校原表填写；已完成与拟实施分开，引用精选五篇中文、三篇英文 |
| 实施项目书 | 工作分解、接口、标定、独立试次、阶段进入条件和交付责任 | 自主执行稿，获批后再填写学校正式任务书；不承担产品导航 |
| 仿真 | 假设、参数、量纲、对照、误差与反例、可复现结果 | 计算不等于实测；内部脚本和核验记录在源目录保存 |
| 三维模型 | 测点、分流、连接、支撑、计量容器、检修空间及待冻结尺寸 | 概念布局，未制造；不承载申报或报告入口，不直接指导采购加工 |
| 运行网站 | 总览、监测、事件核查、设备、历史、设置和数据导出 | 不链接申报书、项目书、PPT或验收报告；保留演示身份与未接入状态 |
| PPT | 评审讲述的问题、系统方案、研究增量、可行性与实施安排 | 内容稳定后单独更新，不混入网站操作流程 |

保留自动采集、有限诊断和事件处理等项目功能。去除产品界面里的材料导航、内部运行编号、验收入口及冗余过程说明。辅助工具不是科研创新点，工具使用与来源记录留在研究档案中；不借文案调整隐藏合成数据或未完成事项。

本轮按以下条件验收：四张数据表相对正文单元格居中；表题、表头居中且无字符缩进；长说明左对齐、预算数字居中；固定列宽不溢出，表头重复、数据行不跨页。八篇参考文献顺序重排，正文没有孤立旧编号，来源及适用限制保留。九幅现有插图保持比例和原图内容，逐页检查最终PDF，不能只检查第一页。运行网站六模块在桌面、平板、手机和横屏无整页横向溢出，事件、复测、保存及导出可继续使用；页面没有材料及报告链接。

后续按单项逐步开展：先以修订申报书供导师审阅，再按批准条件冻结实施任务；实物和独立数据具备后才进入论文验证。三维、仿真、硬件及PPT的下一次修改均另列具体目标，修改后重新验收，不因本轮文档通过就声称它们全部升级完成。
