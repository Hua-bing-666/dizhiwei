## 一、引脚定义（TO263-5L，顶视）

| 引脚号 | 名称 | 功能 |
|---|---|---|
| 1 | GND | 地 |
| 2 | EN | 使能。拉低关断，拉高开启；**悬空默认开启**（TTL 关断能力） |
| 3 | SW | 功率开关输出（开关节点），接电感与肖特基二极管 |
| 4 | VIN | 电源输入，5 — 32 V DC，需就近并大电容到地 |
| 5 | FB | 反馈。外部分压中点接此脚，反馈阈值 **1.25 V**，VOUT = 1.25 × (1 + R2/R1) |
| — | 金属背板（Metal Tab） | 内部与 SW 相连 |

## 二、关键参数（官方电气特性表，Ta = 25 ℃，Vin = 12 V）

| 项目 | 参数 | 出处 |
|---|---|---|
| 拓扑 | 升压 / 升降压 / 反激 / 反相（单反馈脚可编程正负输出） | §General Description |
| 输入电压 | 5 — 32 V（绝对最大 36 V） | EC 表 Vin；Absolute Maximum Ratings |
| SW 脚耐压 | 60 V（内置过压保护） | Absolute Maximum Ratings |
| 开关电流 | 最大 4 A | EC 表 IL |
| 开关频率 | 320 / **400** / 480 kHz | EC 表 Fosc |
| 反馈阈值 VFB | 1.213 / **1.25** / 1.287 V | EC 表 System parameters |
| 最大占空比 | 90 % | EC 表 DMAX |
| **静态电流 Iq** | **2.5 mA typ / 5 mA max**（VEN = 2 V，VFB = Vin） | EC 表 Iq |
| **关断电流 ISTBY** | **70 μA typ / 100 μA max**（VEN = 0 V） | EC 表 ISTBY |
| 内置 NMOS 导通电阻 | 110 mΩ typ / 120 mΩ max（Vin = 12 V，ISW = 4 A） | EC 表 Rdson |
| EN 阈值 | 高（开）1.4 V / 低（关）0.8 V | EC 表 VEN |
| EN 输入漏电流 | 3 μA typ / 10 μA max | EC 表 |
| 效率 | 最高 94 %（手册标称）；测试点 92 %（Vin 12 V、Vout 18.5 V、Iout 2 A） | §Features；System parameters |
| 保护 | 逐周期限流、热关断、软启动、频率补偿内置 | §Features |
| 工作结温 | −40 — +125 ℃ | Absolute Maximum Ratings |
| 热阻 RθJA | 30 ℃/W（TO263-5L，无散热片，自由空气） | Absolute Maximum Ratings |

> 注：EN 脚悬空即为开启状态。本项目用高边开关控制 24 V 支路供电，
> 若直接用 MCU GPIO 驱动 EN，需注意 XL6009 的 EN 高电平阈值为 1.4 V，3.3 V 可直接驱动。
