# XL4015 引脚定义与关键参数

> 来源：芯龙半导体（XLSEMI）官方数据手册《5A 180KHz 36V Buck DC to DC Converter
> XL4015 Rev 2.0》，文件 `XL4015_Datasheet_官方_EN.pdf` / `XL4015_Datasheet_官方_CN.pdf`
> （本目录，取自 xlsemi.com/datasheet/XL4015-EN.pdf）。

## 一、引脚定义（TO263-5L，顶视）

| 引脚号 | 名称 | 功能 |
|---|---|---|
| 1 | GND | 地。布局时须置于肖特基二极管—输出电容地回路之外，避免开关电流尖峰引入噪声 |
| 2 | FB | 反馈。外部分压电阻中点接此脚，内部反馈阈值 **1.25 V**，VOUT = 1.25 × (1 + R2/R1) |
| 3 | SW | 功率开关输出（开关节点），向输出供电 |
| 4 | VC | 内部稳压器旁通脚，经 1 μF 电容接 VIN |
| 5 | VIN | 电源输入，8 — 36 V DC，需就近并大容量电容到地 |
| — | 金属背板（Metal Tab） | 内部与 SW 相连，布线时注意高压摆率与散热 |

## 二、关键参数（官方电气特性表，Ta = 25 ℃）

| 项目 | 参数 | 出处 |
|---|---|---|
| 拓扑 | 降压（Buck），固定频率 PWM | §General Description |
| 输入电压 | 8 — 36 V | EC 表 Vin |
| 输出电压 | 1.25 — 32 V 可调 | EC 表 / §Features |
| 输出电流 | 5 A 恒定输出能力 | §Features |
| 开关频率 | 144 / **180** / 216 kHz（min/typ/max） | EC 表 Fosc |
| 短路保护频率 | 48 kHz（短路时由 180 kHz 降频） | EC 表 Fosp |
| 最大占空比 | 100 % | EC 表 DMAX |
| 最小压差 | 0.3 V | §Features |
| **静态电流 Iq** | **2.1 mA typ / 5 mA max**（VFB = 5 V） | EC 表 Iq |
| 开关管导通电阻 | 60 mΩ typ / 80 mΩ max（Vin = 12 V，ISW = 5 A） | EC 表 Rdson |
| 开关限流 | 7 A（VFB = 0 V） | EC 表 IL |
| 效率 | 最高 96 % | §Features |
| 保护 | 过流、热关断、输出短路 | §Features |
| 工作结温 | −40 — +125 ℃ | 绝对最大额定值表 |

> 说明：手册未给出「无负载待机电流」单列指标，上表 Iq 为芯片工作时的静态供电电流，
> 是评估电池侧常开损耗的直接依据。
