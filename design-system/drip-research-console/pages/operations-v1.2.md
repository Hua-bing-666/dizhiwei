# 运行平台 V1.2 页面规则

本文件适用于 application/config/workspace.json 中的八个运行页面和 V1.2 台架检查界面。它覆盖 MASTER 中研究控制台的蓝色强调色、远程字体和高密度选项；历史研究页面仍保留其原规则。

工作区为浅灰绿背景、深绿导航、白色内容卡片。正文使用本地 Segoe UI / Microsoft YaHei，离线无需加载字体。主要字号15px，说明12—13px，10—11px仅用于来源、版本与辅助坐标，不用于主要操作。重点按钮为深绿色，候选警示为棕色，质量问题为红色，状态均同时附文字。

总览给出摘要与去向，监测给出趋势与特征，事件承担人工核查。禁止为了填满页面重复完整趋势、事件列表或配置表。策略实验与台架准备独立于日常监测；申报书、答辩材料、自动验收报告不放进网站导航。

滚动渐显只作用于静态下方模块，已显示的模块不重复隐藏。主读数、诊断和操作入口立即可读。减少动态效果时取消位移和透明度变化，不使用滚动劫持或逐字动画。

手机导航局部横向滚动，当前页面项自动进入可见范围，主体页面不横向溢出。表格在局部滚动。按钮至少44px高，所有交互保持焦点环；图标用同一套原生线性SVG，旁边的文本承担可访问名称。

台架图来自207个已保存网格构件。分组与部件检查使用弱化其余构件的方式，不做爆炸位移，保持测点与水路关系。检查尺寸明确写成模型三轴包络，不写成供货规格。实验路径按钮同步视角与说明，不触发采集或物理执行器。
