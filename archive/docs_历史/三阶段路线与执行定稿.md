# 三阶段路线与执行定稿 v1.0

日期：2026-10-02。依据：现有文档、公开制度与论文、可复现合成实验。真实传感器、水路、无线、功耗和田间数据均尚未提供。

## 1. 总目标与研究判断

项目名称保持为“面向棉田轮灌工况的滴灌支管异常监测与事件触发 LoRa 通信方法研究”。用一个压力/流量监测节点、一套双支路台架和一个接收端，回答：**在轮灌操作扰动和链路不可靠条件下，怎样保留异常告警，并用合理通信开销维持远端信息质量？**

有开展应用研究的理由，但尚未证明方法创新。压力/流量监测、阀态辅助和事件通信都有先例；价值来自可重复的动态工况、强基线、相同告警可靠性规则及适用边界。已有反例说明单测点可能无法区分供压下降与上游节流，弱异常可能不可见。申报目标可有挑战，已有基础只能表述为文献、模型、程序、仿真和交互展示。

负责人内部成果目标：完成第一完成人的大创和与专业相关的第一作者论文。按用户截图，今年参考规则中省级结项4分加认可6分论文达到10分；国家级5分加6分论文封顶10分。校级3分加6分只到9分，国家级5分加4分也只到9分。未来适用规则、期刊/收录口径与取得成果期限均须学院书面确认。科研分数不写入对外项目摘要，立项级别和论文认可分值不作保证。

不承诺逐滴头早期堵塞诊断，不承诺任意异常准确率，不将“报文减少”写为“续航提升”。节流只模拟水力受限。现场未落实时以台架完成核心研究，论文中场景名称必须与证据匹配。

塔大2025实施细则显示，国/省级创新训练除报告外可选择实物或软硬件研发等成果形式，不必把论文录用绑定为唯一结项条件。校/省/国研究报告参考下限分别5000/8000/10000字，另需调研报告；最终以本批任务书为准。[官方细则](https://jwc.taru.edu.cn/info/1035/3872.htm)、[2026验收通知](https://jwc.taru.edu.cn/info/1052/4432.htm)。

## 4. 第三层：论文路线

**推荐主问题：告警保留/可靠性约束下，轮灌监测的事件通信是否提供有用取舍。** 检测器先采用可解释的强基线；只有在独立实测上确有增量，才把新检测方法作为论文主贡献。

最小论文证据：经标定原始台架数据；真实LoRa发送/接收/确认日志；同一检测器、载荷与采样；10秒周期+可靠告警、较慢周期+可靠告警、原始事件、滤波限频事件；按独立批次留出；短时事件、噪声、漂移、链路阻断与恢复；参数消融；整机能量或明确只讨论通信开销。报告漏检/误报、从故障到本地发现及从本地事件到远端收到的两段延迟、丢失事件、数据覆盖、字节/帧和实际能量。

论文图组建议：系统/布点图、代表时序、异常幅度—检出/误报边界、通信开销—误差—延迟取舍、丢包/中断恢复、独立批次结果及失败案例。无实测阶段，这些图只用于研究设计与模型分析，不能构成已完成实证论文。

2027.5开始写方法与数据协议；2027.8冻结核心实验；2027.9—10形成完整稿并在导师指导下投稿；余下时间处理返修。取得认可发表/收录可能晚于大创结项，需给未来推免截止留余量。期刊认可、费用和适配性须届时核查；2000元启动预算不包含论文版面费。

若实验只证明强基线足够、事件策略没有优势，应如实报告并调整为可观测性/部署边界研究；若只有接线和界面演示，没有独立对照，具备训练价值但不足以支持高水平方法论文。

## 5. 经费、能力与主要不确定性

2000元为启动额度估算，非实际报价：电子/无线260、传感与调理450、水路500、供电外壳250、记录耗材160、调查返工380。假设已有电脑且可借参考压力计和整机电流测量设备。若不可借，先用有线水路小试冻结需求，减少外壳和扩展功能；不要同时购买所有模块。

实际选型还需核查测量量程/精度/分辨率、低流量可用性、接头与漏水、介质兼容性、零点漂移、采样和校准、阀态来源、LoRa模块配置与当地可用频段、接收端供电、时钟对齐、掉电恢复、记录容量、传感器持续耗电、泵安全与独立标签。它们已纳入实施检查，不因仿真界面可运行而消失。

最先决定去留的是压力/流量可观测性和团队实现能力，其次才是田间布设及论文级别。负责人目前确认会焊接，嵌入式/Python能力未确认；导师与编程协作必须落实。没有现场许可时禁止把真实田间试验写为已有条件。
