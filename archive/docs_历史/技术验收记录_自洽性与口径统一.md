## 一、数值自洽性验证（能否"推出来"）

**基础参数**：`C = 0.28`、`R = 0.80`、三档供压 `80 / 120 / 160 kPa`。

| 环 | 检验内容 | 结果 | 判定 |
|---|---|---|---|
| 1 | 健康工况自洽（Q/√P1 是否恒为 C） | 三档均得 **0.2800** | ✓ |
| 2 | 差压量程与精度 | 最大健康压降 **9.33 kPa**，需量程 ≥14.0 ⇒ 选 20 kPa；信号/U = **9.7 / 14.5 / 19.4** | ✓ |
| 2b | 原方案对照 | 信号/U = 0.70 / 1.04 / 1.39，三档全 <2 | ✓（说明改差压的必要性） |
| 3 | 流量是否超量程 | 最大 **4.97 L/min**（160kPa+50%泄漏）≤ 5.0 | ✓（须注明 >50% 超程） |
| 4 | 受限工作区 | R=8 时 P1 = **98.3 kPa** ≥ 30；ΔP = 61.7 ≤ 160 | ✓ |
| 5 | 标定压力跨度 | 跨工况 **100%** ⇒ n 不确定度 0.014 ✓；单工况 0.256% ⇒ 不可辨识 | ✓ |
| 6 | 通道 / 静压 / 供电 | 2 路模拟（器件供 4 路）；耐静压 20 MPa；24V ≤40mA、5V ≈150mA、3.3V ≈81mA | ✓ |

**结论：可从基础参数一路推到器件选型与实验设计，各环自洽，无断链。**

## 二、与实际仿真数据反推比对

用 `heldout_observations.npz` 的正常轨迹（σ=0.3，B 阀关健康段，20 条）反推：

| 项 | 实测反推 | 设计值 | 判定 |
|---|---|---|---|
| 区段阻力 `R = ΔP/Q²` | **0.8004** | 0.80 | ✓ 吻合 |
| 负载系数 `C = Q/√P1` | **0.2799** | 0.28 | ✓ 吻合 |
| log-log 指数 n（跨工况） | **0.4914** | 0.5 | ✓ 吻合 |

**两套口径的预测误差对比**（以上述实测工况为基准）：

| 口径 | 预测 Q | 相对误差 |
|---|---|---|
| 未耦合近似（令 P1 ≈ Ps） | 3.0218 | 3.06% |
| **耦合精确解** | 3.0177 | **2.92%** |

**⇒ 采用耦合精确解。**

## 四、ΔP 取值口径统一

此前文档存在两套数字并存（**10.04 kPa** 与 **9.33 kPa**）。已查明来源并统一：

| 口径 | 160 kPa 档 ΔP | 来源 |
|---|---|---|
| 实测（120 kPa 档） | 6.88 kPa | 由仿真观测直接算出 |
| **耦合精确解（采用）** | **9.33 kPa** | `P1 = Ps/(1+R·C²)` |
| 未耦合近似 | 9.91 kPa | 令 `P1 ≈ Ps` 后算 `R·C²·Ps` |

**量程选择在三种口径下都成立**（9.33×1.5=14.0、9.91×1.5=14.9，均 < 20 kPa），
故该差异不影响设计结论。技术路线文档已附口径说明表。
