# 两份案例与本项目的范围调整

2026年10月3日。国家级、校级身份来自用户说明，尚未独立核对立项名单。分析对象是申报书文本及其中图表，不将文中声称的实验、奖项、合作和性能一律视为已核实事实。原文件只读保存，不把案例中的个人信息和整份文件上传仓库。

## 判断

老师提出的新题目“基于 LoRa 的南疆滴灌支管道早期故障诊断物联网原型系统”可以作为本次申报名称。原来的研究方向并非没有价值，但材料把检测和通信方法放在中心，使用者、诊断结果及系统运行过程展示不足，容易被理解为一个通信模块。改名必须对应任务变化：从单点异常提示，升级为有测量依据的有限故障模式诊断，并交付感知节点、无线接收、管理软件和完整实验资料。

这不是对立项级别的保证。没有公开依据表明“系统”名称或某个模块数量即可获得国家级；问题、研究增量、前期依据、团队能力、资源和任务一致性都需要评审。

## 国家级案例的特点

“云边协同·双车联动”围绕秸秆处理与耕管作业组织双车及无人机，明确硬件控制、数据交互、智能决策三层架构。文中包含实物图片、底板模型、电路图、模块图、平台界面等20个媒体文件，并安排模块标定、系统联调和田间综合评价。已有基础章节声称具备第一代样机、施肥机构及云监控原型，也写出试验田、数据和校准设备缺口。经费为12000元，其中材料9000、印刷3000。

值得借鉴的是围绕一个使用场景形成任务链，把软硬件、方法、实验和成果对应起来；模型图回答结构怎么实现，平台图回答数据怎样使用，测试表回答目标怎样检查。

需要谨慎借鉴：文中50ms、100ms、1.5s、3s等时延指标没有统一测量口径；5、10、15、50亩等规模没有清晰区分实验层次；部分年度工作出现早于项目起点的2025年日期。“预期成果”段落又使用“成功研制”“50亩试验田验证”等完成语气。未见足以核实所有比例和性能的原始数据或完整引用。“3厘米/100米”行走目标与“GPS误差1米”等指标的支撑关系也需要进一步解释。不能把这些写法照搬成我们的既有成果。

## 校级案例的特点

垃圾分类小车以识别、抓取、分类投放为业务链，列出硬件、算法、样机、测试、数据台账和季度工作；即使尚缺硬件，也通过模型、控制流程、数据集计划和结构建模表达前期准备。文中声称的仿真性能未附可复现记录，本次只认定为“案例文本中的声明”。

它的主要问题是前后范围漂移。项目方案写大族CR50、50kg负载、Jetson AGX Xavier、10万图像、DeepSeek-VL与YOLOv8；预期成果却写K210小车、室内识别90%、3大类10小类。还出现四类、八类、三大类十小类等不同分类口径，研究和创业推广任务混杂，经费栏空缺，已有基础部分有重复文字。因此“大系统”叙述也可能降低可执行性。不能由此推断立项级别差异的原因，更不能把堆设备当作国家级标准。

## 对照后的修改

| 方面 | 原方案容易呈现的问题 | 本次决定 |
| --- | --- | --- |
| 使用对象 | 只突出方法对比 | 面向滴灌支管运行巡检，输出异常位置范围、证据曲线、建议检查项 |
| 感知依据 | 单点P/Q原因歧义 | 采用支管入口P0、下游P1和总流量Q；阀态和质量标志一并记录 |
| 研究对象 | “异常”较宽，故障较少定义 | 主研究下游等效泄漏和支管等效受限；正常供压、切换、漂移作为挑战 |
| 早期 | 没有参照阈值 | 记录故障程度、首次可靠发现和预设失效判据，评价提前量、误报及漏检 |
| 系统成果 | 回放网页显得像展示附件 | 规划设备档案、支管示意、趋势、事件确认、回放、导出和离线故障状态 |
| 通信研究 | 发送减少容易代替低功耗 | 同检测器和确认机制对比，测真实延迟和整机能量 |
| 前期基础 | 仿真容易被误读为实测 | 程序与合成结果可追溯；台架、田间、固件和性能全部写拟开展 |
| 任务规模 | 最小样机被当作全部任务 | 一个闭环系统，两个研究问题，四个工作包，独立批次对照与报告体系 |

## 申报的层次

申报书介绍整个系统和研究任务；项目范围文件规定必做、目标、条件和阶段门槛；PPT解释评委应如何判断价值和可行性。三个材料使用同一题目、设备配置、时间、预算和证据口径。

大创结项以任务书中的系统与实验成果兑现。论文只提炼一条证据充分的研究贡献，优先评估测点与工况信息对渐进故障识别的作用，通信作为另一条候选方向。增加第二压力点和使用LoRa均不自动构成论文创新。

学校2025年实施细则要求按级别提交结题报告和调研报告，省级、国家级另完成选择成果；实物或软硬件研发可以作为选择成果，论文不是唯一方式。本批次通知及任务书仍需核对。[塔里木大学实施细则](https://jwc.taru.edu.cn/info/1035/3872.htm)。
