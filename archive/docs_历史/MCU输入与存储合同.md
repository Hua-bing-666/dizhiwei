# MCU输入与存储合同

2026年10月6日。适用于本项目的固定1 Hz移植候选，关联第十轮整数诊断实现与第九轮事件优先策略。本文是模块之间的工程约定，已实现部分和后续目标在表中分开；它不替代器件标定或STM32目标编译验收。

## 一、测量输入与配置

节点接收同一计时基准下的两路压力和累计脉冲端点。内部`t=0`表示首个一秒区间已结束，协议采样序号为`t+1`、采集时刻为`(t+1)×1000 ms`；结束点逐秒递增，不能用串口到达时刻或网页刷新时刻替代。当前版本不跨越32位毫秒回绕，计数扩展溢出或采集时钟缺口必须显式开启新测量会话并重建窗口，不填补虚构样本。累计计数从当前测量会话的零基准开始，不把旧会话计数混入新窗口。

| 字段或条件 | 合同 | 实现状态 |
|---|---|---|
| 时间与顺序 | 采集端点连续1秒；重复、跳时、耗尽拒绝，原状态不改变 | C内核检查索引顺序与32位毫秒边界；硬件计时尚未实现 |
| 累计脉冲 | `uint32_t`；每秒差值用于窗口，不能用舍入流量反推；回退记质量事件并重建窗口 | C实现回退处理及450脉冲/秒算术保护；真实计数扩展与电平需驱动实现 |
| P0、P1 | 单位0.01 kPa，`int32_t`；原始非有限、越量程与时序异常分别携带质量码 | C接受质量码并清窗；采集适配器仍须在舍入前检查原值 |
| 测量时效 | 两次转换顺序完成，不复用旧结果；结束前30 ms窗口，计数锁存偏差不超过1 ms | 第七轮TimingGuard软件规则保留；总线等待、中断延迟与传感器响应未实测 |
| 有效工作域 | 所有实际压力点P1严格大于10 kPa，窗口流量严格大于0.5 L/min | C逐窗检查；量化后的域边界不等同原始浮点边界 |
| 健康配置 | 独立健康许可、数值参照、主窗及短窗门限、预测表与版本指纹 | PC校准并注册，C初始化后只读；不由数值拟合推断健康 |
| 输入排除项 | 不接收场景名、故障真值、未来测量或未读取压力 | C入口只有时刻、计数、两路压力、质量码；配置不包含故障标签 |

时序适配层先沿用[TimingGuard及Counter16参考](../simulation/acquisition_timing.py)的判据，再把有效读数转换为整数；转换未完成或计数锁存迟到时，本次读数不得作为有效压力进入窗口。输入质量码0表示有效，1表示缺失/非有限，2表示原值越量程，3表示时序失败。接近量程端点的负数可能被舍入成零，因此必须保留舍入前的质量判据；传递整数后再做一次量程检查只是第二道保护。

候选SEN0549厂家给出的±1%误差适用区间为0.3—5 L/min，540脉冲/L对应5 L/min时约45脉冲/秒；这条规格不证明5 L/min以上仍具有相同误差。内核450脉冲/秒上界是50 L/min的**算术保护范围**，不能据此拓展传感器的已知精度适用区间。采集适配层必须按实际校准结果和传感器工作域限制输入；已有高于5 L/min的合成轨迹只用于软件检查。5 V脉冲输出的电平转换和抗抖动仍是硬件联调任务。[DFRobot规格](https://wiki.dfrobot.com/sen0549/)

## 二、窗口与整数计算

十秒主窗需要十个连续有效压力点和跨越十个区间的两个计数端点；三秒复核需要三个有效压力点和四个连续计数端点。两者使用同一原始端点历史，主窗在计数回退或压力质量失败后重建，短窗自行检查其三秒内的有效性。主窗连续五次越过相应门限才输出模式；短窗连续两次越限只产生待复核提示，不替代主诊断，不触发真实阀门动作。模式0表示当前没有充分模式证据，不能写成设备已确认健康。

PC只从监测开始前的校准段生成健康参照及门限，本轮不在板端保存100条浮点样本进行中位数和MAD拟合。配置在监测前注册，以10—200 kPa、0.5 kPa间距的381个预测点替代实时幂运算，表内值单位为百万分之一L/min。压力均值保留为整数和与点数，不先舍入平均压力。流量来自`ΔC/(9n)` L/min，n为3或10，540脉冲/L仍是待实物校准的假设。

本轮PC先从历史校准段生成配置，C加载后回放历史端点预热，只从索引130开始与原算法比较诊断；没有把这段历史回放作为在线提前知道校准结果的证据。130是对齐既有参考的验证时间线，真实上线的配置加载与窗口预热另行验收，不能直接宣称所有部署都必须等待130秒。

令预测流量整数为F，泄漏门限整数为T，阻力参照和对应门限分别为R、U，参数单位均为百万分之一；压力整数和分别为S0、S1。内核使用下面两个严格比较，等号不报警：

$$\Delta C\times10^{12}>9nF(10^6+T)$$

$$81n(S_0-S_1)\times10^6>100(\Delta C)^2(R+U)$$

配置校验限制预测值、门限与R＋U，使各乘法的绝对值低于有符号64位上限；最宽的已核对上界为2,025,000,000,000,000,000，小于9,223,372,036,854,775,807。比较使用整数累计脉冲差，只有写入输出流量时才按最接近、平局取偶数舍入至0.001 L/min。表插值、压力输入及参数量化也明确舍入规则；等号严格并不意味着浮点与整数在任意边界都等价。

## 三、固定容量与持久化边界

候选布局保留16个业务槽、1个探测槽和64个完整历史槽，避免以丢弃事件或增大容量掩盖满队列。单槽预留64字节原帧及出生、派发、下次派发、来源序号和尝试状态；最新遥测原帧、测量快照及元数据另行保留。当前仅声明布局并检查尺寸，没有把SQLite迁移到STM32，也没有实现恢复发送队列。主机GCC观测的单槽为84 B，存储布局6968 B，诊断状态200 B，含预测表的配置1548 B，合计8716 B。

这个合计是本轮几个静态结构的主机观测值，不含驱动、FatFS、串口收发、任务栈、中断栈或链接对齐差异。STM32F103C8官方规格为64 KB Flash、20 KB SRAM；目标编译时要把链接映射与最坏栈占用一起核对，不能用主机sizeof断言整机可装入。[ST规格](https://www.st.com/en/microcontrollers-microprocessors/stm32f103c8)、[参考手册](https://www.st.com/resource/en/reference_manual/rm0008-stm32f103xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)

节点原始测量日志与无线业务队列分别保存：原始日志服务标定、诊断复算与论文评价，普通遥测允许被最近状态替代；事件接纳遵循第九轮规则。microSD只作为既有硬件方案中的候选日志介质，尚未实现掉电可靠性。后续持久化须在派发前可靠登记原身份与次数；掉电可能使一次预算已消耗而字节未发出，但不得使重开会话重置次数、重新获得无限预算。配置、健康许可和身份恢复也需要可验证的记录完整性及提交边界。

重启后本地毫秒计时归零，不能把旧事件的出生时刻改写成当前时刻，也不能在没有时间依据时宣布旧样本仍新鲜。300秒期限跨重启需要连续时钟证据；若无法取得，应将旧记录隔离为时间未知，不自动按新出生记录补发。实现后的验收必须覆盖写到一半、元数据与正文不同步、启动身份冲突、旧ACK晚到及计时失效；本轮没有验证这些掉电场景。
