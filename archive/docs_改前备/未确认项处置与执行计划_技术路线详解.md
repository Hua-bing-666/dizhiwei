# 上篇　未确认项逐项处置

## 一、处置原则

**关键认识：未确认项不等于风险。** 按"能否离线确定"把它们分四类，各用不同办法：

| 类型 | 定义 | 处置办法 | 是否阻塞 |
|---|---|---|---|
| **Ⅰ 可仿真确定** | 判据对该参数不敏感，或仿真能给出阈值 | **软件仿真先行** | 不阻塞 |
| **Ⅱ 必须实测** | 只能在自己台架上测 | 列为**本项目产出**（不引用外部） | 不阻塞申报 |
| **Ⅲ 只能现场问** | 公开检索不到，需合作单位 | 列入**对接清单**，给出替代方案 | 不阻塞申报 |
| **Ⅳ 流程性** | 等通知、走流程 | 列入**日历提醒** | 不阻塞 |

> **核心思路：把"不知道"转成"我要去测"，从引用变成产出。** 这既解决无据问题，又增加项目的工作量证据。

### S2　轮灌切换时长、末端压力衰减时长

| 项 | 内容 |
|---|---|
| **为何查不到** | 这是具体团场的运行参数，一般不公开发表 |
| **类型** | **Ⅰ 可仿真确定**（关键判断） |
| **处置** | ① 申报书**删除**"1—5 分钟""1—8 分钟" |
| | ② 改为"阀门切换的过渡过程为**秒级**，本项目在台架上实测其持续时长" |
| | ③ **把"切换过渡时长"列为本项目要测的参数**（变成产出） |
| | ④ 仿真做**敏感性分析**：切换时长取 1/3/5/10/30 秒，看误报率变化 |

**为何可以这样处置（量化依据）**：

把问题转成"切换持续多久才会被误判为故障"。CUSUM 的累积规律是：

```
S_t = max(0, S_{t-1} + z_t − k),  k=0.5,  门限 h=5
```

| 残差偏移 δ（标准差） | 累积到 h=5 所需步数 | 秒数（1Hz） |
|---|---|---|
| 1.0 | 10.0 | **10** |
| 2.0 | 3.3 | **3.3** |
| 3.0 | 2.0 | **2.0** |
| 5.0 | 1.1 | **1.1** |

**结论**：
- 轮灌切换的物理过程是"**阀动作（秒级过渡）+ 阀到位（长稳态）**"，**不是持续 60—300 秒的扰动**
- 过渡过程只有数秒 → 累积来不及到 h=5 → **不误报**
- **⇒ 只要过渡过程在数秒量级，判据就不会把切换误判为故障，且这个结论不依赖"切换到底几秒"**

**这反而是个项目亮点**：仿真若能证明"在 1—10 秒范围内误报率都低"，就等于证明了**判据对该参数不敏感**——**"不需要精确知道"本身就是一个有价值的结论**。

## 一、总体架构（已确认）

```
        ┌─ 台架 A 支路（被测支管） ────────────────────────┐
水源 ─→ P0 上游取压 ─→ 受限元件 R ─→ P1 下游取压 ─→ 流量计 Q ─→ 正常出流
   │                                      │                └─→ 泄漏旁路（可控）
   │                                      └─ 与 P0 一起接差压变送器
   │
   └─→ 干管参照测点 P2（第 4 路，看趋势）

   差压变送器(4-20mA) ─┐
   干管压力(4-20mA)  ─┼─→ 150Ω 取样 ─→ 16 位 ADC ─→ I²C ─┐
                       │                                   │
   流量计 Q(脉冲) ─────┴─→ 施密特整形 ─→ 定时器计数 ──────┤
                                                          ↓
                                                 主控（STM32F103 / GD32F103）
                                                          ↓
                      LoRa(E220) ←── USART ───────────────┤
                                                          ↓
                      microSD ←────── SPI ────────────────┘
```

**与原文的差异**：压力从"两路表压相减"改为"**一路差压 + 一路干管参照**"。测量链更简单（2 个模拟通道），且新增了干管参照。

## 二、水力模型（已确认）

### 2.1 基本关系

```
区段压降：ΔP = P0 − P1 = R · Q²
下游负载：Q = C · √P1
```

其中：压力 kPa，流量 L/min，`R` 单位 kPa/(L/min)²，`C` 单位 (L/min)/√kPa。

### 2.2 两个可解释特征

```
K  = Q / √P1          下游等效负载系数（与 C 同量纲）
R̂  = (P0 − P1) / Q²    区段等效阻力
```

**依据**：`Q = C√P1` 与 `ΔP = RQ²` 是流量-压力标准关系（项目引用文献 [2][3] 及灌溉学报的 `q = k·h^x` 形式）。

### 2.3 为什么 R̂ 与 K 能区分故障类型（**技术路线的核心**）

| 现象 | R̂ 的变化 | K 的变化 | 判别 |
|---|---|---|---|
| **等效泄漏** | 基本不变 | **增大**（分流增加） | K 升 → 泄漏 |
| **等效受限** | **增大**（阻力增加） | 基本不变 | R̂ 升 → 受限 |
| **正常供压调整** | 变化 | 变化 | **两者同向**，比值关系保持 |
| **邻支路开关** | 变化 | 变化 | 同"正常供压调整" |

**⇒ 分类依据是"两个参数相对健康参照的变化方向"，不是两个独立阈值。**

**这条是技术路线里最有价值的推论**，而且可演绎、可解释。当前设计取值：健康 `C=0.28`、`R=0.8`；泄漏时 C 增至 0.37；受限时 R 增至工作区上限。

## 三、判据设计（已确认 + 待仿真确认）

### 3.1 双时间窗（保留原设计）

| 窗 | 样本构成 | 确认规则 | 作用 |
|---|---|---|---|
| **主窗** | 11 个计数端点 + 10 次压力观测（10 秒） | 连续 **5** 次同标签 | 输出"已确认模式" |
| **短窗** | 3 个压力点 + 4 个计数端点（3 秒） | 连续 **2** 次越限 | 输出"关注提示" |

**依据**：项目内部已验证（144 条轨迹、62,892 条记录、130 个短窗事件与参考一致）。

### 3.2 检测统计量（**建议升级，待 E2/E3 确认**）

**现状**：固定阈值 `e_Q > 0.06`、`e_R > 0.6` + 连续确认。

**建议**：CUSUM（累积和）

```
归一化： z_t = (残差 − 中位数) / s,  s = 1.4826 × MAD（健康段稳健尺度）
累积：   S_t = max(0, S_{t−1} + z_t − k),  k = 0.5
报警：   S_t > h,  h 由目标 ARL₀ 反推
```

**为什么 CUSUM 更优（有理论依据）**：
- 对"变化幅度未知"的检测问题，**CUSUM 在给定虚警率下使最坏情况检测延迟最小**（Lorden 1971 最优性）
- **可直接设定 ARL₀（平均误报间隔）**，把"1 次/小时"从事后统计变成**设计输入**
- 天然支持渐进故障：累积小偏差，不等单点越限

**与文献的关系**：同类研究已在用 BOCD / PELT-BIC / PELT-AIC / CUSUM 作变点检测（Benavides-Muñoz 2026）。本项目用 CUSUM 属**对齐主流**，不是落后。

### 3.3 工况自适应：参照差分而非暂停（已确认思路）

| 做法 | 原理 | 效果 |
|---|---|---|
| **干管参照差分** | 用 P2 归一化，扣除共同扰动 | 供压波动残差被抵消 |
| **多工况门限表** | 按 P1 档与 B 状态分档标定 | 不同工况不共用阈值 |
| **切换期降敏不断档** | 切换期提高门限但继续检测 | 保留故障检出 |
| **负载未知时输出"待检"** | 不强行分类 | 避免误报 |

**为什么不用"暂停判断"**：项目内部已有反例——统一 20 秒切换暂停把低噪声快速切换泄漏的有效早期从 **20/20 降到 0/20**。暂停会丢故障。

### 3.4 流量阶跃检测（**新增，解决 S6**）

**原理**：轮灌切换的物理本质是**流量阶跃到零或从零上升**，而泄漏/受限是**缓慢持续偏差**。

| 现象 | 时域特征 | 判据 |
|---|---|---|
| **轮灌切换** | 1—2 个采样内跳变 | **阶跃检测**：\|ΔQ\| 超阈值且方向与轮灌顺序一致 |
| 泄漏/受限 | 缓慢累积 | CUSUM |

**价值**：**不依赖外部阀态信号**，从流量数据自身识别切换时刻。若合作团场阀态不可得（S6），这是替代路线；若可得，两者互为验证。

## 四、测量链设计（已确认 + 待询价）

### 4.1 为什么必须改成差压（量化依据）

| P1 (kPa) | 健康 ΔP | 5% 变化的 ΔP 变化 | 原方案不确定度 | 信号/不确定度 |
|---|---|---|---|---|
| 80 | 5.02 | 0.51 | 0.74 | **0.70 ✗** |
| 120 | 7.53 | 0.77 | 0.74 | **1.04 ✗** |
| 160 | 9.33 | 1.03 | 0.74 | **1.39 ✗** |

**原方案在三档下全部不可分辨。**

改成差压后：

| 差压量程 | 精度 | U | P1=80 | P1=120 | P1=160 |
|---|---|---|---|---|---|
| 35 kPa | ±0.25%FS | 0.088 | 5.9 | 8.8 | 11.8 |
| **20 kPa** | **±0.25%FS** | **0.050** | **10.3** | **15.4** | **20.6** |

**量程约束**：量程必须 ≥ 最大健康 ΔP × 1.5 = 9.33 × 1.5 ≈ **15 kPa**
⇒ **可选档只有 20kPa 与 35kPa**（10kPa 会超量程）

### 4.3 流量通道的已知限制（已确认）

**540 脉冲/L 的分辨率**：

| 窗口 | 4L/min 脉冲数 | 量化步长 | 相对分辨率 |
|---|---|---|---|
| 1 s | 36 | 0.11111 L/min | 2.778% |
| **10 s** | 360 | **0.01111 L/min** | **0.278%** |
| 30 s | 1080 | 0.00370 L/min | 0.093% |
