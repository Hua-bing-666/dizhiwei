# 块一　测量方案与硬件（回答：用什么测、能测多准）

## 1.1 本块重点

**一句话**：把"能不能看出 5% 的流量变化"这个立项前提，变成一组**能买到、买得起、装得上**的器件参数。

## 1.2 技术做法

### （1）测点布置

```
　　　　　　P0（上游取压）　　　　　　　　P1（下游取压）
　　　　　　　　│　　　　　　　　　　　　　　│
水源 ──── 干管 ─┴─── 受限元件 R ────────────┴─── 流量计 Q ──→ 正常出流
　│　　　　　　　　　　　　　　　　　　　　　　　　　　└──→ 泄漏旁路（可控）
　│
　└─→ P2（干管参照测点）　　差压 = P0 − P1 由差压变送器直接测得
```

**四路信息**：差压 `ΔP = P0 − P1`（1 路）、干管参照 `P2`（1 路）、流量 `Q`（1 路脉冲）、以及由 `P0` 与 `ΔP` 得到的下游压力 `P1`。

### （2）为什么必须用差压而不是两只表压相减

| 方案 | 不确定度 U | 5% 信号/U（P1=80/120/160 kPa） | 结论 |
|---|---|---|---|
| 两只 0—200 kPa 表压相减 | 0.74 kPa | 0.70 / 1.04 / 1.39 | ❌ 三档全不可分辨 |
| 单只 0—35 kPa 差压 | 0.088 kPa | 5.9 / 8.8 / 11.8 | ✅ 达标 |
| **单只 0—20 kPa 差压** | **0.050 kPa** | **10.3 / 15.4 / 20.6** | ✅ **最优** |

**根因**：原方案用 200 kPa 量程测 5—10 kPa 压差，**量程/信号 = 20—40 倍**，而精度按满量程百分比给出，误差必然等比放大。**这是架构级问题，换更贵的表压表治不了。**

### （3）量程约束（决定可选的档位）

健康压降 `ΔP = R·Q²`，在 160 kPa 供压档达 **9.33 kPa**。量程须留 1.5 倍过载余量：

```
量程 ≥ 9.33 × 1.5 ≈ 15 kPa
⇒ 可选档位只有 20 kPa 与 35 kPa（10 kPa 会超量程）
```

# 块二　水力建模与标定（回答：用什么量刻画健康与故障）

## 2.1 本块重点

**一句话**：建立"压力—流量—阻力—负载"的可计算关系，并**验证它在本项目的测量条件下真的可辨识**。

## 2.2 技术做法

### （1）基本模型

```
区段压降：  ΔP = P0 − P1 = R · Q²          （R 单位 kPa/(L/min)²）
下游负载：  Q  = C · √P1                    （C 单位 (L/min)/√kPa）
```

### （2）两个可解释特征

```
K  = Q / √P1            下游等效负载系数
R̂  = (P0 − P1) / Q²      区段等效阻力
```

### （3）★关键推导：为什么单一工况下不可辨识

联立消元：

```
P1 = Ps − Rc·Q² − R·Q²            （串联阻力：上游共同阻力 Rc + 本支管阻力 R）
Q  = C·√P1                         （负载关系）

代入：  P1·(1 + (Rc+R)·C²) = Ps
   ⇒    P1 = Ps / (1 + (Rc+R)·C²)
   ⇒    Q  = C·√Ps / √(1 + (Rc+R)·C²)
```

**核心结论**：联合量 **β = (Rc + R)·C²** 一个标量决定一切。

> **⇒ 在单一工况下只能辨识 β，无法把上游共同阻力 Rc 与本支管阻力 R 分离。**

**实测印证**：`Q/√P1` 全程恒为 **0.280**（即 C 可辨识），而 `(P0−P1)/Q²` 中混着 `Rc` 的成分——**这正是"上游供压变化"与"本支管故障"在单支管测点上不可分的数学原因**。

### （4）标定方案（由此推导）

单一工况内 P1 只波动约 0.3%（实测），在此跨度上拟合 log-log 斜率完全由噪声支配：

| 拟合窗口 | 得到的指数 n |
|---|---|
| 20—119（单一工况内） | **−0.228**（错） |
| 20—175 | −0.049（错） |
| **跨工况 20—359** | **+0.4915**（正确） |
| 本项目采用（跨工况联合） | **+0.4755** |

**因此标定必须跨工况**：

```
供压档 × 阀态 = 至少 6 个工况点
本项目采用：80 / 120 / 160 kPa 三档供压，跨档压力跨度约 100%
```

**标定步骤**：
1. 每档供压下、每种阀态下，采集 ≥5 个流量点 × 3 次重复
2. 双向标定（升压、降压各一遍）
3. 联合拟合 `Q_ref = a·(P1/100)^n`，得 `n` 与 `a`
4. 求健康增益 `gain = median(Q / Q_ref)` 与 `r₀ = median(R̂)`
5. 求稳健尺度 `s = 1.4826 × MAD`

## 2.3 可行性验证

| 验证项 | 方法 | 通过准则 | **当前证据** | **不通过怎么办** |
|---|---|---|---|---|
| 模型是否成立 | 用仿真观测反推模型参数 | 与设计值一致 | **实测反推 R=0.79、C=0.280、n=0.49**，与 R=0.8/Cₙ=0.28/n=0.5 一致 | 改用 `ΔP = R·Q^m` 并重新拟合 m |
| 指数可辨识性 | 计算不同跨度下 n 的不确定度 | 跨度足够时不确定度 ≤0.05 | **跨度 1%→不确定度 1.00；20%→0.0055** | 增加供压档数或扩大单档流量范围 |
| 标定可重复 | 3 次重复标定的残差 | 残差 < 目标信号 1/2 | 健康残差尺度 `s_Q=0.0025`、`s_R=0.015`（远小于阈值） | 加长平均窗、改善安装 |
| 流量计压损可分离 | 实测压损—流量曲线 | 曲线可重复、可写入标定记录 | 已识别问题：压损 0.5—10 kPa 与 5% 信号同级 | **必须实测压损曲线**并作为 R̂ 的已知分量扣除 |

**本块结论：可行，但有一处必须补做。** 模型成立且参数已用实测反推核实；**唯一必须补的是"流量计自身压损曲线实测"**——否则压损会污染 R̂ 估计。

# 块三　健康参照建立（回答：健康的基准怎么定）

## 3.1 本块重点

**一句话**：健康基准不能是一个固定点，必须是一个**按工况分档的参照族**。

## 3.2 技术做法

### （1）为什么必须分档（实测依据）

轮灌切换的实测表现（`normal|0.3` 首条轨迹，B 阀 180—299 开）：

| 时段 | P0 | P1 | Q | **C = Q/√P1** | **R̂ = (P0−P1)/Q²** |
|---|---|---|---|---|---|
| B 阀关（早） | 116.6 | 109.7 | 2.931 | **0.280** | **0.79** |
| **B 阀开** | **104.1** | **98.5** | **2.780** | **0.280** | **0.79** |
| B 阀关（晚） | 116.7 | 109.7 | 2.933 | **0.280** | **0.79** |

**轮灌切换使 P0 骤降 10.7%、Q 降 5.2%，但 C 与 R̂ 恒定不变。**

> **⇒ 切换是"换了一个工况点"，不是故障。绝对阈值会被这种大变化误触发，而基于"C 与 R̂ 不变性"的判据不会。**

### （2）参照族的构造

```
健康参照表 = { (P1 档, 阀态) → (gain, r₀, s_Q, s_R) }
```

| 维度 | 分档方式 |
|---|---|
| 供压档 | 80 / 120 / 160 kPa（或按 P2 实测值动态分箱） |
| 阀态 | 由灌溉计划 / 阀态信号 / **流量阶跃自识别**得到 |

**漂移判据（本块的核心设计）**：

```
残差 = 同档内实测参数 − 该档健康参照
     e_Q = Q / (gain·Q_ref) − 1
     e_R = R̂ − r₀
```

### （3）工况识别（不依赖外部阀态信号）

**原理**：轮灌切换的物理本质是**流量的阶跃**（一个采样内跳变），而故障是**缓慢持续偏差**。

| 现象 | 时域特征 | 判据 |
|---|---|---|
| **轮灌切换** | 1—2 个采样内跳变 | **阶跃检测**：\|ΔQ\| 超阈值且方向与轮灌顺序一致 |
| 等效泄漏 | 缓慢累积 | CUSUM |
| 等效受限 | 缓慢累积 | CUSUM |

**⇒ 即使合作团场拿不到阀态信号，也能从流量数据自身识别切换时刻。**

### （4）标定窗口的纪律（本次仿真的教训）

**必须避免"把故障当健康"**。本项目采用的健康窗口：

```
健康窗口 = [(20,175), (200,298), (305,355)]     ← 全部 t<360（故障起始）
```

**这是本次仿真的直接教训**：早期版本把 `(300,599)` 当健康窗口，而故障从 t=360 开始，导致参照被污染、门限被低估（h=5 时健康段误报 40/40）。

## 3.3 可行性验证

| 验证项 | 方法 | 通过准则 | **当前证据** | **不通过怎么办** |
|---|---|---|---|---|
| 工况可分 | 用参数不变性区分切换与故障 | 切换时 C、R̂ 变化 < 噪声尺度 | **实测 C 恒 0.280、R̂ 恒 0.79** | 改用工况标签直接分档 |
| 参照充分 | 每档健康样本量 | ≥100 个有效点 | 健康段可用 155+98+50 = 303 点 | 延长健康观测或并入相邻档 |
| 未污染 | 参照窗口不含故障期 | 窗口全在故障前 | 已修正为 `t<360` | 用留出法交叉检验 |
| 阶跃可识别 | 在台架上做阀门开关 | 检出跳变且不误判为故障 | 理论依据充分，待台架实测 | 退用阀态信号或灌溉计划 |

**本块结论：可行，且是本项目的判断核心。** "参数不变性"这一条把轮灌切换与故障在原理上分开，是本路线最有价值的设计。

# 块四　诊断算法（回答：怎么判、门限定多大）

## 4.1 本块重点

**一句话**：用**双参数方向判别 + CUSUM**，并把门限**由误报率反推**，而不是拍定。

## 4.2 技术做法

### （1）判据框架

```
输入：ΔP、P2、Q（1 Hz）
  ↓
① 质量门控：越量程 / 缺测 / 计数复位 / 时间错位 → 不合格则输出"无法判断"
  ↓
② 特征：K = Q/√P1、R̂ = (P0−P1)/Q²
  ↓
③ 工况识别：流量阶跃检测 + 干管参照 P2 → 得工况标签
  ↓
④ 分工况参照：取该档 (gain, r₀, s_Q, s_R)
  ↓
⑤ 残差归一化：z_Q = e_Q/s_Q，z_R = e_R/s_R
  ↓
⑥ 双路 CUSUM：S_t = max(0, S_{t−1} + z_t − k)，k = 0.5；S > h 报警
  ↓
⑦ 分类：K 升而 R̂ 平 → 泄漏；R̂ 升而 K 平 → 受限；两者同升 → 待检查
  ↓
⑧ 输出：模式 + 支管编号 + 测点区段 + 建议检查部位
```

### （2）为什么用 CUSUM

| 理由 | 依据 |
|---|---|
| **最优性** | 对"变化幅度未知"的检测问题，CUSUM 在给定虚警率下使最坏情况检测延迟最小（Lorden 1971） |
| **可设计** | 门限由目标虚警率反推，把"1 次/小时"从事后统计变成**设计输入** |
| **适合渐进故障** | 累积小偏差，不等单点越限 |
| **对齐主流** | 同类研究已用 BOCD / PELT / CUSUM 做变点检测 |

### （3）★门限的确定（本项目仿真的核心产出）

**方法**：用干净健康段标定 → 算健康段的 CUSUM 峰值分布 → 取峰值最大值 ×1.2 作为门限。

**第一组结果：健康段 CUSUM 峰值分布**（40 条/档）

| σ (kPa) | P50 | P90 | P99 | 最大 |
|---|---|---|---|---|
| 0.3 | 25.53 | 39.24 | 43.69 | 43.71 |
| 1.0 | 23.64 | 34.50 | 43.99 | 46.37 |
| 3.0 | 24.62 | 35.02 | 44.90 | 46.96 |
| 10.0 | 26.92 | 37.51 | 50.51 | **50.55** |

```
健康段峰值最大 = 50.55
⇒ 推荐门限 h = 50.55 × 1.2 = 60.7 → 取整 h = 61
```

**第二组结果：门限扫描验证**（leak 类，σ=1.0）

| 门限 h | 健康段误报 | 故障段检出 |
|---|---|---|
| 5 | **40/40** | 40/40 |
| 10 | 40/40 | 40/40 |
| 15 | 38/40 | 40/40 |
| 20 | 26/40 | 40/40 |
| 30 | 10/40 | 40/40 |
| 40 | 2/40 | 40/40 |
| **60** | **0/40** | **40/40** |
| 80—200 | 0/40 | 40/40 |

> **⇒ h=61 给出"健康零误报 + 故障全检出"的干净分离。**
> **同时说明：原设计的固定阈值（e_Q>0.06、e_R>0.6）在此数据上对应门限过低，属于拍定，缺乏误报率依据。**

**第三组结果：推荐门限下的四类判别**（h=61）

| 故障类型 | σ=0.3 | σ=1.0 | σ=3.0 | σ=10.0 |
|---|---|---|---|---|
| leak（泄漏） | 40/40，t=376 | 40/40，t=377 | 40/40，t=382 | 40/40，t=394 |
| restriction（受限） | 40/40，t=371 | 40/40，t=378 | 40/40，t=388 | 40/40，t=410 |
| drift（漂移） | 40/40，t=383 | 40/40，t=400 | 40/40，t=427 | 40/40，t=499 |
| load_unknown（负载未知） | 40/40，t=376 | 40/40，t=377 | 40/40，t=382 | 40/40，t=394 |

**健康段误报全部为 0/40。**

### （4）最小可检幅度（本次仿真）

**泄漏**（注入窗口 t=205—285，标定窗口不重叠，h=61）

| 相对流量增量 | 检出率 | 中位检出 t |
|---|---|---|
| 1%—5% | **0/10** | — |
| **8%** | **10/10** | 234 |
| 10% | 10/10 | 224 |
| 15% | 10/10 | 216 |
| 20% | 10/10 | 214 |
| 30% | 10/10 | 212 |

**⇒ 本配置下泄漏的最小可检幅度约为 8%。**

**受限**（相对阻力增量）

| R 增量 | 检出率 | 中位检出 t |
|---|---|---|
| +10% | 1/10 | — |
| +20% | 8/10 | 352 |
| **+30%** | **10/10** | 333 |
| +50% | 10/10 | 322 |
| +100% 以上 | 10/10 | 312—316 |

**⇒ 受限的最小可检幅度约为 +25%—30%。受限比泄漏更容易检出**（因为 ΔP 对 R 是线性的，而泄漏对 Q 是平方关系）。

### （5）幅度 × 时长 二维边界（本次仿真）

| 幅度\时长 | 5 s | 10 s | 20 s | 40 s | 60 s |
|---|---|---|---|---|---|
| 3% | 0/10 | 0/10 | 0/10 | 0/10 | 0/10 |
| 5% | 0/10 | 0/10 | 0/10 | 0/10 | 0/10 |
| **10%** | 0/10 | 0/10 | **7/10** | **10/10** | 10/10 |
| 20% | 1/10 | 10/10 | 10/10 | 10/10 | 10/10 |
| 30% | 6/10 | 10/10 | 10/10 | 10/10 | 10/10 |

**读法**：
- **5% 在任何时长下都不可检** → 与块一的核算一致，**原申报书的 5% 目标不成立**
- **10% 需持续 ≥20 秒**才能可靠检出
- **20% 只需 10 秒**
- **30% 在 5 秒内已有 6/10**

### （6）测量不确定度的敏感度（本次仿真）

注入 20% 泄漏、持续 80 秒，叠加不同水平的压力测量噪声：

| U (kPa, 1σ) | 检出 | 误报 |
|---|---|---|
| 0—0.10 | 10/10 | 0/10 |
| 0.15—0.30 | 10/10 | 0/10 |
| 0.50—1.00 | 10/10 | 0/10 |

**⇒ 在 U ≤ 1.0 kPa 范围内，判据对测量不确定度不敏感。**

**这是一个有价值的结论**：说明 **20% 量级的故障用普通工业变送器就能测出**；同时也说明判据的瓶颈在**故障幅度**，不在传感器精度。

> **须补做**：把 U 继续加大到 2—5 kPa 找失效点，让敏感度曲线出现拐点。

## 4.3 可行性验证

| 验证项 | 方法 | 通过准则 | **当前证据** | **不通过怎么办** |
|---|---|---|---|---|
| 门限有依据 | 由健康段 CUSUM 峰值反推 | 健康段零误报 | **h=61 → 健康 0/40、故障 40/40** | 提高 h 或延长平均窗 |
| 四类可分 | 在四类轨迹上测检出与误报 | 泄漏/受限能区分，漂移/负载未知不误判 | 四类均 40/40 检出，误报 0/40 | 增加干管参照差分 |
| 最小幅度 | 注入 1%—50% 泄漏 | 给出明确的分界线 | **8% 可检、5% 不可检** | 目标调整到 10% 并写入申报书 |
| 时长边界 | 幅度 × 时长网格 | 给出二维边界 | 已得 5×5 网格 | 加密网格 |
| 不确定度需求 | 叠加 0—1 kPa 噪声 | 找到失效点 | **1 kPa 内均达标** | 扩到 5 kPa 找拐点 |

**本块结论：可行，且已得出明确边界。** 关键结论是**"5% 不可检、8%—10% 可检"**——这比硬报"识别率 95%"更可信，也直接决定了申报书目标该怎么写。

# 块五　通信与组网（回答：数据怎么传、丢不丢）

## 5.1 本块重点

**一句话**：在 LoRa 的速率约束下，把"事件不丢、顺序不乱、掉电能恢复"做扎实。

## 5.2 技术做法

### （1）帧格式（协议 v2）

| 帧类型 | 长度 | 说明 |
|---|---|---|
| 公共头 | 16 B | 设备号、会话号、序号、类型 |
| 快照 | 35 B | 周期状态摘要 |
| 遥测 | 55 B | 常规周期数据 |
| 事件 | 57 B | 故障事件 |
| 应答 | 24 B | ACK |

**封装**：小端 → CRC16-CCITT-FALSE（初值 0xffff）→ COBS → 追加 0x00 定界。

**身份标识**：`设备号 + 会话号 + 序号`，ACK 在 SQLite 提交后回复。

### （2）队列与可靠性

```
发送槽：16（常规）+ 1（事件优先）+ 64（重传缓冲）
初始派发 ≤8 次，恢复派发 ≤4 次，会话寿命 300 秒
```

### （3）时间预算（关键核算）

| 项 | 数值 |
|---|---|
| E220 空中速率 | 2.4 kbps |
| 最大帧长 | 57 B |
| 单帧传输时间 | 57 × 8 / 2400 ≈ **190 ms** |
| 分包上限 | 64 B（协议约束） |
| 9600 bps 串口下发 57 B | **59.4 ms** |

**⇒ 帧长已控制在分包上限内，接收端按 COBS 定界重组。**

### （4）事件触发与周期上报的权衡

**依据**：同类研究已做"事件触发 vs 周期采集"的田间实证（3 个月，传输减少 77%）。

**本项目的差异化**：不做"事件触发能省多少"的重复验证，而是回答——

> **在"一天只有 1—4 小时有流量"的灌水节拍下，什么时机上报最划算、会不会漏掉故障？**

## 5.3 可行性验证

| 验证项 | 方法 | 通过准则 | **当前证据** | **不通过怎么办** |
|---|---|---|---|---|
| 帧长合规 | 计算最大帧 vs 分包上限 | 57 B ≤ 64 B | ✅ 已核实 | 压缩字段或分片 |
| 传输时间 | 计算单帧空中时间 | 不超时隙 | 190 ms @2.4 kbps | 提高速率或缩短帧 |
| 链路可达 | 36 次对照试验 | 送达率有实测值 | 待台架实测 | 降速率或加中继 |
| 掉电恢复 | ≥3 次断电重启 | 不丢事件、序号续接 | 已有主机端验证 | 缩短会话寿命、提前落盘 |
| 8 小时连续 | 连续记录 | 无数据缺口 | 待实测 | 缩短记录周期、加大缓冲 |

**本块结论：可行。** 帧长、速率、时间预算均已核算通过；风险集中在**掉电与会话恢复**，已有主机端验证，需在台架上复现。

# 块七　台架与实验设计（回答：实验怎么做、做几次）

## 7.1 本块重点

**一句话**：在实验室里**复现真实的灌水节拍与轮灌切换**，并在受控条件下做够统计量的故障实验。

## 7.2 技术做法

### （1）台架构成

```
A 支路（被测）：上游取压 P0 → 受限元件 R → 下游取压 P1 → 流量计 Q → 正常出流
                                                                  └→ 泄漏旁路（可控）
B 支路（模拟隔壁轮灌）：并联，可开关，用于制造真实轮灌切换
干管参照：P2 测点
台架尺寸：约 900 × 520 mm，De25 PVC-U（外径 20 / 内径 16），水路按水力等效缩比
```

**三类扰动装置**：
1. **上游扰动阀** —— 模拟供压波动
2. **B 末端可调堵塞元件** —— 模拟邻支路变化
3. **干管参照测点** —— 提供共同扰动参照

### （2）灌水节拍的复现（本块的关键）

**必须复现真实节拍**：一次灌水 0.4—1.8 小时，然后关闭，隔一段再开。

| 参数 | 取值 | 依据 |
|---|---|---|
| 单次灌水时长 | 0.4 / 1.0 / 1.8 小时（三档） | 由阿拉尔 27.5—52.8 亩/小时换算 |
| 轮灌周期 | 72 小时 | 十二团实测 |
| 停灌期 | 流量为零，管道静压 | — |

**⇒ 判据只在 `P1 > 10 kPa 且 Q > 0.5 L/min` 时有效；停灌段输出"无当前数据"。**

### （3）实验设计

| 实验组 | 内容 | 次数 | 说明 |
|---|---|---|---|
| **标定** | 每档供压下 ≥5 流量点 × 3 次，双向 | 6 工况 × 15 ≈ 90 次读数 | 得 `n`、`a`、`gain`、`r₀`、`s` |
| **主要故障** | 泄漏与受限两类 × 多档幅度 | **54 次独立操作** | 关键档位加密到 6—8 次 |
| **对照** | 正常轮灌切换（B 阀开关） | ≥20 次 | 验证"切换不被误判" |
| **对照** | 上游供压扰动 | ≥12 次 | 验证干管参照的作用 |
| **对照** | 邻支路扰动 | ≥12 次 | 验证共模抑制 |
| **留出验证** | 方法冻结后的独立批次 | ≥24 次 | 防止过拟合 |
| **总计** | | **约 200 次操作** | 3 人团队可完成 |

### （4）"提前量"的定义（本项目的口径）

**不按秒计，按"第几次灌水"计**：

```
提前量 = 故障发生到首次正确报警之间，经历的灌水窗口次数
```

**依据**：一条支管一天只有 1—4 小时有流量；15 秒门限占 0.4—1.8 小时窗口的 **0.2%—1.0%**，门限不是瓶颈。

## 7.3 可行性验证

| 验证项 | 方法 | 通过准则 | **当前证据** | **不通过怎么办** |
|---|---|---|---|---|
| 节拍可复现 | 台架按 0.4/1.0/1.8 h 运行 | 三档均可稳定运行 | 待搭台架 | 缩短时长并说明缩比关系 |
| 密封性 | 保压检查 | 无渗漏 | 待搭台架 | 加装生料带/密封圈 |
| 故障可注入 | 旁路阀与受限元件 | 幅度可调、可重复 | 待搭台架 | 改用可换孔板 |
| 次数可完成 | 工时核算 | 200 次 ≤ 团队可用工时 | **344—630 工时 vs 540—900 可用** | 减到 150 次或 120 次 |
| 标定充分 | 跨工况标定 | 得正确的 n | **跨工况得 n=0.4755** | 增加供压档 |

**本块结论：可行。** 台架规模小（约 900×520 mm）、材料常见、成本可控（水路材料 300—500 元）；**关键是"节拍复现"和"标定跨工况"两条纪律**。

# 块八　数据组织与统计（回答：怎么保证结论可信）

## 8.1 本块重点

**一句话**：把"次数"当样本量，把"置信区间"和"独立操作"讲清楚，不用"识别率 95%"这种说不清的口径。

## 8.2 技术做法

### （1）统计口径

| 指标 | 定义 | 为什么这样定 |
|---|---|---|
| **独立操作次数** | 每次人为故障注入算 1 次 | 避免把同一操作的多帧数据当多个样本 |
| **误报率** | 误报次数 / 单位时间（目标 ≤1 次/小时） | 直接对应泵工的感受 |
| **检出概率** | 正确报警的操作次数 / 总操作次数 | 与样本量一起给出 |
| **提前量** | 按灌水窗口次数计 | 贴合真实节拍 |
| **最短可检时长** | 能被检出的最短故障持续时长 | 由二维边界给出 |

### （2）置信区间

**必须给区间，不能只给点估计**：

```
n=3/格  → Wilson 95% 置信区间约 [79%, 96%]     ← 区间太宽，说明样本不足
n=6—8/格 → 区间明显收窄
```

**⇒ 关键档位必须加密到 6—8 次**，总次数 54—72 次。

### （3）留出验证

```
1. 用一部分数据标定门限与参照
2. 冻结方法与参数
3. 在独立留出批次上验证
4. 报告留出结果（而不是全部数据的结果）
```

**⇒ 防止"在同一批数据上调参又验证"的过拟合。**

### （4）消融实验（说明每个设计都有用）

| 消融项 | 对比 |
|---|---|
| 去掉干管参照 | 供压扰动下的误报率上升多少 |
| 去掉工况分档 | 轮灌切换的误报率上升多少 |
| CUSUM 换回固定阈值 | 检出延迟与误报的变化 |

## 8.3 可行性验证

| 验证项 | 方法 | 通过准则 | **当前证据** | **不通过怎么办** |
|---|---|---|---|---|
| 样本量充分 | 计算置信区间宽度 | 关键档 ≥6 次 | 已核算（n=3 时区间 [79%,96%] 太宽） | 加密关键档 |
| 独立操作 | 每次注入单独记录 | 操作级可追溯 | 实验设计已按此组织 | 补记录表 |
| 留出验证 | 冻结后独立批次 | 有留出结果 | 设计已含 ≥24 次 | 缩小结论范围 |
| 消融完整 | 三项消融 | 每项都有对照 | 设计已含 | 至少做干管参照一项 |

**本块结论：可行。** 核心是**统计纪律**：给区间、按操作计样本、留出验证、做消融。这四点做到，结论就"经得起推敲"。
