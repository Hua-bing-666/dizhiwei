一、现象：同一工况内 P1—Q 关系无法辨识，跨工况才能辨识
============================================================================
normal|0.3 首条轨迹的工况结构（B 阀 180—299 开）：
  B关 早期       t=20—174  P1 均值 109.71 标准差 0.281（相对 0.26%）  Q 均值 2.9311 标准差 0.0187
  B开          t=200—298  P1 均值 98.52 标准差 0.306（相对 0.31%）  Q 均值 2.7795 标准差 0.0199
  B关 后期       t=305—598  P1 均值 109.69 标准差 0.291（相对 0.27%）  Q 均值 2.9328 标准差 0.0201

⇒ 每个工况内 P1 只波动约 1%%，跨度极小。
⇒ 在这样窄的范围内，log-log 斜率由噪声主导 → 拟合指数不可信（实测得 -1.46 到 +0.49）

============================================================================
二、根因：可辨识性 —— 两种物理解释在数学上不可分
============================================================================
在本项目的测点上，观测方程可写成：
    P1 = Ps − Rc·Q² − R·Q²          （串联阻力）
    Q  = C·√P1                        （负载关系）

展开参数化：  P1 = Ps − (Rc + R)·C²·P1
             ⇒ P1·(1 + (Rc+R)·C²) = Ps
             ⇒ P1 = Ps / (1 + (Rc+R)·C²)
             ⇒ Q  = C·√Ps / √(1 + (Rc+R)·C²)

关键：联合量 β = (Rc + R)·C² 一个标量决定一切。
⇒ 在单一工况下，只能辨识 β，无法把 Rc、R、C 分离。
⇒ 实测印证：Q/√P1 全程恒为 0.280（即 C 已知），
   而 R 与 Rc 的具体分配不可辨识 —— 这正是 (P0−P1)/Q² 中 Rc 成分的来源。

============================================================================
三、定量：需要多大的压力跨度才能辨识指数？
============================================================================
设真实 Q = C·√P1，在 [P1_lo, P1_hi] 范围内拟合 Q = a·P1^n
拟合斜率 n 的相对误差与压力跨度 ΔP/P 的关系：
   斜率不确定性 ≈ σ_Q/(Q·√N) / ln(P1_hi/P1_lo)

  P1跨度(相对)   ln比值   σ_Q/Q=0.1%时 n 的不确定度   σ_Q/Q=1%时
         1%   0.0100                  0.1005          1.0050
         2%   0.0198                  0.0505          0.5050
         5%   0.0488                  0.0205          0.2050
        10%   0.0953                  0.0105          0.1049
        20%   0.1823                  0.0055          0.0548
        50%   0.4055                  0.0025          0.0247
       100%   0.6931                  0.0014          0.0144

⇒ 当前台架在单一供压档下 P1 跨度约 1%% → n 的不确定度高达 1.0—10（毫无意义）
⇒ 要辨识到 n 的不确定度 ≤0.05，需压力跨度 ≥20%%（σ_Q/Q=0.1%%）
⇒ 这正是申报书设计『80/120/160kPa 三档供压』的意义 —— 跨档合起来跨度 ~100%%，
   实测跨档拟合得 n=0.49（正确），单档拟合得 −1.46（错误）

============================================================================
四、由此定位的三个技术瓶颈（项目要回答的核心问题）
============================================================================
瓶颈一【可辨识性】
  在单一工况点、仅有 ±1%% 压力波动时，压力—流量关系不可辨识。
  → 必须用『多供压档 + 阀态变化』构造足够宽的跨度。
  → 问题：跨度要多大才够？（本节给出 20%% 的初步答案，台架需验证）

瓶颈二【共模/差模不可分】
  β = (Rc+R)·C² 把上游共同阻力 Rc 与本支管阻力 R 混在一起。
  → 单支管 + 单点流量无法把『上游供压变化』与『本支管故障』分开。
  → 这是结构性限制，不是算法能解决的；必须靠『干管参照』或『阀态分档』。
  → 问题：加一路干管参照后，可分的边界在哪？

瓶颈三【切换与故障的时域可分性】
  实测：B 阀开关使 P0 从 116.6 骤降到 104.1（−10.7%%），P1 从 109.9 降到 98.2，
        但 C 恒为 0.280、R 恒为 0.79 —— 切换只是换了一个工况点，不是故障。
  → 切换的特征是『阶跃 + 新稳态』；故障的特征是『同一工况内参数漂移』。
  → 问题：能否用『参数在工况内的漂移』而非『参数绝对值』做判据？
    （这正是本项目的判据新意所在：把判据建立在『与同工况健康参照的偏离』上，
      而不是绝对阈值上）

============================================================================
五、实测印证：健康工况内的残差尺度有多大（决定可检下限）
============================================================================
用 B 阀『关』的工况（20—175 + 300—599）联合标定：
  拟合指数 n = +0.4755     r0 = 0.7959     增益 = 0.9997
  e_Q 的稳健尺度 s_Q = 0.00247        e_R 的稳健尺度 s_R = 0.01514

原判据阈值：e_Q > 0.06, e_R > 0.60
⇒ 阈值 / 噪声尺度 = 24 倍（流量通道）、40 倍（阻力通道）

结论：
  · 阈值比健康噪声大 26—60 倍 → 正常工况几乎不可能误报（这是好的一面）
  · 但也意味着：**只有幅度很大的故障才会被检出**
  · 在 σ_p=0.3kPa（理想）下噪声尺度仅 0.0023；
    若传感器不确定度升到 σ_p=10kPa，噪声尺度会等比放大 → 阈值不再有裕度
  · ⇒ **可检下限由测量不确定度决定**，这正是本项目要建立『可检边界』的原因
