# 研究工作台与三维查看器的实际设计规范

本页覆盖MASTER.md中不适合本项目的展示网站模式、销售入口和在线字体建议。技能检索返回的Minimalism & Swiss Style适合本项目；Enterprise Gateway营销结构不适用，因此未实施。科研原型以明确状态、可读数据与操作证据为主。

现有技术栈为离线HTML、CSS、原生JavaScript，以及已固定版本的Three.js。保持本地打开可用；不引入在线字体、React构建系统或在线素材依赖。

## 共同视觉规范

| 用途 | 实际配置 |
| --- | --- |
| 正文 | Segoe UI、Microsoft YaHei，15px，行高1.7 |
| 主标题 | 29—41px；小屏32px；单个页面一个主题 |
| 正文色 | #172b3a |
| 次要说明 | #536777 |
| 主要动作 | #176451，白色文字 |
| 键盘焦点 | #315c95，3px外轮廓 |
| 画布与表面 | #f5f7f9背景，白色内容区 |
| 状态提示 | 配文本的暖色提示，不用颜色单独表达状态 |
| 圆角与间距 | 7px控件、10—12px内容区；8/16/24/32px节奏 |

侧栏224px，页面顶栏显示章节和离线状态。窄屏使用可横向滚动的章节导航，内容不产生整页横向溢出；宽表仅在自身容器内滚动。界面使用本项目自绘SVG图标，不包含第三方图标或照片复制。

## 信息与交互

首页分别列出480次合成诊断、1920次通信回放和54次计划实物操作，不能合并成累计实物试验数量。三维入口采用真实场景渲染，不以模型图冒充样机照片。

诊断页的处置表单按需展开。人工查看、复测及归档独立记录；缺少备注、复测依据、或处于离线/无效时，分别阻止不合条件的保存。浏览器本地记录和JSON导出均标识synthetic_ui_demo，实际接收数据库和硬件接入仍为未来任务。

三维查看器提供整体、俯视、前视与两处局部，配按钮、键盘及指针操作。数字标注与侧栏图例互补，模型颜色仅辅助区分回路。展示实际用途和几何核验边界。

技能参考为[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)，布局参考[shadcn/ui](https://github.com/shadcn-ui/ui)和[Tabler](https://github.com/tabler/tabler)。参考的是组织方式，本项目未引入它们的组件源码或整套模板。
